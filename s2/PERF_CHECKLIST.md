작성 전 상태: **미측정**. Godot 4.7.2 stable / Mobile / 디버그 APK.

각 행은 새 실행 후 동일한 위치와 조작으로 시험한다. 필드 시간 60초 부근과 600초 부근에서 10초 동안 관찰한 FPS 범위/대표값과 Frame 평균을 기록한다. 앱을 끄거나 화면을 잠그지 않고 계속 돌린다. 조건마다 기기를 식힌 정도도 비고에 적는다. `좀비 제출/설정`을 함께 적어 부하가 실제로 비슷했는지 확인한다.

- [ ] E 조건 10분 뒤 대표 FPS가 **30 이상**, Frame이 **33.33ms 이하**이며 지속적인 30 미만 구간 없음.

## 장면 전환과 조작

| 구간 | 처음 실행 끊김 유무 / Max(120f) ms | 10분 시험 후 홈부터 다시 실행 / Max ms | 비고 |
|---|---|---|---|
| 달리는 여섯 객차 → 감속 / 정지 | | | |
| 짧은 로딩 → 정차 카메라 회전 | | | |
| 당당함 하차 → 처짐 자세 전환 | | | |
| 정차 → 사선 탑뷰 필드 | | | |

- [ ] 정차 카메라 회전 중 눈에 띄는 끊김 없음(필수 기준).
- [ ] 정차 전환 **최초 실행**과 이미 한 번 실행한 뒤의 차이 확인.
- [ ] 당당함은 고개가 들리고 처짐은 어깨·가슴 자세가 변함.
- [ ] 바닥 탭 이동, 벽 차단, 문 통과 확인.
- [ ] 소음 반경 안 좀비가 모이고 밖 좀비는 계속 배회함.
- [ ] 벽 뒤가 어둡게 가려지고 이동할 때 시야가 갱신됨.
- [ ] 좀비 50/100/150, 시야·안개·비 단추가 작동함.
- [ ] 가로 화면 유지, 한글 글꼴, 단추 터치와 화면 모서리 잘림 확인.
