# 건물 조각 키트

`tools/blender/building_kit.py`(판 1)가 블렌더 4.5.10 LTS 헤드리스로 만든다. 이 파일과 `catalog.json`은 스크립트가 새로 쓰니 손으로 고치지 않는다.

```
blender -b --factory-startup -P tools/blender/building_kit.py -- --repo .
```

## 약속

- 칸 1 m, 층 3.0 m, 턱 0.35 m(`map_view.gd`의 `LEVEL_H`·`CUT_H`). 바깥벽 0.45 m, 안벽 0.2 m, 모두 칸 가운데.
- Godot 축으로 X는 벽을 따라, +Y는 위, +Z는 바깥이다. 90° 단위로 돌려 놓는다.
- 늘림 조각은 X 끝면이 없다(이웃 조각이 덮는다). 안벽과 기단만 끝면이 있다(홀로 끝나거나 문 칸에서 끊긴다).
- 기단은 1층에만 놓는 따로 조각이다. 위층 바깥벽은 바닥까지 벽면이다.
- 열린 층에서는 가로 줄(북쪽 바깥 줄 빼고)을 턱 조각으로 바꾼다. 턱 줄 끝 모서리는 `ext_corner_cut`이고, 그 모서리와 만나는 선 줄의 끝은 `wall_end_cap`으로 막는다.
- 유리, 문짝, 판자는 상태가 바뀌니 낱 노드로 놓는다. 나머지는 건물 × 층 × 무리마다 한 메시로 굽는다.
- 박공지붕은 경간 10 m로 만들었다. X는 지붕 길이만큼 늘이고, Y와 Z는 같은 배율(경간 ÷ 10)로 바꾸면 경사 35°가 그대로다. 처마 내밈(0.3 m)과 지붕 두께도 같은 배율로 바뀐다. 박공 끝 벽은 X와 Z를 같은 배율로 바꾼다.
- 그림자는 바깥 무리와 지붕만 드리운다(3번 이식).

## 칠 구역

정점 색 R·G·B가 구역 번호의 비트(0 또는 1)이고 A가 날씨 받음(바깥에 드러난 면 1, 안쪽 0)이다. 무늬와 색은 건물 셰이더가 세계 좌표로 그린다.

| 번호 | 구역 | R G B |
|---|---|---|
| 0 | 벽면 | 0 0 0 |
| 1 | 석재(기단·띠·창턱·모서리돌) | 1 0 0 |
| 2 | 나무 | 0 1 0 |
| 3 | 유리 | 1 1 0 |
| 4 | 지붕 | 0 0 1 |
| 5 | 쇠붙이 | 1 0 1 |
