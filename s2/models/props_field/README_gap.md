# 지도 조립 소품 gap

`tools/blender/props_field_gap.py` 자동 장부. 샛길 틈 세 갈래, 벽장 선반, 겨울 잡목 덤불, 5종.

rect 가운데 바닥, +Y 위·+Z 앞(지도 안쪽), facing은 +Y축 -90도씩. 발자국 96% 안쪽.

재질·그림·빛·애니메이션 없는 단일 메시/단일 surface, 정점색 Col, 각 600삼각형 이하.
틈 셋은 지나갈 수 있다(solid none). 철조망·가시·망루는 금지선이라 없다.
덤불의 눈은 굽지 않는다: 위가 넓은 덩이라 눈 오는 날 소품 셰이더(weathered)가 윗면에 얹는다.
