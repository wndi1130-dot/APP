# 원작별 적용 상황과 구현 근거

[목록](README.md) · [출처 장부](sources.md)

## 읽는 법

**제작자 확인**은 공개 본문/전사의 내용이다. **독립 분석**은 다른 제작자의 청취 해석이다. **프로젝트 제안**은 우리가 옮겨 볼 방법이다. 원작 재생을 직접 확인한 것과 혼용하지 않는다. 현재 직접 영상 재생/음원 청취는 0건이다.

## 1. Frostpunk 1: 법률서·사건 화면의 석탄 같은 검은 얼룩

11 bit의 Bartosz Sobolewski는 법률서(Book of Laws)와 이야기 사건 화면의 어두운 UI 얼룩이 핵심 자원인 석탄을 연상시키며 어두운 톤을 강화한다고 설명한다. 결빙된 화면 가장자리 등도 같은 방향의 미술 장치다. **적용 상황과 재질의 의미가 확인된 자료**다. [G01](sources.md#g01)

알 수 없는 것: 각 버튼 호버/클릭의 원본 셰이더, 확산 텍스처, 재생시간, 곡선, 실제 유체 사용 여부. 이 인터뷰만으로 '법률을 고를 때 매번 동일한 잉크 시뮬레이션'이라고 기록하지 않는다.

적용 제안: 열차의 정치·사건 UI에는 물 자체보다 목탄·그을음·종이의 재질 언어를 먼저 비교한다. 선택의 무게는 큰 검정 화면을 매번 덮는 방식보다 소수의 중요한 진입/확정 이벤트에 배분한다.

## 2. Frostpunk 2: Council splotch는 상태를 보여 주는 합성 효과

Adam Dyląg의 분해 설명에서 의회 내부 장면과 게임 UI 위에 여러 효과층을 조합한다. Niagara 리본의 렌더타깃, UI의 촉수 재질, 원형의 기름 같은 후처리가 결합된다. 여러 노이즈와 변형 강도는 도시의 Tension에 반응한다. 긴장이 충분히 낮아지면 촉수·리본이 없어지고, 표결 중에는 얼룩이 중앙으로 이동한다고 설명한다. [G02](sources.md#g02)

이 설명으로 확정할 수 있는 것은 **의회라는 문맥 + 현재 긴장이라는 입력 + 합성된 기름 효과**다. '정치 버튼의 단순 눌림', 'Idea Tree의 연구 노드', '전체 화면의 실시간 유체'를 모두 이 하나의 구현으로 설명할 수는 없다.

저자는 GIC 2025 발표와 슬라이드를 언급하지만 이번에는 슬라이드 본문을 읽거나 영상을 보지 못했다. 제작자 설명을 넘는 해상도·파티클 수·shader graph 노드·GPU ms는 비워 둔다.

## 3. 연구 화면: Idea Tree의 실제 제작자와 볼 구간

Bartosz Babis의 VFX Reel 2025는 설명에서 **00:54–01:00 Idea Tree shader: Marin Zujic**을 표시한다. 연구 화면의 시각 효과를 더 볼 정확한 탐색 단서다. 이 구간은 저자의 크레딧 시간이지, 우리가 재생해 측정한 시간은 아니다. 릴에 다른 작품·티저도 섞여 있다. [G03](sources.md#g03)

연구 트리 진입·노드 호버·선택·시작·진행·완료는 따로 봐야 한다. 현재 자료로 각 상황의 재생 길이와 소리를 채울 수 없어 [캡처 계획](capture_checklist.md)에 별도 항목을 만들었다. Council의 알고리즘을 Idea Tree의 알고리즘이라고 복사하지 않는다.

우리 게임은 단순 연구보다 구시대 기술의 복원이라는 의미가 있다. 그래서 도면 선·분리된 조각·맞물림을 국소 번짐과 조합하는 안을 제안한다. 이는 원작 구현 설명이 아니다. [P01](sources.md#p01)

## 4. 작은 창·퀘스트의 움직임과 형태 연속성

Jakub Galanciak의 FP2 PC 포트폴리오는 modal과 quest log의 애니메이션·구현 담당을 명시한다. 해당 화면을 직접 비교할 제작자 원자료로 수록했다. 본문에 없는 easing·duration·사운드는 만들지 않았다. [G04](sources.md#g04)

Milena Młynarska의 개발 참여 사례는 사건 표식과 열리는 창의 주요 모양이 이어지도록 고치는 문제를 다룬다. 설명상의 Ghost/Small Lens/Big Lens 형태 대응은 공간·의미가 이어지는 UI의 참고다. 저장/불러오기 개선안은 미구현이라고 명시하므로 출시 UI와 나눠 기록한다. [G05](sources.md#g05)

적용 제안: 눌렀던 버튼의 모양이 커지는 마스크의 출발점이 되면 무엇을 열었는지 추적하기 쉽다. 그러나 같은 창의 탭 이동은 큰 전환을 반복하지 않고 선택 배경만 교체한다.

## 5. 콘솔판은 PC hover를 그대로 옮기지 않았다

FP1의 원형 메뉴 설명은 발전기·원형 도시와 조작 체계를 연결한다. FP2 콘솔의 Command Radial은 Idea Tree/탐험/Council로 들어가는 상위 메뉴이고, HUD 대부분을 잠시 숨기고 배경을 흐려 집중시킨다. 진행 표시도 이 메뉴에 있다. 상황별 Quick Radial은 별도이고 두 radial은 시간을 멈춘다. [G12](sources.md#g12) [G13](sources.md#g13)

이는 화면 정리와 입력 문맥의 실제 사례다. 휴대폰에 PC의 hover를 필수로 두거나, 모든 세부 패널을 열 때마다 blur·시간정지를 복제하는 근거는 아니다. 우리 전술 일시정지/전략 시간은 기존 규칙을 따른다.

## 6. This War of Mine: 목탄풍과 사진·평면 UI의 관계

공식 소개는 목탄풍 미술을 명시한다. 원래 UI 제작자 Tomasz Piętek은 인터페이스·아이콘뿐 아니라 초상과 중요한 순간의 사진까지 만들었다고 설명한다. [G06](sources.md#g06) [G07](sources.md#g07)

이 자료에서 버튼별 확산 알고리즘이나 UI sound event 표는 얻지 못했다. 사용자가 느낀 번짐·간단한 강조를 연구 목표로 삼되 'TWOM도 Niagara/같은 유체'라고 설명하지 않는다. 생존자 선택, 제작/거래, 밤 계획, 새 날 요약은 서로 다른 사용 상황으로 다음 관찰에서 분리한다.

적용 제안: 사건 카드·일지·대사에는 거친 종이/목탄 가장자리, 중요한 사진의 등장과 짧은 장 넘김을 활용한다. 배경의 번짐으로 본문을 읽기 전 강제 대기시키지 않는다.

## 7. 결론과 남은 증거

원작의 미술 일관성은 확인되지만 세 작품의 공통 엔진·동일 shader·물리 시뮬레이션은 확인되지 않았다. **재질이 번지는 시각, 입력의 짧은 피드백, 사회 상태의 지속 표현, 중요한 결과의 연출을 별개 층으로 설계**하는 것이 이 보고서의 제안이다.

원작의 정확한 버튼 상태별 영상, 무음/음악 제거 비교, 각 cue의 오디오 원본/이벤트 이름, 실제 easing/ms, 현재 출시 빌드 차이는 미확인이다. 후속 재생/청취로 채워야 하며 [상황별 표](event_matrix.md)의 숫자를 역으로 원작 값처럼 읽지 않는다.
