## 먼저 지킬 것

최신 main의 설계를 먼저 대조한다. 기존 아트 연구 PR #12와 최신 main은 별개이고, 여기에서 오래된 문서를 main 위에 덮어쓰지 않는다. 이번 수집은 `research/ui-motion-sound-20261007` 브랜치의 독립 폴더다. 다른 작업자의 source/game code는 변경하지 않는다.

월드·홈은 비픽셀. 사용자는 이제 UI motion의 번짐·간단한 반응 방향을 원한다. 이를 여전히 완전히 미정이라고 무시하지 않는다. 반대로 폰트·모든 아이콘 화풍·engine·원작 fluid 알고리즘을 임의 확정하지 않는다. 하늘색은 지지에만 쓴다는 최신 색 의미, 단계 레버, 왼쪽 사건 카드, 기술 복원, 분리된 고철/목재 재고를 보존한다. [P01](sources.md#p01) [P03](sources.md#p03)

## 권장 분업

원작 관찰 담당은 capture_plan의 미확인 항목만 채우며 timestamp와 direct observation 여부를 남긴다. 시각 담당은 T01~T12를 참고해 자체 reveal/edge 방식의 비용과 품질을 비교한다. 소리 담당은 먼저 허용 음원을 청취하고 cue 의미·파일·반복 규칙을 분리한다. 통합 담당은 이벤트 ID·비밀 정보·시간정지·취소를 검수한다. 원본 한 파일을 여러 작업자가 동시에 덮어쓰지 않는다.

## 제작이 허용될 때의 납품 단위

버튼 한 장이 아니라 normal/focus/pressed/selected/disabled/pending 상태, opening/closing, 취소·역방향, 실제 hit area, mask·noise 원본과 라이선스, 재생 curve, reduced-motion fallback, sound cue·원본/가공 파일/권리·trigger, 측정 로그를 함께 납품한다. 모든 텍스트를 이미지에 구워 한국어 조판·폰 크기 대응을 잃지 않는다.

정치와 연구는 특별 전환의 후보지만 모두 1초 넘는 풀스크린 효과로 통일하지 않는다. ms 수치는 event_matrix의 **초기 비교값**이지 확정 규격이 아니다. 게임 로직 승인과 시각 종료를 분리하고, 메뉴를 꺼도 결과를 재실행하지 않는다.

## 실제 시험 목록

연타·빠른 탭 교체, 드래그 취소, 잘못된 입력, 비활성 클릭, timeScale 0, 앱 백그라운드/복귀, audio context 미활성, 소리 꺼짐, 동작 감소, 작은/긴 한글 라벨, 화면비 변경, 비밀 투표, 알림 10개 동시, 낮은 품질 설정을 점검한다. 성공 배지가 실제 거절보다 먼저 보이지 않는지 확인한다.

FPS 평균만 보지 말고 입력 이후 첫 반응, 프레임시간 변동, GPU/CPU/메모리, 모바일 발열을 측정한다. 원작자 장면과 자체 prototype을 같은 조건으로 비교하기 전 '원작 수준' 또는 '모바일 최적화 완료'라고 보고하지 않는다.

## 저장 규칙

공개 저장소에는 이 연구의 작성 문서·URL·출처 상태를 둔다. 원작 영상/GIF/음원/아트북 전문은 미러하지 않는다. MIT/CC0 후보라도 실제 취득 파일과 포함 자산의 고지를 먼저 확인한다. 유체 데모·표본 음원·3D 에셋은 본 폴더의 완료 수에 포함되지 않는다.
