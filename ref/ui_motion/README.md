## 핵심 결론

FP1의 법률서/사건 화면은 석탄을 연상시키는 어두운 얼룩이라는 미술 의도가 공개돼 있다. FP2 Council은 긴장도에 반응하는 기름 얼룩의 기술 분해가 공개돼 있다. TWOM은 목탄풍과 사진·아이콘의 미술 계열이 확인된다. **세 작품의 모든 버튼이 동일 엔진·같은 유체 셰이더로 구현됐다고 볼 근거는 없다.** [G01](sources.md#g01) [G02](sources.md#g02) [G06](sources.md#g06) [G07](sources.md#g07)

먼저 작은 버튼에는 짧은 국소 번짐, 중요한 화면에는 더 큰 마스크 전환, 긴장에는 가장자리의 지속 상태를 배정하는 안을 비교한다. 이것은 본 보고서의 제안이다. 글자·숫자·실제 클릭 영역은 움직이는 얼룩과 분리한다.

## 이번 수집의 범위

출처 항목 **37개**: 원작 관련 14개(그중 G10은 독립 분석), 기술 문서/도구 16개, 음원 팩 페이지 2개, 프로젝트 문서 3개, 미확보 탐색 경로 2개. 합계는 자료 항목 수이지 독립적인 실험 수·영상 시청 수가 아니다. G08/G09처럼 같은 개발 자료를 설명하는 항목도 구분했다. 기존 85개 자산 목록에 이 숫자를 단순 더하지 않는다.

**[WATCH] 동영상 직접 재생·음원 청취·원작 프레임 시간 측정은 하지 않았다.** 영상은 제작자 설명/전사/챕터를 읽었다. 원작마다 정확히 어떤 click.wav를 언제 불렀는지나 easing 수치까지 확보한 것은 아니다. 미확인 값은 비워 두고, 아래 제안 수치와 혼합하지 않는다.

저장한 것은 작성한 조사문·목록·URL·후속 검사 규격이다. 원작 이미지·GIF·영상·오디오·아트북·전사 전문, 외부 코드 패키지는 올리지 않았다. 설치·프로토타입 구현·게임 규칙 수정·main 병합도 하지 않았다.

## 최신 프로젝트와의 연결

조사 시 main은 기존 연구 PR #12의 기준보다 진행돼 있었다. 이번 폴더는 최신 main의 비픽셀 아트 정정, 어두운 바깥 날씨, **하늘색은 지지에만 사용**, 별도 고철·목재를 묶어 보여 주는 결정을 유지한다. 구 판의 밝은 하늘색 겨울·픽셀 글꼴 기본값으로 되돌리지 않는다. [P01](sources.md#p01) [P03](sources.md#p03)

기존 2~6판 원문: [고정 커밋의 전체 아트 색인](https://github.com/wndi1130-dot/APP/blob/f7e13f20d44296bd6ce1d9d745109dab0adc5e7a/ref/art/README.md). 이 링크는 당시 연구 기록이며 main에 합쳐졌다는 뜻이 아니다. 이번 브랜치는 `research/ui-motion-sound-20261007`이다.
