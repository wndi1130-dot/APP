# 상황별 UI 모션·사운드 매핑 — 프로젝트 제안

[목록](README.md) · [JSON](event_matrix.json)

모든 ms는 우리 게임의 후속 A/B 시험용 제안이다. 원작 실측/제작사 권장값이 아니다. duration 0은 시간에 맞춘 일회 연출이 없는 데이터/설정 이벤트다.

원작의 per-button cue sheet가 아니다. 다음 항목의 시각·음색·반복 규칙은 모두 우리 프로젝트의 비교안이다.

<a id="e01"></a>
## E01. 호버·키보드 포커스

발생: 새 버튼에 포인터/포커스가 들어옴
그림: 버튼 뒤의 작은 목탄 번짐. 라벨은 고정.
소리: `focus_soft_optional`
승인/결과: 선택/자원 소모 없음
반복: 기본 무음; 소리를 켜도 새 대상에만, 미세 이동에는 재생 안 함
취소: 포인터 이탈·스크롤 시작 시 현재 값에서 약하게 소거
동작 감소: 정적 테두리와 짧은 명도 변화
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [G01](sources.md#g01) · [T05](sources.md#t05)

<a id="e02"></a>
## E02. 버튼 누름

발생: pointerdown/submit 준비
그림: 테두리/배경만 짧게 눌림. 글자 확대·수축 없음.
소리: `press_tick`
승인/결과: 준비 반응일 뿐 승인 아님
반복: 한 포인터 한 번. click과 중복 금지
취소: pointercancel/영역 밖 release는 E04
동작 감소: 정적 눌림 표시
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [T16](sources.md#t16)

<a id="e03"></a>
## E03. 유효 클릭 승인

발생: 동일 대상에서 release/keyboard submit + 유효성 통과
그림: 작은 번짐이 선택 면을 채운 뒤 선택 표시만 남음.
소리: `accept_click`
승인/결과: 검증된 명령 ID당 한 번. 서버/로직 거절 시 E05
반복: 액션 ID 중복 방지
취소: 그림 중단은 승인된 명령을 되돌리지 않음
동작 감소: 즉시 선택 표시 + 짧은 fade
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [G01](sources.md#g01) · [G05](sources.md#g05) · [T14](sources.md#t14)

<a id="e04"></a>
## E04. 누름 취소

발생: 드래그 이탈/스크롤/운영체제 취소
그림: 눌림과 얼룩을 원래 상태로 되돌림.
소리: `none`
승인/결과: 명령 실행 안 함
반복: 소리 없음
취소: 남은 완료 콜백 무효화

<a id="e05"></a>
## E05. 실행 불가

발생: 부족한 비용/비활성/조건 불충족의 명시적 입력
그림: 채우지 않는 짧은 테두리 반응 + 이유/필요치 유지.
소리: `deny_dull`
승인/결과: 비용 차감·성공 소리 없음
반복: 같은 이유 연타는 rate-limit; 숫자는 정확히 유지
취소: hover에는 경고 재생 안 함
동작 감소: 정적 경고 아이콘/이유
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [P01](sources.md#p01) · [T14](sources.md#t14)

<a id="e06"></a>
## E06. 같은 창의 탭 전환

발생: 정치/연구 내 하위 탭 A→B
그림: A 얼룩 소거와 B 번짐 겹침; 패널 전체 재등장 금지.

승인/결과: 선택 대상만 변경
반복: 마지막 유효 선택 우선; 입력 줄 세우지 않음
취소: 이전 전환을 현재 화면 상태에서 중단
동작 감소: 짧은 crossfade
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [G05](sources.md#g05) · [T04](sources.md#t04)

<a id="e07"></a>
## E07. 정치 화면 진입

발생: 정치 버튼을 유효 클릭

취소: 닫기/다른 메뉴 입력을 반영; 선택 정보를 보존
동작 감소: 이동 없는 100–150ms fade 제안
clock: `ui_unscaled`

<a id="e09"></a>
## E09. 법안 표결 제출

발생: 검증 후 표결 레버 승인
그림: 레버 걸림→의회 시선 정리→정해진 표결 장면.
소리: `vote_latch`
승인/결과: 표결 ID당 한 번. 결과는 게임 로직에서 결정
반복: 표 수마다 동일 click 100번 금지
취소: 장면 생략은 최종 결과를 한 번 반영. hidden votes 누설 금지
동작 감소: 요약 집계만 표시
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [G02](sources.md#g02) · [P01](sources.md#p01)

<a id="e10"></a>
## E10. 표결 결과

발생: 공개 가능한 집계 완료
그림: 통과/부결을 이름표와 숫자로 확실히 고정. 번짐은 한 번 정착.
소리: `law_result`
승인/결과: 집계 완료 전 성공 소리 금지. 도덕적 좋은 결과라고 축하하지 않음
반복: 결과 ID당 한 번; 화면 다시 열 때 재생하지 않음
취소: 종료 콜백은 저장 결과를 중복 실행하지 않음
동작 감소: 즉시 결과 + 작은 명도 변화
clock: `ui_unscaled`
참고 출처(동일 구현 주장 아님): [G10](sources.md#g10) · [P01](sources.md#p01)

## E11. 연구·복원 화면 진입

동작 감소: 고정 도면 crossfade
clock: `ui_unscaled`

<a id="e16"></a>
## E16. 사건 카드 열기

발생: 홈 왼쪽 서류 더미 선택
그림: 서류가 왼쪽 절반으로 펼쳐지고 가장자리만 목탄 마스크. 오른쪽 열차 유지.
소리: `paper_open`

## 음향 cue 의도 목록

실제 WAV 선정 전의 설계 ID다. 모두 미청취·미제작 상태이다. `none`은 무음 정책이다.

### `focus_soft_optional` — UI 탐색
기본 무음. 필요하면 매우 짧고 건조한 종이/목탄 접촉.
선택 확정·성공과 구분. hover 연타에 연속 스위시 금지.

### `press_tick` — UI 입력
짧은 마른 클릭 한 층.
손가락이 닿았다는 피드백; 비활성 클릭에 성공 임팩트를 쓰지 않음.

### `accept_click` — UI 승인
마른 스위치 + 작은 재질 울림.
큰 저역 없이 즉시 반응. 매 버튼마다 종/함성 금지.

### `deny_dull` — UI 거절
짧고 둔한 걸림.
불쾌한 고음 버저를 연타하지 않음. 이유는 시각으로.

### `tab_brush` — 탭 전환
짧은 종이/목탄 쓸림.
왼쪽/오른쪽 의미를 과도한 스테레오 위치에만 의존하지 않음.

### `politics_open` — 정치 메뉴
종이 펼침/기계 래치 + 절제된 저역 꼬리.
저역은 휴대폰에서 안 들릴 수 있으므로 중역 반응을 남김. 원작 음원이라고 명명하지 않음.

### `faction_select_soft` — 공동체 선택
짧은 마른 탭.
군중 환호는 선택 버튼마다가 아니라 사회/대사 상태에만.

### `vote_latch` — 표결 제출
레버 걸림; 돌/투표함 접촉은 장면 단계에서 별도 제작.
승인 전 결과 음원 금지. 100표에 100회 중첩하지 않음.

### `law_result` — 결과 전달
통과는 짧은 무게감 있는 확정, 부결은 닫히는 둔한 응답을 비교.
도덕적 승리의 팡파르 아님. 정확한 결과는 라벨·숫자로 전달.

### `research_open` — 기술 화면
도면 펼침 + 마른 마찰.
액체처럼 보여도 물방울·거품 소리를 자동으로 배정하지 않음.

### `research_select` — 기술 선택
짧은 연필/종이 접촉을 자체 녹음하는 안.
노드 탐색은 시작/완료 소리와 다름. 실제 라이브러리 파일 미선정.

### `research_start` — 작업 시작
작은 래치/맞물림.
조건 검사 뒤 한 번만.

### `research_complete` — 작업 완료
마지막 부품 맞물림 + 절제된 짧은 맑은 표시음.
경고·법안 결과와 식별. 청취로 적합성 확인 전 확정하지 않음.

### `paper_open` — 사건·일지
자체 녹음한 종이 펼침/마찰 후보.
서술이 중요한 곳에서 잔향이 음성을 가리지 않음.

### `notice_soft` — 일반 알림
작은 종이/책갈피 소리.
연속 알림은 묶음; 반복 찌르기 금지.

### `detent_tick` — 단계 조절
짧은 기계 걸림; 제한된 음색 변형.
단계가 실제 바뀔 때만; 실제 단위를 pitch로 숨겨 표현하지 않음.

### `resource_unfold` — 재고 상세
가벼운 펼침.
메뉴 열기가 자원 획득으로 들리지 않게 함.

### `crowd_state` — 의회 공간
자작/허용 음원의 낮은 웅성거림과 상태별 밀도.
짧은 버튼 효과와 별도 루프 그룹. 숨은 투표자·비밀을 누설하지 않음.

### `critical_warning` — 위급 알림
일반 click과 구별되는 고유 짧은 신호 + 필요한 자막.
다른 UI가 씹지 않도록 우선순위. 지속 사이렌 기본값 금지.

### `panel_close` — 닫기
짧은 종이/래치 마무리.
기계적인 전체 파형 역재생이 자연스러운지는 청취 후 판단.
