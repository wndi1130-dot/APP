## 1. 이번 조사에서 달라진 초점

**모델 수를 늘리기보다, 사물과 인물이 상태에 따라 달라지는 데 필요한 자원을 채운다.** 이는 다음 제작을 위한 제안이며 새 기능 확정이 아니다.

| 참고 축 | 우리 프로젝트에 필요한 자원 묶음 | 그대로 가져오지 않을 것 |
|---|---|---|
| This War of Mine | 지친 민간인의 자세·생활 동작·입던 옷·사람이 쓴 자리 | 2D 단면을 전체 월드 방식으로 강제하기, 모든 동작을 전투 모션으로 대체하기 |
| Frostpunk 1 | 열원·증기관·작업 도구·적설/서리/젖음의 상태 변형 | 빅토리아 시대풍을 붕괴 전 현대 중앙유럽 전체에 적용하기 |
| Frostpunk 2 | 정치 상태에 반응하는 계기·테두리·군중 자세·소리 | PC/콘솔 UI 복사, 원작 기름 얼룩·로고·Niagara 자산 재사용 |
| Metro 시리즈 | 세계 속 계기·일지·무전, 생활 소품과 여정이 남는 객실 | 1인칭 장비 조작 강제, 가스마스크/방사능 시스템 추가, 모바일 HUD 제거 |

월드는 사용자가 정정한 **좀보이드식 그래픽·사선 탑뷰**를 유지한다. UI·초상·폰트의 최종 화풍과 엔진 버전·카메라 각도를 이 조사로 결정하지 않는다. 기존 세션 안내의 S1 정치 프로토타입이라는 단계와 공개 저장소 저작물 경계를 유지한다. [현재 세션 안내](../../docs/handoff/session_start.md), [아트 기준](../../docs/art/production_brief.md)

## 2. 실제 제작자가 설명한 자료

출처가 설명하는 사실과 우리 게임으로 옮기는 제안을 나눴다. 원작의 제작 문서/포트폴리오는 **참고자료**이지, 게임 자산의 사용권을 주는 라이브러리가 아니다.

### R01 · This War of Mine — Indie Game Exposes the Intimate Horror of War

**출처:** [ACM SIGGRAPH / 개발팀 Dominik Zieliński·Olaf Pożoga·Przemek Marszał 인터뷰](https://www.siggraph.org/news/indie-game-exposes-the-intimate-horror-of-war/)

**확인:** 평범한 민간인을 표현하려고 실제 사람과 일상복을 스캔했고, 다른 게임에는 괜찮아도 이 작품의 지친 인물상과 맞지 않는 애니메이션은 버렸다고 설명한다.

**우리 쪽 제안:** 전투 가능 여부와 별개로 피로·추위·불안이 읽히는 자세와 생활 동작을 모션 검수 기준에 추가한다.

**잘못 읽기 쉬운 점:** 인물끼리 눈을 맞추거나 바람에 반응하는 행동은 인터뷰에서 더 만들고 싶다는 아쉬움이다. 구현된 기능으로 적지 않는다. 사진·캐릭터·원본 모션 사용권을 주는 자료가 아니다.

### R02 · Frostpunk 1 / The Last Autumn — Building a snow-free Frostpunk with RizomUV

**출처:** [11 bit studios / 실제 제작팀의 작업 설명](https://11bitstudios.com/frostpunk_rizomuv/)

**확인:** 설경을 연결하는 눈 덮개 메시와, 비가 오는 환경에서 동토로 변하는 오브젝트의 여러 재질 설정·일부 별도 텍스처 세트를 설명한다. UV 재사용과 재질별 배치도 다룬다.

**우리 쪽 제안:** 눈은 단일 셰이더가 아니라 얇은 서리 마스크·두꺼운 덮개 메시·입자·흔적의 분리된 자원으로 설계 후보를 잡는다.

**잘못 읽기 쉬운 점:** 특정 DLC의 제작 방식이다. 본편 모든 눈의 구현이라고 확대하지 않는다. RizomUV 구매나 우리 프로젝트의 3개 상태 고정을 요구하는 근거도 아니다.

### R03 · Frostpunk 2 — Frostpunk 2 – the Council splotch

**출처:** [Adam Dyląg / 해당 효과 제작자](https://gunzes.artstation.com/projects/kNVK9d)

**확인:** 의회 화면의 기름 얼룩은 긴장도에 반응한다. 동적 후처리, Niagara 리본의 렌더 타깃, UI 재질을 결합하며, 긴장도에 따라 노이즈 움직임과 변형 강도가 달라진다.

**우리 쪽 제안:** 우리 UI에서는 독자적인 그을음·압력·성에 모티프를 후보로 삼고, 긴장도 하나가 변형 진폭·속도·테두리 침범량을 함께 제어하도록 비교한다.

**잘못 읽기 쉬운 점:** 원작 효과 파일을 제공하는 에셋이 아니다. Niagara는 Unity에 그대로 들어가지 않는다. 제작자는 GIC 2025 발표 슬라이드를 공개했지만 녹화본을 찾지 못했다고 적었다. 이번에는 발표 영상을 시청했다고 주장하지 않는다.

### R04 · Frostpunk 2 — Game UX Case Study: Frostpunk 2 (2024)

**출처:** [Milena Młynarska / 개발 참여자의 2026-05-08 사례 연구](https://www.milenamlynarska.com/uxui)

**우리 쪽 제안:** 서류 뭉치 버튼과 실제 결정 카드, 공동체 표식과 펼쳐지는 패널의 형태·의미가 연결되는지 검수한다.

**잘못 읽기 쉬운 점:** 함께 소개된 저장/로딩 화면 재설계는 제작 사정으로 구현되지 않았다고 명시돼 있다. 이를 출시판 기능으로 소개하지 않는다. Heatstamps를 우리 게임에 추가하는 근거가 아니다.

### R06 · Metro Exodus — Metro Exodus – Main menu 제작 설명

**출처:** [Andrii Krasavin / 해당 시기 Senior Game·Level Designer](https://akrasavin.github.io/portfolio/projects/metro-exodus.html)

**확인:** 열차 객실 메뉴가 여정의 계절·수집 소품·인물 상태에 반응하도록 만들었다. 저장 파일에 맞춰 카메라가 붙은 객실을 해당 환경으로 옮기는 장면 구성 방식을 설명한다.
