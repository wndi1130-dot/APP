# A5 Gemini 문장 생성 파이프라인

`gen_text.ts`는 비어 있는 문장 필드를 Gemini로 채운다. 지금은 프로필의 한 줄 소개(`line`, 40자 이내)만 다룬다. 사건 본문, 선택지, 인물 소개 같은 다른 필드도 같은 구조(요청 조립 → 호출 → A1 검사 → 저장)로 넓힐 수 있게 나눠 두었다.

## 저장 위치

생성한 줄은 `data/profiles.json`에 쓰지 않고 `generated/profile_lines.json`에 프로필 id별로 모은다. A3 생성기는 같은 시드면 같은 `data/profiles.json`을 바이트까지 다시 만들고 `--check`로 그걸 확인한다. 생성 문장을 같은 파일에 쓰면 그 검사가 깨진다. 게임은 `applyProfileLines`로 두 파일을 합쳐 읽는다. 이미 채워진 줄은 다시 만들지 않고 덮어쓰지도 않는다.

```json
{
  "version": 1,
  "lines": {
    "p_001": { "line": "...", "model": "모델 이름", "prompt_version": "profile-line-v2", "generated_at": "2026-10-05T12:00:00.000Z" }
  }
}
```

## 실행

저장소 루트에서 Node.js 22.18 이상으로 실행한다. `s1/`에서는 `npm exec --offline -- tsx tools/gen_text.ts ...`로도 된다.

```sh
# 요청만 만들어 본다. 키와 모델이 없어도 되고 네트워크를 쓰지 않는다.
node s1/tools/gen_text.ts --dry-run --limit 1

# 실제로 생성해 화면에만 보여 준다(파일은 그대로).
GEMINI_API_KEY=... GEMINI_MODEL=모델이름 node s1/tools/gen_text.ts --limit 5

# 통과한 줄을 저장한다.
GEMINI_API_KEY=... GEMINI_MODEL=모델이름 node s1/tools/gen_text.ts --limit 5 --write
```

| 옵션 | 뜻 |
|---|---|
| `--dry-run` | 요청 본문만 출력한다 |
| `--write` | 통과한 줄을 `--out` 파일에 더한다. 없으면 미리보기만 한다 |
| `--limit N` | 한 번에 채울 항목 수. 기본 5, 최대 200 |
| `--max-attempts N` | 항목마다 다시 요청하는 최대 횟수. 기본 3 |
| `--model 이름` | 모델 이름. `GEMINI_MODEL`보다 우선한다 |
| `--profiles 경로`, `--out 경로` | 입력과 출력 파일. 출력은 `s1/` 안으로 제한한다 |

## 키와 비용

- 키는 환경변수 `GEMINI_API_KEY`로만 받는다. 명령줄 옵션으로 받지 않는다(셸 기록에 남는다). 요청 주소가 아니라 `x-goog-api-key` 헤더로만 보내고, 오류 메시지에서는 `***`로 가린다.
- 모델 이름과 한도는 `GEN_TEXT_CONFIG` 한 곳에 있다. 콘텐츠 가이드는 'Gemini 4.0'을 쓴다고 적었지만 API에서 쓰는 정확한 모델 이름은 확인하지 못해 기본값을 두지 않았다. 실행할 때 `GEMINI_MODEL`로 정한다.
- 요청은 한 항목씩 차례로 보낸다. 기본 한도는 5개다.

## 요청과 검사

- 고정 지시: 콘텐츠 가이드 2장의 문체, 세계관의 금기, 쓰지 않는 것을 줄여 넣었다. 프로필 한 줄은 3인칭 현재형 한 문장으로, 물건이나 습관 하나를 보여 주게 했다.
- 데이터: 가이드 3.5가 허락한 필드(이름, 나이, 공동체, 고향, 탄 경위, 좋아하는 것, 싫어하는 것)만 넘긴다.
- 예시: 가이드 3.2의 두 인물만 넣는다. 다른 작품의 대사는 넣지 않는다.
- 출력: `{"line": "..."}` JSON 하나만 받는다(`responseMimeType: application/json`).
- 저장 전 검사: JSON 형식, 40자, 줄바꿈, 한 문장, 이름·나이 되풀이 금지, 그리고 A1 검사기(`validateContent`)의 `line` 진단. 경고도 거절로 본다. 거절되면 이유를 붙여 다시 요청하고, 횟수를 넘기면 저장하지 않고 이유를 출력한다.

## 확인

`npm test`(s1/)의 `tests/gen_text.test.ts` 13개가 가짜 응답으로 돈다. 네트워크와 실제 키를 쓰지 않는다. 요청 조립, 거절과 재요청, 횟수 제한, 덮어쓰기 금지, 키 가리기, 드라이런, `--write` 없는 미리보기, 출력 경로 제한을 확인한다.

## 드라이런 예시

`node s1/tools/gen_text.ts --dry-run --limit 1`의 첫 요청에서 사용자 부분만 옮겼다. 고정 지시(`systemInstruction`)는 `gen_text_prompt.ts`에 있다.

```text
[예시: 콘텐츠 가이드 3.2]
수석 기관사: 헨리크 마주레크(Henryk Mazurek), 67세, 볼슈틴 출신, 기관실 대표. …
꼬리칸 대표: 파블라 크레이치(Pavla Krejčí), 41세, 브르노 출신, 꼬리칸 대표. …

[프로필 한 줄 예시: 콘텐츠 가이드 3.2]
- 기술·의무진: 빈 약병도 씻어서 선반에 세운다.
- 기관실: 석탄 냄새가 남은 장갑을 찾는다.
- 꼬리칸: 해빙기에도 낡은 털장갑을 챙긴다.

[이번 항목]
{
  "이름": "알기르다스 유레비추스",
  "나이": 20,
  "공동체": "꼬리칸",
  "고향": "빌뉴스, 리투아니아",
  "탄_경위": "나중에 태운 피난민이다",
  "좋아하는_것": "조개 수프",
  "싫어하는_것": "고장 난 지퍼"
}

[출력 형식]
{"line": "40자 이내 한 문장"}
```

## 남은 문제

- 실제 Gemini 호출은 해 보지 않았다. 요청 형식은 Gemini REST `generateContent`를 따랐고 테스트는 가짜 응답으로만 돈다. 모델은 Gemini 4.0으로 정했고(2026-10-06), 공개되면 API 모델 이름을 `GEMINI_MODEL`에 넣고 `--limit 1`부터 돌린다.
- 가이드 3.2에 B7 노트의 창작 예문 셋을 프로필 한 줄 예시로 넣었다(2026-10-06, `profile-line-v2`). 셋 중 둘이 장갑이라 지시에 '예시의 물건을 그대로 쓰지 않는다'를 더했다. 첫 실행에서 장갑이 되풀이되는지 본다.
- 같은 공동체 사람들의 줄이 서로 비슷해지는지는 실제 생성 뒤에 사람이 본다.
