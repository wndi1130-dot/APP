# 어두운 길 초안 비판

검토일은 2026-10-07이다. 지정한 네 파일을 대조한 읽기 전용 검토다. 원본 수정과 실행 시험은 하지 않았다.
아래 인용은 짧은 직접 인용이다. 나머지는 검토자의 요약과 수정 제안이다. 계산에 가정이 들어가면 ‘추정’으로 표시한다.
‘확정과 충돌’은 기존 결정과 다른 설계다. ‘확정 변경 제안’은 채택하려면 기존 결정을 따로 바꿔야 하는 안이다. 숫자와 미확정 제안 사이의 차이는 확정 위반으로 세지 않는다.

## 1. 한눈 요약

- 수사 확률은 최대 120%가 된다. 헛단서도 확정 증거가 되어 오판 없는 처벌로 이어질 수 있다.
- 완주 우위 10%p 허용선은 기존 9%p 우위를 그대로 통과시킨다. 새 숫자가 문제를 풀었다는 근거는 없음이다.
- 탄압은 물자보다 뒤늦은 관계 손실을 주로 쓴다. 판 막바지에는 대가를 피하기 쉬워 보인다(추정).
- 자동 처벌의 책임을 법 통과 1점으로만 세면, 반복된 피해와 ‘깨끗했다’는 결말이 함께 나올 수 있다.
- 임박 뒤 경비 배치가 무엇을 막는지 불명확하다. 확실한 예고와 불확실한 분위기도 같은 징후 틀에 섞인다.
- 재판·위기 법·대권 연장과 여러 기한이 충돌한다. 비상 소집만으로 모두 해결되는 구조는 아니다.
- 사건 표는 세는 방식에 따라 35종 또는 41종이다. 이동 카드 두 장 제한은 전체 결정 수를 제한하지 않는다.
- 집단 대상 탄압의 경계와 외부인 의심의 반복을 다듬어야 한다. 비밀 투표와 일대기 톤은 확정 사항과도 대조해야 한다.

## 8. 초안에서 잘된 점: 그대로 둘 것

- 폭력의 결과를 빈 자리·붕대·목격자의 말로 남기는 방향은 유지한다(s1b_dark_path_d81bb12.md:52, 427–449).
- 이름·장소·구간과 살아 있는 목격자를 기록하고, 추모의 벽에 같은 글씨로 남기는 원칙은 유지한다(s1b_dark_path_d81bb12.md:427, 448–457).
- 뒷정치의 실행자가 약점을 쥐고 승계가 문제를 이어받는 구조는 유지한다(s1b_dark_path_d81bb12.md:257–258).
- 새 단계 대신 기존 회기와 서류 자리에 사건을 넣고, 유품과 밤샘을 합치는 방향은 유지한다(s1b_dark_path_d81bb12.md:86, 414).
- 사실성과 창작의 근거를 구분하고, 거주 공간과 출신 집단에 대한 민감한 선을 명시한 점은 유지한다(s1b_dark_path_d81bb12.md:17, 49–53, 367).

## 9. 확인 못 한 것

- 새 수단을 포함한 완주·반란·쿠데타·피해 빈도의 실행 결과는 제공 파일에서 찾지 못했다. 근거: 없음이다. 수치 조정은 완료되었다고 판단하지 않는다.
- 실제 코드의 단서 추첨, 사건 취소, 안건 우선순위와 대권 종료 처리는 확인하지 않았다. 코드 경로와 상태에 대한 초안의 진술을 실행 사실로 확정하지 않는다.
- 문장 풀, 사건 데이터와 새 일대기의 실제 출력은 읽을 대상에 없었다. 문장 중복률, 의미 반복률과 금지 표현의 검사 결과는 없음이다.
- 모바일 가로 실화면, 글자 크기, 선택지 밑줄, 스크롤과 내정 소요 시간은 확인하지 않았다. 새 화면 하나가 부담을 줄인다는 효과도 미확인이다.
- 단서·추모·계엄 해제 뒤의 세계 기록과 가족 상태가 저장되는지도 확인하지 않았다. 본 검토는 제공된 설계 문서에 대한 판단이다.
- 실제 연령 등급 판정과 역사적 사실의 독립 검증은 하지 않았다. 다른 게임의 대사나 외부 문헌을 인용하지 않았다.
- 집단을 겨냥한 폭력의 신규 제안은 하지 않았다. 특정 민족·종교·국적과 도난·암거래·소문·질병을 연결한 근거는 지정 초안에서 찾지 못했다. 해당 연결: 없음이다.
