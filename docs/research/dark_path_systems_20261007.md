**개인에 대한 처벌의 표현**

[2차] 마지막 법 뒤 생기는 처형대는 도시 안 시설이고, 버튼은 특정 개인을 플레이어가 지정하기보다 임의 시민을 대상으로 하며 시설 정보창에 처형된 시민과 죄목 목록을 남긴다고 설명된다. [처형대][S27]

[2차] 처형대가 화면 안에 존재한다는 점은 확인되지만, 실제 실행 애니메이션의 세부와 모든 모드의 동일 연출은 확인 못 함이다. [처형대 설명][S27]

**우리 게임에 쓸 점**
