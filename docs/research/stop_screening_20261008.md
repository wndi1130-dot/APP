# 캠페인 정차 후보 거르기 (2026-10-08, first_leg_story 8.1 기준, 조사 기록)

판정 규칙: 루나 '뺌' → 뺌. 루나 '뺌(불확실)'과 위키 문서 낱말 신호가 함께 있으면 → 뺌. 둘 중 하나만 있으면 → 뺌(불확실). 둘 다 없으면 → 통과. 둘째 모델은 첫 답이 36곳 모두를 뺌 또는 뺌(불확실)로 적고 PARTIAL로 끝나 판정에 쓰지 않았고, 고친 질문지로 다시 묻는 중이다. 이유와 내용은 적지 않는다(first_leg_story 8.1).

## 나머지 물음

- (라) 'Uckermark' 지역 이름표: 두 모델 모두 안 쓰는 게 낫다. 대신 '브란덴부르크 북동부'(8.1의 '브란덴부르크 북부' 표기와 같은 결).
- (마) 파제발크 기관고만 쓰기: 파제발크가 위 판정에서 빠지므로 따로 정하지 않아도 된다(두 모델 의견은 갈림).
- (바) 루브민 발전소: 냉각탑 없음. 바다에서 열린 수로로 냉각수를 받던 방식이다. [독일어 위키 '냉각' 절](https://de.wikipedia.org/wiki/Kernkraftwerk_Greifswald), [GRS 기술보고서](https://www.grs.de/sites/default/files/2024-10/GRS-083.pdf). 다만 루브민 지선은 위에서 뺌(불확실)이다.
- 프렌츨라우–파제발크 사이 작은 역: Nechlin(두 모델 모두 골랐고 신호 없음, RE3 시간표에 정차역으로 나옴).
