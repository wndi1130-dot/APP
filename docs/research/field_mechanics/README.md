## 표시

- **[1차]** 개발사 블로그·공식 문서·소스 코드·논문 같은 원출처.
- **[1차·공식 위키]** PZwiki처럼 개발사가 인정한 위키. 빌드 번호를 같이 적는다.
- **[1차·레거시]** 원출처지만 옛 빌드 기준이라 지금과 다를 수 있다.
- **[2차]** 팬 위키·기사·포럼 요약.
- **[미확인]** 링크가 자동 접속을 막아 이 정리 단계에서 원문을 열어 보지 못했다. 내용은 워커 답 그대로다.
- **원문 대조** 이 정리 단계에서 해당 수치를 원문과 직접 맞춰 봤다.
- **[제안]** 우리 게임에 어떻게 쓸지에 대한 워커 또는 정리자의 안. 결정이 아니다.

## 링크 확인 상태 (2026-10-07)

- graphics.md의 출처 31개는 모두 열렸다.
- animation.md는 언리얼 문서 하나(403)를 빼고 모두 열렸다.
- weapons.md는 PZwiki·팬덤·DayZ 포럼·Medium·army.mil이 자동 접속을 막았다. PZwiki의 B-F 권총, Tired, Endurance, Build 42.1.0 수치는 브라우저로 원문을 열어 맞춰 봤다. 나머지는 [미확인]으로 남겼다.

## 원문을 두는 곳

워커 질문과 답 원문은 공개 저장소에 올리지 않고 사용자 컴퓨터에만 둔다. 이 폴더는 그 답을 우리말로 줄이고 출처 링크를 붙인 메모다.
