# S1c 내정 3. 쟁기 값 숫자 비평 (2026-10-08)

근거: 코드 4ba1025, 문서 main 6ee9794
묻은 곳: 코덱스(높은 추론), 읽기 전용
물음: 부품 0~3과 '모자라면 석탄 +1·1시간 늦음'이 너무 싼지 비싼지, 판당 몇 번 미는지, 망자 10/30 구간이 무리 밀도와 맞는지
제 한 줄 판정: 부품 쪽은 적당하고, 부족분 값(석탄 +1)이 싸서 '부품 없이 계속 밀기'로 기울 위험이 있다는 판정이다. 판당 4~5번은 모델 추정이다. 10/30과 밀도 단계 연결은 아직 없다.

---

판정: 부품 1·2·3은 수리 1회(2개)·복원(2·4·8개)과 경쟁하므로 지나치게 싸지는 않다. 다만 부족분을 석탄 +1·지연 1시간으로 넘기는 길은 (가) ‘부품 없이도 계속 밀기’로 기울 위험이 있다. 석탄 +1은 기본 달리기 6의 약 17%이며, 지연의 실제 손실은 미확인이다. (main `docs/design/briefs/s1c_domestic.md:264–270,391`; 코드 `s1/src/game/data.ts:18`)
(나) ‘늘 기다리기’ 가능성은 낮다. 기다릴수록 무리가 늘고 정차 열차도 공격받으므로 대기가 공짜 대안은 아니다. 선로에 닿기 전 조기 출발은 부품 0이라, 핵심 선택은 더 파밍할지 떠날지다. (main `docs/design/briefs/zombies.md:9`; `docs/design/briefs/s1c_domestic.md:393`)
횟수는 **추정: 24구간·약 20정차 한 판에서 유료 돌파 4~5회**를 기준으로 잡겠다. 문서의 부품 최대 공급 34−통상 지출 25=여유 9개를 평균 2개씩 쓰는 계산이며, 장갑·추가 복원을 택하면 줄고 부족분 전환을 감수하면 늘어난다. 출발 시 망자 수 분포가 없어 실제 빈도 예측은 아니다. (main `docs/design/briefs/s1c_domestic.md:758–772,395`)
10/30은 밀도 단계와 **아직 수치로 연결되지 않았다**. 배경은 ‘고요·흩어짐·가득’과 예보로 정하지만 쟁기는 출발 시 선로 위 개체 수로 계산한다. ‘고요=0, 흩어짐=1~10, 가득=11 이상(31 이상은 큰 무리)’을 출발 장면의 표시 규칙으로 붙이는 안이 자연스럽다. (main `docs/design/briefs/presentation_motion.md:555`; `docs/design/briefs/s1c_domestic.md:383–388`; `docs/design/briefs/zombies.md:111`)
숫자 안: **부품 0·1·2·3과 경계 10/30은 유지**, 부족분 1개당 **석탄 +2·지연 1시간(최대 +6·3시간)**을 비교 시험하자. 이는 부품 고갈 뒤 돌파에도 자원 부담을 남기려는 제안이며 검증값은 아니다. S1에는 돌파가 없으므로 현재 코드로 플레이 균형을 확정할 수 없다. (main `docs/design/briefs/s1c_domestic.md:391–395`)
