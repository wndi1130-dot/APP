# J06 새 P11 그림 점검: 열차장 인상과 금지선 (2026-10-08)

대상: 3D 스레드 P11 그림 여섯 장(M7c v3·v4, M7b v7·v8, M8 v3·v4)과 비교용 지금 PICK(M8 v2). 그림은 저장소에 올리지 않고 사용자 바탕화면에만 둔다.
묻은 곳: 코덱스(높은 추론), 그림 입력. 웹 GPT는 이 통로에 그림 입력이 없어 묻지 못했다(미확인).
제가 직접 연 것: M8 v3·v4·PICK의 4·5·6칸 원본 크기 잘라 낸 것, M7c v3, M7b v7. M7c v4와 M7b v8은 코덱스 판정만 있다.

## 1. 눈 가림 인상 검사 (게임 설명 없이 물음)

물음: 4칸 앞 인물과 6칸 가운데 인물이 무엇으로 먼저 읽히나(군인, 장교, 경찰, 철도원, 민간인), 무엇 때문인가, 셋 중 가장 덜 군인 같은 것은.

| 그림 | 코덱스 | 제 판단 | 웹 GPT |
|---|---|---|---|
| M8 v3 (챙 모자 + 회색 외투) | 4칸 장교 / 6칸 장교. 각진 챙모자가 정모로, 넓은 옷깃과 단추가 장교복으로 읽힘 | 4칸 장교 또는 철도원. 모자 앞에 둥근 금빛 표식과 금단추가 있다(원본 크기에서 보임). 이 표식이 모표로 읽혀 금지선에 걸린다 | 미확인 |
| M8 v4 (털모자 + 목도리) | 4칸 민간인 / 6칸 민간인. 털모자·목도리·방한 외투, 가죽띠 없음 | 4칸 민간인 / 6칸 민간인. 같은 판단 | 미확인 |
| M8 v2 PICK | 4칸 장교 / 6칸 장교. 대각선 가죽띠, 버클 허리띠, 두 줄 단추 | 6칸 장교. v3과 같은 챙모자 실루엣 | 미확인 |

가장 덜 군인 같은 그림: 코덱스와 제 판단 모두 M8 v4(털모자).

모자를 바꿔도 남는 것(두 판단 같음): 4칸 오른쪽 동행 인물은 납작모자, 허리띠를 맨 긴 외투, 가슴 띠, 소총을 들고 있어 v3·v4·PICK 모두에서 군인 인상을 남긴다. 6칸 오른쪽 칸 문간에 소총을 들고 선 인물도 세 장 모두 같다.

## 2. 금지선 점검 ('걸리는 것 | 어디')

### 내 점검

| 그림 | 걸리는 것 | 어디 |
|---|---|---|
| M8 v3 | 모표 | 4칸 앞 인물 챙모자 앞 둥근 금빛 표식 |
| M8 v3·v4·PICK | 군복(애매) | 4칸 오른쪽 동행 인물: 허리띠 맨 긴 외투, 가슴 띠, 소총 |
| M8 v3·v4·PICK | 무장 감시로 읽힐 틈(애매) | 6칸 오른쪽 칸 문간에 소총 들고 선 인물이 회의하는 칸을 지키는 모양 |
| M8 v3·v4·PICK | 사람 탄 칸이 화차로 읽힐 틈(애매) | 6칸 잘라 본 칸이 창 없는 판자벽이라 객차보다 화차처럼 보임 |
| M8 v3·v4, M7b v7·v8 | 망루(애매) | 다리 달린 나무 급수탑(M8 5칸 왼쪽 위, M7b 왼쪽 위). 계단 달린 높은 초소(M8 5칸·M7b 오른쪽)는 신호소로 읽힐 가능성이 더 크다 |
| M8 5칸, M7b v7 | 철조망(애매) | 왼쪽 나무 말뚝 울타리의 가는 가로선. 바깥 방어선 자리라 허용 범위일 수 있음 |
| M7c v3 | 별(애매) | 오른쪽 아래 바닥 표시 타원 안 흰 표식. 이동 표시 아이콘으로 읽힘 |
| M7b v7 | 휘장(애매) | 왼쪽 두 번째 초상 아래 방패 아이콘 |

보지 못한 것(걸림 없음): 연기 나는 건물 굴뚝(M7c 왼쪽 건물 굴뚝에 연기 없음), 냉각탑, 멈춘 열차의 곧은 연기 기둥(M7c 기관차 김은 바퀴 높이로 낮게 퍼짐), 사람 탄 칸의 사슬·빗장·쇠창살, 승강장 가방·신발 무더기, 아이 얼굴 가까이 그림. 석탄 싣기(M7b 위쪽 무개화차)는 허용된 짐이다.

### 갈린 곳

- M8 v3 모표: 코덱스는 '애매', 저는 '걸림'. 원본 크기 잘라 본 것에서 둥근 금빛 표식이 모자 앞에 분명히 보인다.
- 6칸 문간 소총 인물: 코덱스는 v3에서만 복장을 짚었고, 저는 v3·v4·PICK 모두 '무장 감시' 인상으로 본다.
- 6칸 판자벽 칸: 코덱스는 짚지 않았다. PICK에도 같은 모양이라 새 그림만의 문제는 아니다.
- 망루: 코덱스는 계단 달린 초소를, 저는 다리 달린 급수탑을 더 걸리는 쪽으로 봤다. 둘 다 '애매'.
- M7b v8의 방패 아이콘: 코덱스는 v8엔 적지 않았다(제가 v8을 열지 않아 대조 못 함).

## 3. 열차장 모자 카드에 주는 것

- 털모자(M8 v4)가 두 판단 모두에서 가장 민간인으로 읽힌다. 챙 모자(v3)는 모표가 남아 있어 지금 그림 그대로는 금지선에 걸린다.
- 어느 모자를 고르든 4칸 동행 인물과 6칸 문간 인물의 소총·띠는 따로 손봐야 군인 인상이 빠진다(예: 총을 등에 메게 하거나 등불·도끼로 바꾸기, 가슴 띠 빼기). 이건 제 제안이고 모델에 묻지 않았다.
