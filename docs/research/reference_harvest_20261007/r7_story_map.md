# 레퍼런스 수집: 이야기와 지도

> 이 영역 레퍼런스 40개. 웹 수집 결과에서 인용 표지만 지웠다. 링크 하나(파제발크 기관고 페이지, 리초 급수탑 사진 라이선스)를 직접 열어 줄의 주장과 맞는지 확인했고, 나머지 링크와 라이선스 표기는 쓰기 전에 다시 확인한다. 그림·음원 파일은 저장소에 넣지 않고 링크만 둔다. 이 문서는 조사 기록이며 확정 사항이 아니다.

## 1. 레퍼런스 표

노선의 작업가설은 **라이프치히 → 비터펠트 → 루터슈타트 비텐베르크 → 위터보크 → 베를린 → 에버스발데 → 앙거뮌데 → 프렌츨라우 → 파제발크 → 앙클람 → 그라이프스발트 → 슈트랄준트 → 뤼겐**으로 둔다. 베를린 북쪽에는 **노이슈트렐리츠·노이브란덴부르크를 거치는 대체 축**도 비교할 수 있다. 이는 지역 간 연결을 잡는 초안이며, 증기기관차의 도심 통과 경로와 각 시설의 인입선까지 검증한 운행 경로는 아니다.
