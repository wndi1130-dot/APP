> 이 영역 레퍼런스 40개. 웹 수집 결과에서 인용 표지만 지웠다. 링크 하나(Google Play 목표 API 문서(2026-08-31부터 API 36))를 직접 열어 줄의 주장과 맞는지 확인했고, 나머지 링크와 라이선스 표기는 쓰기 전에 다시 확인한다. 그림·음원 파일은 저장소에 넣지 않고 링크만 둔다. 이 문서는 조사 기록이며 확정 사항이 아니다.

## 2. 이 영역에서 추가로 할 것

실제 작업 목록을 열람한 것은 아니므로 아래는 **누락 여부를 대조할 추가 작업 후보**이다. ‘먼저’는 대량 콘텐츠 제작이나 외부 테스트 전에 착수할 일이며, ‘나중’은 해당 기능·배포 단계가 정해진 뒤 마무리할 일이다. 분량·시험 시간의 예시는 이 프로젝트에 대한 제안값이다.

| 번호 | 우선순위 | 추가할 작업 | 완료 기준 | 연결 레퍼런스 |
|---|---|---|---|---|
