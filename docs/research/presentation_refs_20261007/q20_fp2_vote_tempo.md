# 프로스트펑크 2 개표 박자와 열차 식당칸 의회 초안

> 의회 장면을 직접 확인한 영상 수: 1개. 그 영상을 보고 박자를 적은 정리다. 조사 상태: PARTIAL. 초 단위 수치는 영상 시점 링크로 다시 확인한다. 그림·영상·음원 파일은 저장소에 넣지 않고 링크만 둔다. 이 문서는 조사 기록이며 확정 사항이 아니다.

조사일은 2026-10-07이다. 머리말의 영상 수는 의회 장면의 실제 프레임을 확인한 수이다. 끝까지 확인하고 단계별 길이를 실측한 표결은 0회이다. 공식 영상 두 개와 플레이 영상 한 개를 주요 대상으로 찾았으나, 세 영상의 표결을 처음부터 끝까지 재는 조건은 충족하지 못했다. 아래에서는 **프레임 관찰, 자막 시간, 설명·리뷰의 서술, 설계 제안**을 구분한다.

## 1절 한눈 요약

- 공식 협상 영상의 0:50에서 법안, 협상 대상, 찬성·보류·반대의 사전 분포를 확인했다.
- 리뷰는 표가 들어오는 과정을 보여 주며 긴장을 만든다고 설명한다. 표 공개의 단위·속도·멈칫은 확인 못 함이다.
- 공식 의회 영상의 자막 시각은 확보했으나, 해설 구간의 길이를 개표 애니메이션의 길이로 환산하지 않았다.
- 근소·압도·통과·부결의 화면 및 소리 차이와 반복 때의 실제 단축은 확인 못 함이다.
- 식당칸 초안은 대표 다섯 명, 각 1표, 통과에 3표가 필요한 가정으로 평온 8초·보통 10초·난장판 12초를 제안한다.
- 이 초 수치는 새 장면의 설계값이며, 프로스트펑크 2에서 실측한 값이 아니다.

## 3절 표 공개 방식과 근소·압도·부결 차이

공식 협상 영상의 **0:50에서 확인한 것은 원형 의회 배치와 중앙의 찬성 37·보류 37·반대 26이라는 사전 분포**이다. 법안과 협상 대상이 함께 표시되어 있다. 이는 집단의 현재 입장을 전달하는 화면이라는 관찰이며, 실제 표가 공개되는 애니메이션을 확인했다는 뜻은 아니다. [공식 영상 0:50](https://www.youtube.com/watch?v=qZcLb3ceacs&t=50s)

[GMA Gaming의 리뷰](https://gmagaming.com/2024/10/03/frostpunk-2-review/)는 표가 들어오는 과정을 보여 주는 기능이 긴장을 높인다고 설명한다. 따라서 점진적 공개가 긴장에 기여한다는 해석은 리뷰 근거가 있다. 의석 한 개마다 표가 바뀌는지, 집단별 묶음으로 처리되는지, 계수 표시가 같은 속도로 움직이는지는 이 설명만으로 확정할 수 없다.

|---|---|---|
| 진영별 덩어리 이동 | 0:50에서 집단별 협상 상태와 원형 의회 배치를 확인했다. | 진영 전체가 동시에 움직이거나 한 덩어리로 투표하는지는 확인 못 함이다. |

| 막대·저울·숫자의 증가 | 중앙에 찬성·보류·반대 숫자와 색 표시가 있다. | 공개 중 막대가 차오르는지, 저울이 움직이는지, 숫자의 갱신 간격이 일정한지는 확인 못 함이다. |
| 동점 부근의 멈칫 | 특정 접전이 흥미로웠다는 영상 제작자의 설명이 있다. | 임계점에서 의도적으로 지연하는지, 실제 표차가 얼마였는지는 확인 못 함이다. |
| 군중음·망치·종·음악 | 공식 자막은 협상과 사회적 긴장 상승을 설명한다. | 첫 표·과반 확보·마지막 표·결과 문구와 소리가 맞물리는 시점은 모두 확인 못 함이다. |

근소한 통과와 압도적인 통과의 실제 공개 시간, 카메라 변화, 환호의 크기를 비교할 수 있는 두 표결은 확보하지 못했다. 부결 사례의 전 과정을 확인한 영상도 확보하지 못했다. 같은 영상 안에서 반복되는 여러 표결의 비교는 확인 못 함이다. 접전의 제작자 소감을 게임의 별도 접전 연출이 존재한다는 근거로 사용하지 않는다. [접전 언급이 있는 플레이 영상](https://www.youtube.com/watch?v=bYgdeALB52s)

식당칸에 옮길 때 가져올 수 있는 방향은 **결정 전에 거래의 대가를 보이고, 결정 중에는 표가 드러나는 과정을 읽게 하는 것**이다. 거래의 존재는 리뷰와 공식 해설로 뒷받침되며, 다섯 표를 어떤 간격으로 공개할지는 새 장면의 설계 문제이다. [GMA Gaming 리뷰](https://gmagaming.com/2024/10/03/frostpunk-2-review/), [공식 의회 영상의 협상 설명 1:22](https://www.youtube.com/watch?v=Lk-A9pOTDqw&t=82s)

## 4절 반복 때 줄이기

프로스트펑크 2가 반복 횟수에 따라 자동으로 개표 시간을 줄이는지는 확인 못 함이다. 편집된 소개 영상이 짧게 보이는 사실로 실제 게임의 반복 단축을 판정할 수 없다.

[2024년의 표결 애니메이션 건너뛰기 토론](https://steamcommunity.com/app/1601580/discussions/0/4853281437087884081/)의 검색 발췌에는 스페이스 키로 건너뛸 수 있다는 이용자 보고가 있다. 원문 페이지는 콘텐츠 확인 화면까지만 열렸고 댓글 본문은 직접 확인하지 못했다. 그러므로 이는 **검색 발췌에서 확인한 이용자 보고**이며, 실제 작동이나 2026-10-07의 게임 버전에서 같은 기능이 유지되는지는 확인 못 함이다.

식당칸에서는 다음 단축안을 제안한다. 아래 시간은 모두 설계값이다.

| 상황 | 제안하는 재생 방식 | 시간과 남길 정보 |
|---|---|---|
| 첫 표결 또는 새 공동체의 첫 참가 | 5절의 전체 박자를 사용한다. | 사회 상태에 따라 8·10·12초이다. 공동체 이름과 표 방향을 모두 보여 준다. |
| 익숙한 일반 표결 | 사용자가 짧은 연출을 선택할 수 있게 한다. | 시작 0.4초, 다섯 표 공개 1.5초, 결과 0.7초, 반응 0.4초로 합계 3초이다. |
| 즉시 결과 보기 | 결과 확정 후 공개 연출을 건너뛴다. | 다섯 공동체의 표와 합계·통과 여부를 한 화면에 표시한다. 결과 화면은 사용자가 닫을 때까지 유지한다. |
| 접전·큰 약속이 걸린 표결 | 전체 박자를 기본으로 제시하되 단축 선택은 유지한다. | 표결의 중요성을 이유로 매번 강제 대기시키지 않는다. 약속의 내용은 결과 화면에서도 다시 읽을 수 있게 한다. |

표 공개를 건너뛰어도 각 공동체의 최종 입장과 거래 기록은 남겨야 한다. 자동으로 결과 화면까지 닫는 방식은 표차와 관계 변화를 읽기 어렵게 만든다. 이는 모바일 장면의 사용성에 관한 설계 제안이다.

## 5절 우리 식당칸 의회 박자표 초안 세 종류

**아래 모든 초 수치는 설계 제안이며, 실제 체감에 대한 추정값이다. 영상에서 잰 값은 없다.** 대표 다섯 명이 각 1표를 가지며, 찬성 3표 이상이면 통과하는 가정을 둔다. 공동체마다 표의 무게가 다르다면 합계와 통과 기준을 별도로 설계해야 한다.

법안 읽기와 흥정은 플레이어가 끝낼 때까지 기다린다. 따라서 이 두 단계의 길이는 고정하지 않는다. 법안 카드에는 효과와 비용을, 협상 화면에는 요구 사항과 약속의 대가를 제시한다. 아래의 **0.0초는 거래가 끝난 뒤 ‘표결 시작’을 누른 순간**이다. 8·10·12초는 그 뒤 마지막 반응까지의 길이이다.

폰 화면에는 공동체 이름이 붙은 대표 카드 다섯 개를 두 줄로 배치하고, 상단에 찬성·반대 합계를 고정한다. 공개된 표는 색, 찬성·반대 글자, 표식으로 함께 표시한다. 표가 공개될 때마다 해당 카드만 강조하며, 대표의 얼굴이나 식당칸 반응은 합계를 가리지 않게 한다. 기관·바퀴·차체의 낮은 소리는 모든 사회 상태에서 공통으로 이어진다.

기본 초안에는 인위적인 동점 정지를 넣지 않았다. 접전의 멈칫을 시험하려면 실제로 네 표까지 2 대 2가 된 경우에만 다섯 번째 표 직전 0.5초를 추가하는 변형을 제안한다. 그러면 전체 길이는 각각 8.5·10.5·12.5초가 된다. 공개 순서는 사전에 정하며, 접전을 만들 목적으로 표나 순서를 바꾸지 않는다. 이는 별도 체감 시험을 위한 설계 제안이다.

## 6절 못 연 것, 못 찾은 것

- **세 영상의 표결 전 과정과 초 단위 실측을 확보하지 못했다.** 직접 확인한 의회 프레임은 공식 협상 영상의 0:50 한 지점이다. 단계 경계를 추정해 숫자로 채우지 않았다.
- 공식 협상 영상에서 1:00 이후로 이동할 때 재생 오류가 반복되었다. 공식 의회 영상도 탐색 뒤 오류가 발생했고, 다른 재생 경로에서는 이동·캡처 요청이 응답하지 않거나 시간 제한에 걸렸다. 재생기 시각 표시만 바뀐 상태를 정상 프레임으로 인정하지 않았다.
- [공식 게임플레이 트레일러](https://www.youtube.com/watch?v=PWlLOpqIYjA)도 열었다. 전체 길이 2:07과 도시 프레임은 확인했으나 의회 표결 전 과정은 확인 못 함이며, 본 의회 영상 수에 포함하지 않았다.
- 공식 영상 두 개의 설명과 시각별 자막은 열람했다. 공식 의회 영상의 0:44·0:54·1:22를 실제 개표 단계의 시작으로 사용하지 않았다. 자막은 표 공개 단위, 군중음 크기, 망치·종, 음악 상승의 시점을 알려 주지 않았다.
- 접전을 언급한 플레이 영상은 검색의 제목·채널·공개일·설명까지 확인했다. 원문 페이지의 직접 열람과 실제 표차·통과 문구·표결 시각은 확인 못 함이다.
- 압도적 통과, 근소한 부결, 압도적 부결의 연속 표결 사례와 같은 영상 안의 반복 표결 비교는 확보하지 못했다. 이 사례가 존재하지 않는다는 뜻은 아니다.
- 스페이스 키로 건너뛴다는 내용은 검색 발췌의 이용자 보고이다. 원문 댓글 열람, 실제 조작, 최신 버전 유지 여부는 확인 못 함이다.
- 영상·음원·자막 파일은 내려받지 않았다. 화면 캡처는 확인용으로만 쓰고 저장소에 넣지 않았다. 직접 청취와 실제 게임에서의 재현 검증은 수행하지 못했다.
- 5절의 평온·보통·난장판 박자표는 사용할 수 있는 설계 초안이다. 프로스트펑크 2의 실측을 재현한 표로 취급하면 안 된다.
