# 건물 꼴 카드 (결정 478: 용도와 지역에 따라)

겉에서 읽히는 꼴이 안(용도·뒤질 거리)을 약속한다. 꼴 = 지붕 꼴 · 벽 재질 · 문창 · 덧붙이. 이것을 ① 용도(이름 → 용도 표, 지도에 손으로 쓴 role이 이김: `s2/game/world/building_uses.gd`) ② 지역(지도 갈래 무리, map-layout 확정)으로 고른다. 같은 용도 안에서는 통제된 무작위(색 판·덧붙이 자리·크기). 1단계는 자리·크기·층·방 나누기를 그대로 두고 지붕·벽 재질·문창·덧붙이로만 가른다. 몸체 꼴(ㄱ자·긴 날개)은 2단계.

세는 도구: `s2/tools/building_census.gd`(짓기는 갈래 몇 개씩 `--only=`, 세기는 `--sum`). 결과 `s2/build/building_census/sum_<phase>.md`.

## 지키는 것

지도 발주 공통 글 6장(그리지 않는 것)에 걸리는 꼴은 만들지 않는다. 표지·덧붙이마다 대조한 표는 코디네이터 리뷰 폴더의 꼴 카드에 있다. 굴뚝은 조각만 두고 연기는 없다. 같은 꼴의 긴 건물이 줄지어 서지 않게 길이·색·물매를 섞는다.

## 1단계 차례 (제안)

- 1가 **셰이더·규칙만**: 벽 재질 여섯(회칠·벽돌·세로 판자·가로 판자·통나무·골함석, 돌 기단 띠)을 지역·용도로, 지붕 물매(가파른 박공)·평지붕을 용도로, 굴뚝을 집·산장 용도로. 새 메시 없음, 그리기 호출 그대로.

## 2가 지붕 실루엣

2가의 범위는 지붕 실루엣 넷·지붕창·이웃 같은 꼴 피하기·현황 셈이다. 창 꼴·덧문·간판·현관·베란다·차고 덧붙이·낡음은 뒤 PR에 둔다. `building.gdshader`, 지도 파일, 실내·방·소품 코드는 바꾸지 않는다.

`BuildingForms.pick()`은 기존 `roof`(`gable` 또는 `flat`)를 유지하고 `silhouette`·`dormers`(0~3)를 더 돌려준다. `roof == flat`이면 실루엣도 `flat`이다. 실제 지붕 계획은 `silhouette`를 읽는다. `pick()`의 지붕창 수는 희망 수이며, `plan()["looks"]`에는 경사면에 들어간 실제 수를 남긴다.

|---|---|---|
| 집 / 읍내 | 박공 `gable`, 모임 `hip`, 반모임 `half_hip` | 후보를 같은 비중으로 번호 해시에서 고름 |
| 큰 집 / 읍내 | 위 셋 + 맨사드 `mansard` | **바닥 80칸 이상·2층 이상**을 큰 집으로 가정 |

| 교회 | 가파른 박공 | 기존 1.7 물매 유지 |
| 병원 | 평지붕 `flat` | 기존 규칙 유지 |
| 헛간 | 맨사드 | 아래 약 60°·위 약 20°에 기존 용도 물매 배수 적용 |
| 창고·바깥 창고·차고·정자 | 외쪽 | `store/shed/depot/shelter`, **30칸 이하** |
| 그보다 큰 창고·차고, 일터 | 기존 박공·평지붕 | 기존 평지붕 판정은 병원·160칸 이상 일터·읍내 2층 이상 가게. 큰 차고에 새 평지붕 판정을 추가하지 않음 |
| 지역을 모르는 지도 | 박공, 지붕창 0 | 물매 1.0·기존 칠 유지. 명시된 오르는 옥상은 기존대로 평지붕 |

집·산장 물매에는 기존 표 위에 `0.85 / 1.0 / 1.15 / 1.3` 가운데 하나를 번호 해시로 곱한다. 지붕창은 집·산장·모임·관청의 박공·모임·맨사드, 대표 사각형 긴 변 8 m 이상에서 0~3개다. 위층 있는 집·산장은 0개가 덜 나오게 한다. 좁은 면·모임 끝·맨사드 꺾임·용마루를 넘지 않는 자리만 쓰며, 굴뚝 덮개와 지붕창 볼의 폭·깊이를 피한다. 공간이 부족하면 실제 수가 희망 수보다 적다.

새 조각은 모두 기존 정점색 구역·노출 비트 규약을 쓴다. 지붕 겉은 `roof/1`, 밑·두께는 `wood`, 용마루 덮개는 `metal`, 끝 벽은 `wall`, 지붕창 앞은 `glass`다. 표의 삼각형은 면 정의에서 센 **소스 어림**이며, 실제 값은 Blender가 다시 쓰는 카탈로그로 확인한다.

| 조각 | 구성 | 삼각형 어림 / 상한 |
|---|---|---:|
| `roof_hip_end` | 모임 끝 반 피라미드, 대각 용마루 덮개 | 24 / 40 |
| `roof_half_hip_end` | 박공 위 1/3을 접은 끝 | 32 / 48 |
| `roof_half_hip_wall` | 반모임 아래 사다리꼴 벽 | 12 / 16 |
| `roof_mansard` | 아래 60°·위 20°인 두 번 꺾인 경사면 | 42 / 56 |
| `roof_mansard_end` | 꺾인 오각 벽 | 16 / 20 |
| `roof_shed` | 한 면 지붕과 경사를 따라 닫은 높은 쪽 벽 | 22 / 24 |
| `roof_shed_side` | 외쪽 옆 삼각 벽 | 8 / 12 |
| `roof_dormer` | 작은 박공·앞 유리·옆 볼 | 66 / 100 |

경간 기준은 10 m, 기본 박공은 35°다. 몸통은 길이 방향, 경간은 `k`, 높이는 `k × pitch`로 늘린다. 모임 몸통은 벽 길이에서 경간을 뺀 길이이며, 정사각형은 끝 둘로만 덮는다. 끝 길이에는 처마 내밈을 포함한다. 반모임은 접힌 끝과 아래 벽을 같은 평면에 잇기 위해 끝 방향 내밈을 생략하고 측면 처마는 유지한다. 맨사드는 두 경사의 교점을 역산하여 기준 박공과 같은 중앙 높이로 맞춘다. 외쪽은 전체 경간에 35°이므로 높은 벽 높이는 기준 박공 중앙 높이의 두 배다. 독립 외쪽의 높은 벽은 북쪽, 남북으로 긴 사각형은 서쪽을 기본으로 하고, 다른 사각형이 붙은 날개는 본채 가운데 쪽을 택한다.

ㄱ자·여러 사각형과 높은 층에 붙은 평지붕은 기존 분할 경로를 쓴다. 굴뚝 밑은 해당 실루엣의 겉면 높이에서 0.15 m 묻히고, 지붕창 원점은 겉면 높이에 둔다. 지붕창 높이 배수는 앉는 면의 물매에 맞춘다. 모든 새 조각·끝 벽·굴뚝·지붕창은 `out["roofs"]`로 보내 기존 건물당 지붕 메시 하나에 굽는다. 시야 구멍의 공용 셰이더와 `cut_away`·`near`의 지붕 숨김·그림자 해제 경로를 그대로 탄다.

### 이웃 피하기

첫 판에서 문·창·방이 있어 그리는 건물의 바닥 경계 상자와 꼴을 모두 고른다. 그다음 건물 번호 오름차순으로 바닥 경계 상자 가운데 사이 **24 m 이하**의 이웃을 본다. 서명은 `실루엣 | 물매 급 | 벽 재질 | 색 판:칠 번호`이며, 물매 급은 `<0.9 낮음 / >1.2 가파름 / 나머지 보통`이다. 지붕 색 번호와 지붕창 수는 이웃 서명에 넣지 않는다.

이미 고른 같은 서명 이웃이 둘 이상이면 용도·지역 후보의 다음 실루엣을 순환하고, 그 후보들을 다 쓰면 같은 색 판의 다음 칠 번호를 순환한다. 새 건물이 앞서 고른 이웃의 같은 서명 이웃 수를 셋 이상으로 만드는 경우도 막는다. 비어 있지 않은 같은 `row_group`끼리만 제외한다(필드 없음·빈 문자열은 예외가 아님). 건물 줄 순서를 뒤집어도 선택과 조각 배치는 같다.

후보가 모두 막힌 고밀도 지도에서는 용도 밖 꼴을 만들지 않고 충돌이 가장 적은 후보를 남긴다. 남은 충돌은 `looks[b]["neighbor_conflicts"]`와 현황 셈으로 드러난다. 모든 배치에서 중복을 없앨 수 있다는 보장은 하지 않는다.

### 계기판 칸

같은 `--phase`의 `rows_*.json`에 실루엣·물매 급·실제 지붕창 수·칠 번호·바닥 가운데·`row_group`·서명을 남기고, `--sum`이 아래 칸을 계산한다. `sum_*.md`에는 기존 지역·갈래·용도 표의 새 칸, 전체 표, 지도별 꼴 조합 수를 함께 쓴다. `sum_*.json`은 기존 그룹 사전 형태를 유지하고 각 그룹에 `roof_2a`를 더한다. 같은 지도·건물의 여러 사각형은 한 채로 세며, 겹친 rows 묶음은 지도·번호로 중복 제거한다(파일명 순서상 뒤의 줄을 사용하므로 서로 다른 실행을 같은 phase에 섞지 않는다).

| Markdown 칸 / JSON 필드 | 뜻 | 2가 측정 |
|---|---|---|
| 실루엣 수 / `silhouette_count` | 선택된 실루엣 종류 수 | (부른 세션이 잼) |
| 최다 실루엣 몫 / `dominant_silhouette_share` | 가장 흔한 실루엣 건물 수 / 전체 건물 수 | (부른 세션이 잼) |
| 지도 꼴 조합 가운데값 / `map_form_median` | 실루엣 × 물매 급 × 벽 × 지붕창 유무 조합 수의 지도별 가운데값 | (부른 세션이 잼) |
| 지도 꼴 조합 최소 / `map_form_min` | 위 조합 수의 지도별 최소 | (부른 세션이 잼) |
| 24 m 같은 서명 최대 / `near_same_max` | 자신·같은 row_group을 뺀 같은 서명 이웃 수의 최대 | (부른 세션이 잼) |
| 24 m 셋 이상 건물 / `near_same_ge3_buildings` | 위 이웃이 셋 이상인 건물 수 | (부른 세션이 잼) |

지도 꼴 조합은 용도별 줄에서는 해당 용도 안에서, 전체 표에서는 지도 전체에서 센다. 이웃 수는 용도별 줄에서도 지도 전체의 이웃을 본다. 2가 필드가 없는 예전 rows는 `not_collected`이며 새 수치로 추정하지 않는다.

### 2가 인계 상태

- 목표·끝낸 일: 지정한 소스·시험·문서 7개에 새 조각·꼴 선택·이웃 조정·배치·현황 셈·회귀 시험을 작성했다. 생성 장부(`catalog.json`, 모델 README)와 GLB는 손으로 고치지 않았다.
- 실제 확인: Python 3.13 절대 런타임에서 `-X utf8 -I -m py_compile tools/blender/building_kit.py`로 최종 소스 문법 검사 종료 코드 0. 검사로 만든 캐시와 빈 캐시 폴더는 휴지통에 보냈다. GDScript 시험·Blender 면 법선/삼각형 검사·GLB 생성·Godot 가져오기·그리기 예산·계기판 실행·시각 확인은 `not_run`이다. Markdown 렌더 외형은 `not_verified`다.
- 열린 위험: 새 GLB를 굽기 전에는 새 `PIECES`가 카탈로그에 없어 키트 로더가 상자 대체 경로를 탄다. 꺾임·끝 이음·지붕창 묻힘과 좁은/회전된 사각형은 실제 그림 확인이 필요하다. 노드 경로는 유지했지만 삼각형 총량·지도 계획 시간은 아직 실측하지 않았다. 이 작업 트리에는 `s2/addons/gut`도 없으므로 부른 세션의 시험 환경을 준비해야 한다.
- failure_code: 없음(요청한 소스 작성 범위). 실행 제한으로 남긴 검증은 위의 `not_run`이며 통과로 처리하지 않는다.
- 기록 범위: 최신 발주의 허용 파일 밖인 공용 원장·별도 `00_인계.md`는 쓰지 않고 이 절로 인계를 남긴다. 이 실행은 GUI·외부 호출·설치를 하지 않는다.
- 다음 한 걸음: 부른 세션에서 **Blender 굽기 → Godot 가져오기 → 지정 두 시험·계기판·대표 그림 확인**을 한 검증 단계로 수행하고 위 측정 칸을 채운다.
