# 공용 소품 규격

상위 20종 중 기존 `props_stop01`에 있는 `wardrobe`·`workbench`를 제외한 18종이다. `tools/blender/props_common.py`가 각 `<kind>.glb`와 `catalog.json`·`README.md`를 만든다. 자동 장부는 손으로 고치지 않는다.

한 칸은 1m다. 지도 80개의 원문에서 사전형 rect와 축약 행의 w·h를 함께 세어 최빈 크기를 채택했다. 일부 원문 수는 실행 중 배치 수와 다르므로 전체 소품 점유율의 근거로 쓰지 않는다. 가장 흔한 크기에 동률은 없었다.

| 종류 | 발자국 m | 높이 m | 모양과 크기의 이유 |
|---|---|---|---|
| shelf | 3×1 | 1.8 | 최빈 긴 선반, 네 단 |
| cold_stove | 1×1 | 1.1 | 무쇠 몸통과 짧은 관 포함 |
| desk | 2×1 | 0.75 | 두 칸 책상과 서랍 둘 |
| barrel | 1×1 | 0.9 | 한 칸 나무 통, 쇠 테 둘 |
| bed | 2×1 | 0.5 | 누울 길이는 가로 두 칸, 낮은 머리판 |
| bare_tree | 1×1 | 5.2 | 잎 없이 위로 뻗는 좁은 수형 |
| crate_stack | 2×2 | 1.25 | 상자 셋을 두 단으로 쌓음 |

기준점은 전체 발자국 가운데 바닥이다. Blender X=가로, Z=위, -Y=앞이며 glTF/Godot은 +Y=위, +Z=앞이다. 높이에는 손잡이·관·뚜껑을 포함한다. 가지와 열린 문도 발자국 안에 맞춘다. 지도 rect 가운데 바닥에 놓고 facing 0~3을 +Y 둘레 0/90/180/270도로 해석한다. 직사각형은 회전 후 가로·깊이만 rect에 맞추고 높이를 유지한다. 실제 배치 연결은 별도 작업이다.

각 파일은 단일 메시·단일 면 묶음이며 LOD 없이 삼각형 600 이하다. 낡은 나무 두 색, 쇠 두 색, 천, 법랑의 선형 RGBA 6색을 정점에 직접 담는다. 그림·재질·셰이더는 만들지 않는다. 건물 키트의 구역 번호 비트와 달리 소품 색은 그대로 사용할 수 있다. 발주의 「그리지 않는 것」을 그대로 적용한다.

다음 10종은 공용 표의 확정 순서를 받은 뒤 같은 표준 입력 집계로 발자국을 정하고, 기존 조형 함수를 재사용하거나 필요한 함수를 작성한 뒤 `PROPS` 종류 사전에 한 줄씩 추가한다. 그 줄에는 함수·발자국·높이·최빈 수·원문 수·쓰임을 적는다. 시험의 허용 이름을 새 발주 범위에 맞추고 같은 헤드리스 명령으로 장부까지 다시 생성한다.
