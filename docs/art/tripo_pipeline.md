# 트리포 소품 생산 기준 (초안)

2026-10-09, '트리포·블렌더 MCP' 스레드. 사용자가 트리포 맥스 한 달을 본격 생산용으로 쓰기로 했다(결정 카드: 공유 폴더 decision_cards/tripo.md). 이 문서의 수치와 순서는 **제안**이고, 처음 2~3일 기준 잡기 결과로 고친다.

## 1. 무엇을 트리포로 만들고 무엇을 안 만드나

- 만든다: 움직이지 않는 소품과 건물 조각. 필드 장소의 가구, 수납(뒤질 자리), 잔해, 바리케이드 조각, 부서진 탈것, 역 구내 설비, 열차 칸 안 소품.
- 참고(2026-10-09): Charakuru(github.com/nanocle/Charakuru, 트리포 후원 키트)는 그림 한 장 → Codex가 트리포 웹을 브라우저로 조작 → 기증 몸에서 가중치를 옮겨 VRM 아바타를 만든다. 애니풍·4K·면 수 조절 없음·캐릭터마다 뼈대라 우리 생산에는 안 맞는다. 기증 몸 가중치 옮기기는 사람 모델 단계에서 참고한다. 자체 라이선스(매출·투자 합 1억 엔 미만 무료, 키트 코드·기증 몸은 저장소에 넣지 않음).
- 안 만든다:
  - 사람·망자: 기본 몸 하나(Quaternius CC0, MPFB 후보)에 옷만 갈아 끼운다. 뼈대와 동작을 함께 써야 하고, 망자 무리는 VAT로 돌리므로 모델마다 뼈대가 다르면 안 된다. 트리포는 손과 얼굴이 약하다(제3자 리뷰).
  - 열차 겉모습: 칸 치수와 부품을 맞춘 키트라 스크립트로 만든다(K12 방식, T1 부품 키트).
  - 지형, 눈 덮인 바닥, 길: 엔진의 셰이더와 타일로 한다.
- 애매한 것: 건물 한 채 통째로. 벽 자르기(단면)와 안으로 들어가기가 있어서 통짜 메시는 쓰기 어렵다. 트리포로는 바깥 장식 조각(굴뚝, 차양, 창틀)까지만 만들고 벽·바닥은 모듈 키트로 짠다(추정, 기준 잡기 때 확인).

## 2. 한 개를 만드는 흐름

1. 주문: 이미지→3D를 기본으로 한다. 그림은 우리 시안 PICK이나 새로 그린 정면·옆 그림을 쓴다. 글→3D는 단순한 물건(상자, 양동이)에만 쓴다.
2. 트리포 설정: 스마트 저폴리, 목표 면 수(아래 3장), 텍스처 표준(HD·8K 안 씀), **조명 빼기 켬**. 결과에 위장 무늬, 끈, 휘장, 글씨가 보이면 그 자리에서 버린다.
3. 블렌더 스크립트(`blender -b -P`)로 일괄 처리: 거리로 합치기, 떠 있는 조각 지우기, 법선 정리, 크기(미터)와 기준점(바닥 가운데) 맞추기, 면 수 검사, 텍스처를 작은 크기로 다시 굽기(색만, 조명·AO 없음), 이름 붙이기, LOD1 만들기, glTF(.glb) 내보내기. 대화로 블렌더를 조작하지 않고 스크립트로 돌려서 토큰을 아끼고 다시 돌릴 수 있게 한다.
4. 손칠 맞추기: 좀보이드식 단색 손칠 쪽으로 채도를 낮추고 색 수를 줄인다. 같은 장소 소품끼리 팔레트를 맞춘다(팔레트 표는 기준 잡기 때 만든다).
5. 금지선 검사: 그림만 보여 주고 무엇으로 읽히는지 다른 모델에 묻는 눈 가림 검사를 묶음마다 한 번 한다. 3D 시안 때 쓴 방식과 같다.
6. Godot에 넣고 폰(갤럭시 S22)에서 장소 하나를 채워 잰다. 처음 묶음과 장소가 새로 늘 때마다 잰다.
7. 권리 장부 4장에 줄을 만든다(아래 5장).

## 3. 예산 (제안)

S2 성능 시험은 망자 150마리(정점 1,764)에서 평균 9ms였다. 소품이 들어간 장면은 아직 안 쟀다. 처음 묶음으로 잰 뒤 고친다.

| 크기 | 예 | LOD0 삼각형 | LOD1 | 텍스처 | 재질 |
|---|---|---|---|---|---|
| 작음 | 양동이, 깡통, 책 더미, 등불 | 150~400 | 없음 | 256² | 1 |
| 중간 | 의자, 침대, 선반, 난로, 손수레 | 400~1,500 | 절반 | 512² | 1 |
| 큼 | 부서진 차, 물탱크, 신호 설비, 가판대 | 1,500~5,000 | 1/3 | 1024² | 1~2 |

- 노멀 맵은 쓰지 않는다. 이 면 수와 카메라 거리에선 차이가 작고 메모리만 먹는다(추정).
- 텍스처는 장소별 아틀라스로 묶는 걸 기본으로 한다. 묶기 전 낱개 텍스처는 위 크기를 넘지 않는다.
- 트리포 기본 출력(수십만~백만 면)은 그대로 쓰지 않는다.

## 4. 주문 공통 줄

모든 트리포 주문(글과 첨부 그림)에 붙인다. 영어 주문이면 같은 뜻으로 옮긴다.

- 낡고 칙칙한 겨울 아포칼립스, 단색 손칠, 채도 낮음, 조명과 그림자를 텍스처에 굽지 않음.
- 글씨, 상표, 로고, 표지판 문구 없음. 실제 제조사 생김새를 따라 하지 않음(차, 총, 가전).
- 휘장, 별, 완장, 모표, 위장 무늬(얼룩진 옷감 포함), 철모, 빨간 십자와 초승달 없음. 군용 상자·군용 배낭·국방색 없음.
- 짐은 자루와 나무 상자. 여행가방, 보따리, 신발 무더기 없음.
- 철조망, 망루, 막사, 하역 경사로 없음. 울타리는 나무 가로대.
- 열차 칸 안 소품에 사슬, 빗장, 쇠창살, 자물쇠 없음. 문은 열린 상태로.
- 연기 나는 굴뚝, 냉각탑 없음. 굴뚝은 연기 없이.
- 위생 소품은 솥, 김 없는 빨랫줄, 빈 대야만. 샤워기, 분무기, '소독' 표지 없음.
- 프로젝트 지시문의 민감한 역사 금지선 전체를 따른다. 걸리는 물건은 주문하지 않는다.

## 5. 권리와 저장소

- 트리포 약관(2025-07-11 개정)상 유료 회원은 입력과 출력의 권리를 대체로 가진다. 무료 회원 생성물은 트리포가 권리를 가진다. 그래서 **유료 기간에만 만든다.** 해지 뒤 권리 유지와 공개 저장소에 두는 것은 약관에 문장이 없으니 트리포 지원에 글로 묻고, 답은 PC에만 보관한다.
- 트리포 원본(고해상도 .glb)은 공개 저장소에 올리지 않는다. 사용자 PC에 둔다. 게임에 들어갈 가공한 모델만, 권리 장부에 줄을 만든 뒤 넣는다. 공개 저장소에 낱개 에셋을 묶음처럼 쌓아 두면 트리포와 겨루는 에셋 배포로 읽힐 수 있다(추정). 그래서 모델 파일을 어디에 둘지(공개 저장소, Git LFS, 비공개 저장소)는 첫 모델을 넣기 전에 통합 스레드와 정한다.
- 권리 장부 칸: 자산 이름, 종류 'AI 생성(3D)', 트리포 요금제(맥스), 만든 날, 트리포 모델 버전, 입력 그림의 출처, 블렌더에서 손본 내역. 영수증과 요금제 화면은 PC에만.
- 출시 때 Steam은 게임에 든 AI 생성 그림·3D를 상점 페이지에 밝혀야 한다(2026-01 보도 기준, Steamworks 원문 미확인).
- 트리포 API 키는 저장소, 공유 폴더, 채팅에 두지 않는다. PC의 환경 변수에만.

## 6. 블렌더 MCP를 쓸 때

- 대량 처리는 2장의 스크립트로 한다. MCP는 처음 기준을 잡을 때 모양을 보며 고칠 때만 쓴다.
- 블렌더 MCP(ahujasid, 지금 이름 mcp-for-blender)는 임의 파이썬 실행 도구가 있다. 원격 측정을 끄고(DISABLE_TELEMETRY=true) 안전 모드(BLENDER_MCP_SAFE_MODE=1)를 켠다. 버전을 고정한다. 소켓은 내 PC 안에서만.
- 트리포 공식 MCP(VAST-AI-Research/tripo-mcp)와 블렌더 애드온은 API 키로 돈다. API는 웹 구독과 따로 쓴 만큼 내는 요금이라, 맥스 크레딧을 API에서 쓰는지 먼저 확인한다. 안 되면 생성은 웹에서 하고 받은 파일을 스크립트로 처리한다.

### 6.1 웹 크레딧과 API 크레딧 (2026-10-09 확인)

- 둘은 따로다. 트리포 도움말: "Web App credits are not API credits." 사용자 키로 V3 잔액을 두 번 조회하니 0이었다(웹 맥스 구독 중).
- 공식 자동화 도구(Tripo CLI의 `tripo batch run`, Codex 플러그인, tripo-mcp)는 전부 API 크레딧을 쓴다.
- 웹 스튜디오를 브라우저나 스크립트로 자동 조작하지 않는다. 약관 3조가 자동 소프트웨어로 서비스에 접근하는 것을 막는다. 웹 크레딧을 쓰는 비공식 MCP(Ador-able/tripo-studio-mcp)도 비밀번호를 넘기고 같은 조항에 걸려 쓰지 않는다.
- 그래서 웹 크레딧으로는 이렇게 한다: Claude가 묶음마다 주문 목록 파일을 만든다 → 사용자가 스튜디오 일괄 생성(맥스 기능)에 붙여 넣고 일괄 내보내기(또는 DCC 브리지)를 누른다 → PC의 폴더 지켜보기 스크립트가 받은 파일을 2장 흐름으로 처리한다.
- 주문 본문에 '없음' 목록(no helmets 같은 부정문)을 넣지 않는다. 생성 모델이 낱말을 거꾸로 집어 넣을 수 있다(추정). 부정 프롬프트 칸이 있을 때만 거기에 넣고, 나머지는 결과를 보고 거른다. 예외: 사람이나 망자가 들어가는 주문은 금지선의 망자 옷 끝문장을 주문 맨 끝에 그대로 붙인다(트리포로는 사람·망자를 만들지 않으므로 보통 해당 없다). 금지선 목록의 다른 항목(표식, 군복, 철조망 울타리 같은 것)은 결과를 눈으로 거른다.
- V3 3D 생성은 model_version이 필수다. P1 계열은 스마트 저폴리 옵션을 못 쓰므로 저폴리가 필요하면 v3.1을 고른다(API로 갈 때).

## 7. 한 달 순서 (제안)

1. 1~3일, 기준 잡기: 장소 하나(역 구내나 셋집 한 층)의 소품 8~10개를 만든다. 2~5장을 지나 S22에서 잰다. 면 수, 텍스처 크기, 팔레트, 주문 줄을 이 결과로 고친다.
2. 4일~3주, 대량 생산: 8장 목록을 장소 단위로 만든다. 장소 하나가 끝날 때마다 눈 가림 검사와 권리 장부 줄.
3. 마지막 주: 남은 크레딧으로 변형(부서진 판, 눈 덮인 판)을 만든다. 해지 전 모든 원본을 PC에 받아 둔다.

크레딧 어림: 이미지→3D 텍스처 포함 30, 저폴리 +10, 한 개 약 40. 다시 뽑기를 셋에 하나로 치면 맥스 2만 5천으로 약 450개.

## 8. 소품 목록

2026-10-09 문서와 s2 회색 상자에서 뽑은 후보다(소넷 서브에이전트 조사, 출처 줄은 생략). s2 코드는 회색 상자라 배치와 이름만 근거다. 크기: 작음/중간/큼.

### 8.1 첫 묶음: 역 구내 (기준 잡기)

주문 원문은 공유 폴더 tripo/batch01_station.json. 나무 대합실 의자, 둥근 철 난로, 벽걸이 손종, 나무 상자, 석탄 자루, 전철기 레버, 승강장 가로등(글자 없는 판), 손수레, 차막이, 버려진 소형 승용차(상표 없음).

### 8.2 필드 장소별 (술레후프 지도)

- 역사: 매표 창구와 작은 금고, 역무실 책상·전신기·서류함, 매점 선반, 작은 수납장, 역장 집 옷장·책상·찬장·침대.
- 급수탑: 얼어붙은 급수탑(큼, 다리와 계단이 망루로 읽히지 않게 굵고 낮게), 배수 암거 입구, 등잔·젖은 담요·작은 나무 상자, 장작 더미.
- 화물 측선: 무개 석탄 화차, 석탄 더미, 버려진 탄수차, 빈 화차(문 열림), 고철 더미, 곡괭이·삽.
- 역 앞 거리: 가게 선반, 약국 계산대·선반·약상자(십자 표식 없음), 부엌 레인지·찬장·옷장·서랍장·침대·다락 궤, 부서진 승용차·픽업·밴, 맨홀 뚜껑, 맨홀 막은 판자 더미.
- 신호소: 낮고 넓은 신호소 건물, 나무 사다리, 레버 틀(총으로 보이지 않게), 탁자·찬 난로·신호탄.
- 공동주택: 층별 가구, 지하실 문, 바닥 배수구 격자, 판자 칸막이 지하 창고 칸.
- 화물 창고: 상자·자루 더미, 공구함, 선반, 반장 사물함, 사무실 책상, 고장 난 손수레, 안에서 휜 철문(건물 문에만), 매달린 화물(바름·기움·떨어짐 세 상태).
- 남쪽 주택가: 주택 가구, 나무 가로대 울타리.
- 뒤 정차 후보(지도 없음): 원형 기관고, 철교 둑, 발전소 컨베이어·호퍼·갈탄 더미(냉각탑은 김 없이), 병원 병상·구급차(표장 없음), 물데강 앞 옛 객차(문 열림).

### 8.3 열차 칸 안

- 꼬리칸: 3단 나무 침상, 해먹, 빨랫줄과 해진 천, 자루 묶음(칸 안에서만), 둥근 철 난로와 굽은 연통.
- 앞칸: 천 좌석, 러그, 주전자 난로, 커튼.
- 경비대칸: 침상, 일반형 무기 걸이, 매단 손등불, 카드 탁자와 스툴.
- 식당칸: 긴 탁자와 벤치, 레인지와 큰 솥, 빨랫줄. 추모 이름 판자벽은 글자를 데칼로 따로 한다.
- 열차장실: 책상·오일램프·일지, 노선도 판, 무전기와 헤드셋, 좁은 침대, 외투 걸이(챙 모자 걸지 않음).
- 의무칸: 좁은 병상과 천 커튼 레일, 약 선반, 세면대, 약장, 접은 천 들것. 표장 없음.
- 창고칸: 상자, 자루, 통, 철선 코일, 고철 묶음, 눈 채운 얼음 상자, 방수포 짐.
- 공방칸: 작업대와 바이스, 작은 선반(기계), 꺼진 화덕, 부품 통, 벽 공구판, 작업등.
- 냉동칸: 긴 의자, 병 속 초와 마른 꽃. 천에 싼 형체는 트리포로 만들지 않는다(사람 모양).
- 온실칸: 재배 상자, 양동이, 작은 난로, 물통.
- 공통: 2단 침상, 짚 매트리스, 철제 병상, 석탄통, 장작, 나무 궤, 밧줄 코일, 세면대, 양동이, 랜턴, 병에 꽂은 초, 말아 둔 양탄자, 아이 장난감. 앞칸용(깔끔)과 꼬리칸용(해진) 두 벌.
- 빨래·물 끓이기: 끓는 솥과 난로, 법랑 대야 더미, 빨래판과 통, 건조대, 눈 녹이는 양동이.

### 8.4 정차·구내와 공통

- 승강장 판, 역사 차양, 승강장 배수구 덮개(세 상태), 썰매, 핸드카, 모터카, 불탄 빈 객차(문 열림, 사슬 없음), 완목식 신호기, 화물 기중기, 전신주, 전차선 기둥.
- 눈더미, 얼음 웅덩이, 고드름, 헐벗은 나무, 쓰러진 나무, 꺼진 드럼통, 판자 덧댄 창, 횃불, 모닥불, 깡통 줄, 빗물받이 격자, 큰 배수로 출구, 벽돌 건널목 초소, 주말농장 오두막.

### 8.5 트리포로 만들지 않는 것

- 사람 모양이 되는 것: 눈 속 사람 모양 둔덕, 천에 싼 형체.
- 핏자국, 끌린 자국, 분필 표식: 데칼이다.
- 장작 더미를 열차·굴뚝과 한 화면에 두는 화장 장면 소품: 문서 쪽 정리 전엔 만들지 않는다.
- 빨강은 위험 경고, 하늘색은 정치 지지 전용이라 소품 색으로 쓰지 않는다.
