- 칸 길이, 폭, 높이, 연결 간격이 정해지면 나중의 진짜 모델도 같은 틀에 맞춘다.

## 1. 열차 대역 (Blender Python 스크립트)

- 실행: `blender -b -P tools/blender/train_kit.py -- --out out/` (PC에 Blender가 없으면 Python 3.11의 `pip install bpy`로도 돌게 쓴다. 둘 다 안 되면 그 사실만 알린다).
- 출력: glTF 2.0 바이너리(.glb), 칸마다 한 파일. LOD0과 LOD1을 한 파일에 `_LOD0`, `_LOD1` 이름으로 넣는다.
- 편성 14개(왼쪽 꼬리 → 오른쪽 기관차, train_cars_20261007.md 표와 T6 PICK 번호): 꼬리칸 3·2·1(낡은 3등 나무 객차), 냉동칸(난방 끊은 나무 객차, 연통 없음), 창고칸(나무 화차, 옆문 열림), 의무칸, 식당칸(부엌 연통 하나), 경비대칸(지붕에 낮은 난간 전망대, 높은 탑 아님), 열차장실(강철 침대차, 지붕 안테나 줄과 기둥 둘), 앞칸(강철 침대차), 공방칸(나무 화차, 옆문 활짝, 연통 없음), 기관실(나무 객차), 탄수차, 기관차(쐐기 쟁기).
- 치수(제안): 객차 길이 20m, 폭 2.9m, 높이 4.2m. 화차 길이 11m. 표준궤 1,435mm. 칸 사이 0.8m.
- 예산(제안, 맞지 않으면 숫자를 보고하고 고친다):
  - 객차 LOD0 2,500 삼각형 이하, LOD1 800 이하
  - 화차 1,500 / 500
  - 기관차와 탄수차를 합쳐 7,000 / 2,000
  - 열차 전체 LOD0 35,000 이하
- 재질: 칸마다 재질 하나. 텍스처는 객차·기관차 1024², 화차 512² 자리표시(단색과 잡음, 창 자리는 호박색 발광 칸). 앰비언트 오클루전은 정점 색으로 굽는다.
- 금지선(그림과 같음): 사람 사는 칸에 사슬·빗장·창살·자물쇠·막힌 창 없음, 닫힌 화차에 연통 없음, 화차 문은 처음부터 열림.
- 연기 붙일 자리: 기관차 굴뚝 끝과 객차 연통 끝에 빈 노드(`smoke_loco`, `smoke_stove_N`)를 둔다. 파티클은 Godot에서 붙인다.

## 2. 사람 대역 (같은 스크립트, 선택)

- 사람 하나: 1,500 삼각형 이하, 뼈 24개 이하, 재질 하나(256²).
- 동작: 걷기, 서 있기, 비틀거리기(좀비), 각 1초 반복.
- 옷 모양은 해진 겨울옷 덩어리 정도로만. 철모처럼 보이는 머리 모양, 가슴 띠는 만들지 않는다.

## 3. 결과 형식

- `tools/blender/train_kit.py`와 README(실행법, 각 칸의 삼각형 수 표, 파일 크기 표).
- 만든 .glb와 회색 미리보기 그림 한 장(열차 전체를 옆에서 본 것). 미리보기는 우리가 만든 것이라 저장소에 올려도 된다.
- 직접 확인한 것과 못 한 것을 나눠 적는다(예: Godot에서 열어 봤는지).

## 4. Godot 연기 시험 (S2 스레드에 넘길 제안)

S2가 열차 대역을 필드에 놓고 기관차 연기를 GPUParticles3D로 붙여 S22에서 잰다. 연기 단계는 T8 시트(달림, 느려짐, 멈춤, 출발)를 따른다. 멈춤 때는 굴뚝 연기를 끄고 실린더 김만 낮게 낸다. 잴 것은 입자 수 64·128·256에서 평균 프레임과 가장 느린 프레임이다. 이 부분의 코드는 S2 스레드 몫이다.
