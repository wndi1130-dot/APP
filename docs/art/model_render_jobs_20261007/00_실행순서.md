# 모델 시안 작업 실행 순서 (2026-10-07)

주문서 원문: 저장소 docs/art/model_renders_20261007.md (main, M3b·M3c 더한 판). 이 폴더의 작업 파일은 그 주문서를 세션 하나에 일 하나씩 나눈 것이다.
작성: "모델링 시안" 스레드. 결과 평가와 다음 단계 열기도 그 스레드가 한다.

## 공통

- 이 파일들은 저장소 `docs/art/model_render_jobs_20261007/`에 있다. 로컬 워커 쪽에서 main을 받아 이 폴더 전체를 `바탕 화면\모델컨셉_20261007\_jobs\`로 복사해 쓴다(`_jobs\done\`, `_jobs\log\`는 만들어 두었다). 결과 그림은 저장소에 올리지 않는다.
- 모든 세션의 작업 폴더(현재 폴더)는 `바탕 화면\모델컨셉_20261007\` 이다. 렌더 작업의 첨부 경로 `..\화면컨셉_20261007\...` 는 여기서 본 상대 경로다.
- 작업 파일 하나 = 세션 하나. 서로 기다릴 필요 없는 건 동시에 돌려도 된다.
- 끝난 작업 파일은 `_jobs\done\` 으로 옮긴다(지우지 않는다). 실패하면 로그를 `_jobs\log\` 에 남기고 한 번만 다시 돌린다.
- 결과 그림과 참고 그림은 공개 저장소에 올리지 않는다.
