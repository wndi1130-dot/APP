# S1 콘텐츠 가이드: 스키마, 문체, 캐릭터 바이블

작성: 2026-10-05 · 상태: 초안 · 2026-10-07 6장(글 데이터 규격) 추가

S1의 글(프로필, 인물, 사건 카드, 법안, 일대기)은 Gemini 4.0이 쓴다. 이 문서는 그 글을 담을 틀이다. 근거: [S1 기획서](s1_political_prototype.md), [decisions.md](../design/decisions.md), [세계관 브리프](../design/briefs/world_lore.md), [유럽 무대 브리프](../design/briefs/europe_setting.md)

## 0. 원칙

- 로직은 우리가, 말은 Gemini가 쓴다. 조건과 효과는 데이터로 먼저 정하고, Gemini는 그 위에 문장만 얹는다.
- 생성 순서: 시뮬레이션 데이터 → Gemini 문장 → 스키마 검사 → 금지어 검사 → 사람 검수(핵심 인물의 목소리).
- S1은 서버가 없다. 문장은 미리 생성해 JSON으로 넣고, 플레이 중에 실시간으로 생성하지 않는다.
- 같은 시드면 같은 사람들이 나온다.

## 1. 콘텐츠 스키마

공통 규칙

- 모든 항목은 id(영문 소문자와 밑줄)를 가진다. 사람에게 보이는 글은 한국어다.
- 효과는 1.9의 효과 어휘에 있는 것만 쓴다. 새 효과가 필요하면 어휘부터 늘린다.

### 1.1 프로필 (200명)

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: p_001 |
| name | 문자열 | 한글 표기. 외래어 표기법을 따른다 |
| name_original | 문자열 | 원어 표기(검수용) |
| age | 정수 | 0~85 |
| community | 열거 | tail(꼬리칸), engine(기관실), guard(경비대), medtech(기술·의무진), front(앞칸) |
| origin_tag | 열거 | original(원래 승객), rescued(구조민) |
| boarding | 열거 | depot(차고), bought(물건·권력을 내고), force(경찰·군), rescue(구조), refugee(피난), born(열차에서 태어남) |
| hometown | 문자열 | 도시, 나라 |
| like | 문자열 | 하나 |
| dislike | 문자열 | 하나 |
| line | 문자열 | 한 줄 소개, 40자 이내(Gemini) |
| state | 열거 | alive, injured, dead, away |

프로필 필드에 더해 다음을 가진다.

| 필드 | 형식 | 설명 |
|---|---|---|
| role | 열거 | captain(열차장), deputy(부관), ration_officer(배급장), rep(대표), aide(측근), faction_leader(세력 지도자) |
| trait | 열거 | greed(탐욕), ideal(이상주의), family(가족), fear(겁), ambition(야심). 처음엔 가려져 있다 |
| secrets | 목록 | 비밀 id 0~2개 |
| relations | 목록 | {대상 id, 종류: family, friend, enemy} 1~3개 |
| luxuries | 정수 | 가진 사치품 |
| debts | 목록 | {누구에게 또는 누구로부터, 사유} |

| voice | 열거 | 말투 키(2장) |
| bio | 문자열 | 3문장 이내(Gemini) |

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: s_hid_bitten_kin(물린 가족을 숨겨 줬다가 몰래 처리했다) |

### 1.4 사건 카드

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: ev_tail_cold_01 |
| stage | 열거 | s1a, s1b, s1c |
| phase | 열거 | travel(이동), stop(정차), council(의회), settle(정산) |
| trigger | 조건 목록 | 구간 범위, 처지 문턱, 플래그, 필요한 인물 |

| body | 문자열 | 3문장, 120자 이내(Gemini) |
| choices | 2~4개 | {label: 15자 이내(일지에 남는 행동), say: 40자 이내(카드에 보이는 열차장의 말), effects, followups, witnesses} |
| repeat | 정수 | 0이면 한 번만, 그 외엔 다시 나오기까지의 구간 수. 다시 나올 땐 본문·요구·결과 중 둘 이상이 달라야 한다(상태 키: 대표, 석탄·식량 40 단위, 꼬리칸 온기·배급 10 단위, 법. 같은 사건은 연달아 세 번까지). 한 벌만 쓰지 말고 상황별 변주를 함께 낸다 |
| chronicle | 참조 | 일대기 기록 틀 id(중요한 사건만) |

## 2. 문체 가이드

### 기본

- 한국어로 짧고 구체적으로 쓴다. 감정을 설명하지 말고 사물과 행동으로 보여준다. "춥다" 대신 "숨이 하얗게 얼었다". 선택 뒤의 문장에도 감정 이름 대신 물건을 다루는 행동이 남게 쓴다.
- 이 세계는 차갑고 건조하다. 영웅적인 말투나 희망찬 구호는 인물의 입으로만 나온다.
- 길이: 사건 본문 3문장(120자) 이내, 선택지 행동(label) 15자 이내, 선택지 대사(say) 한두 문장 40자 이내, 프로필 한 줄 40자 이내, 인물 소개 3문장 이내, 일대기 증언 2문장 이내.
- 단위는 미터법과 섭씨. 때는 '○번째 겨울, ○구간째'로 쓴다.

### 공동체별 말투

| 공동체 | 말투 |
|---|---|
| 기관실 | 짧고 기술적이다. 숫자로 말한다. 기관차를 사람처럼 부른다 |
| 앞칸 | 격식 있고 돌려 말한다. 거래의 언어를 쓴다 |
| 경비대 | 명령과 보고. 짧게 끊는다 |
| 기술·의무진 | 정확하고 지쳐 있다. 수치와 기한을 말한다 |
| 꼬리칸 | 거칠고 직설적이다. '우리'로 말한다 |

- 먼저 꺼내는 말: 기관실은 남은 양과 교대, 앞칸은 조건과 몫, 경비대는 위치와 인원, 기술·의무진은 수치와 기한, 꼬리칸은 우리 물건부터 말한다.
- 짧은 관찰 다음에 필요한 조건을 붙인다. 모든 공동체를 같은 어절 수로 자르지 않는다.
- 세력의 말: 엔진 신앙은 불, 심장, 구원의 어휘를 쓴다. 복원파는 고치고 되찾는 어휘를, 적응파는 받아들이고 버티는 어휘를 쓴다.

### 성향은 이름 대신 행동으로

성향을 가리키는 단어(탐욕, 겁 등)는 문장에 쓰지 않는다. 행동으로 드러낸다.

- 탐욕: 물건과 값을 먼저 말한다.
- 이상주의: 원칙과 약속을 말한다.
- 가족: 가족을 먼저 챙긴다.
- 겁: 피하고 미룬다.
- 야심: 자리와 그다음을 말한다.

### 사건, 법, 선택지

2026-10-06에 B7 노트([ref/dialogue_references.md](../../ref/dialogue_references.md) 4장)의 후보에서 골라 넣었다.

- 직접 본 일, 남에게 들은 일, 추측을 문장 안에서 구별한다.
- 법에는 시행할 행동을 쓰고, 뒤따르는 사건에는 달라진 물건과 행동을 쓴다.
- 선택지는 카드에 열차장이 직접 하는 말(say)로 보인다. 행동 설명("의약품을 준다")이 아니라 태도가 드러나는 말("의약품은 약자의 것이다. 아이들에게 먼저 써라!")로 쓰고, 효과와 비용은 대사에 넣지 않고 비용 줄로 보인다. 대사에도 구체적인 물건이나 사람을 하나는 넣고, 같은 카드의 선택지는 같은 질문에 답하게 한다([선택지 형식 조사](../research/dialogue_choice_forms_20261007.md) 3장 2·3·5번, 길이 기준은 사용자 결정대로 40자를 유지). 일지에는 짧은 행동(label)이 남는다(2026-10-07 사용자).
- 선택지 행동(label)에는 물건·대상과 실행 동사를 적는다. 인물은 돌려 말해도 되지만, 플레이어가 건네는 물자와 약속은 대상과 이행 기준까지 읽혀야 한다.
- 지금 확인되는 비용은 보여 준다. 선택하는 즉시 확실하게 바뀌는 불만·지지는 '약간 증가'처럼 보여 준다. 나중의 반응과 관계를 성공으로 미리 알려 주지 않는다.
- 물건을 발견했다고 곧바로 범죄나 비밀로 확정하지 않는다. 단서와 확정을 가른다.
- 프로필 한 줄은 주어진 취향과 생활 행동만 근거로 쓴다. 성향, 비밀, 입력되지 않은 관계를 지어내지 않는다.
- 보류: 같은 사건을 공동체마다 다르게 증언하게 하는 것(분량이 크게 늘어 큰 사건에만 시험한다), 지시어·명사화를 줄이는 조건(사람이 고칠 때 쓰는 점검표로 둔다).

### 세계관의 금기

- 추위와 감염의 원인을 단정하지 않는다. 인물은 자기 해석을 믿을 뿐이다.
- 대사에서 '좀비'라고 부르지 않는다. '망자', '그것들'처럼 이 세계의 말을 쓴다.
- 도덕 점수나 선악 수치를 문장에 드러내지 않는다.

### 쓰지 않는 것

- 실제 총기 제조사와 모델명. 일반 명칭과 별명을 쓴다.
- 강제 이송 열차를 흉내 내는 표현과 장면: 사람을 화물칸에 싣기, 줄 세워 가르는 선별 장면의 직접 모방, 수용소 어휘.
- 국적이나 민족을 집단의 성격으로 쓰는 것. 희생양은 외부인이지 특정 민족이 아니다.
- 희생양을 몰아붙이는 말이 이름, 출신, 말씨, 외모, 신앙을 겨냥하는 것. 겨냥은 '늦게 탔다, 밖에서 왔다, 한 말과 본 것이 다르다, 그날 밤 거기 있었다'에만 건다. 출신은 고향 대신 "서쪽 어딘가"나 탄 경위로만 말한다.
- 유명 실존 인물, 실제 정당과 단체의 이름.
- 신체 훼손의 직접 묘사. 폭력과 절단은 소리와 결과로 암시한다.
- 상투어: "희망의 불씨", "운명의 수레바퀴", "모든 것이 변했다" 같은 말.

### 이름

- 중부 유럽(독일, 폴란드, 체코)을 중심으로 섞고, 피난민은 더 넓게 섞는다.
- 한글 표기는 국립국어원 외래어 표기법을 따르고, 원어 표기를 함께 저장한다.
- 유명 실존 인물과 같은 이름은 피한다(검수 때 확인).
- 생성기는 모든 사람에게 '희생양 후보 가능' 표시를 단다(아이는 언제나 아니다). 폴란드·독일·체코 풀의 흔한 앞쪽 묶음에서 이름과 성을 받은 사람만 참이고, 그 묶음도 특정 민족·종교로 읽히기 쉬운 이름은 사람이 검수해 뺀다. 이야기(길잡이)와 군중은 이 표시가 참인 사람만 희생양으로 고른다(first_leg_story 4.1, s1b_dark_path 1.4).

### 용어집

열차장, 부관, 배급장, 구간, 정차, 회기, 칸(꼬리칸, 기관실, 앞칸, 식당칸, 열차장실, 의무칸 등), 망자, 갓 일어난 자, 얼어붙은 자, 껴입은 자, 한파, 해빙기, 중앙역(라이프치히), 볼슈틴 차고.

| 메트로 시리즈(메트로 2033, 라스트 라이트, 엑소더스, 글루홉스키의 원작 소설) | 역마다 나라가 된 지하 사회. 칸마다 공동체가 된 우리 열차와 구조가 같다. 짧은 무전과 소문의 말투 |

| 프로스트펑크 1·2 | 법과 안건의 문장, 공동체와 세력이 요구하는 문장 |
| 수저린(Suzerain) | 내각과 의회의 협상 대사, 뇌물과 압박을 말로 주고받는 법 |
| 남한산성(김훈 소설) | 얼어붙은 포위 속 어전 회의. 주화파와 척화파의 다툼이 회기 대사의 본보기다. 짧고 구체적인 한국어 문장의 기준 |
| 설국열차(영화, 드라마판) | 열차 안 계급 정치, 앞칸의 연설과 꼬리칸의 말 |
| 크루세이더 킹즈 3 | 비밀, 약점, 음모를 성향에 묶어 사건으로 쓰는 법 |
| 배너 사가(The Banner Saga) | 이동하는 공동체가 길 위에서 내리는 결정과 짧은 사건 문장 |
| 페이퍼스, 플리즈(Papers, Please) | 누구를 들일지 가르는 짧고 건조한 선택. 구조민을 태울지 정하는 장면의 본보기 |
| 스베틀라나 알렉시예비치(「체르노빌의 목소리」 등) | 같은 일을 여러 목소리가 다르게 말하는 증언. 일대기의 집단별 증언의 본보기 |
| 코맥 매카시 「로드」 | 감정을 설명하지 않고 사물과 행동으로 쓰는 건조한 문장 |

- 문장을 베끼지 않는다. 저장소가 공개라서 대본을 모아 올리면 저작권 문제가 된다. 분석에 필요한 짧은 인용만 출처와 함께 쓴다(저작권법 제28조, 공표된 저작물의 인용).
- Gemini에 원작 대사를 예시로 넣지 않는다. 예시는 우리가 쓴 것(3.2)만 쓴다.
- 번역본만 보면 번역투가 묻어온다("~하는 것이다", "그것은 ~이다" 같은 말). 한국어 문장의 기준은 남한산성처럼 처음부터 한국어로 쓴 글로 잡는다.

## 3. 캐릭터 바이블의 틀

### 3.1 깊은 시뮬레이션 인물 템플릿 (S1a)

템플릿마다 역할, 공동체, 탄 경위, 나이 범위, 말투는 고정이다. 이름, 성향, 비밀, 관계는 판마다 무작위다. 같은 역할이라도 판마다 다른 사람이 된다.

- **열차장**(플레이어): 이름과 탄 경위를 시작할 때 고른다(결정). 고른 공동체와 관계가 조금 좋게 시작한다. 좀보이드처럼 스탯, 특성, 피지컬도 정한다(설계 예정).
- **부관**: 열차장의 오른팔. 후계는 S1 범위 밖이지만, 후계 후보로서의 성격은 정해 둔다.
- **배급장**: '맡기기'의 얼굴이다. 성향이 배급에 묻어난다. 앞칸이나 기술·의무진 출신이 많다.
- **기관실 대표 = 수석 기관사**: 60~75세, 차고 출신. 파업 카드의 얼굴이다. 늙었다는 것 자체가 지식 소실의 예고다.
- **앞칸 대표**: 물건이나 권력을 내고 탄 사람. 협상과 뇌물에 익숙하다.
- **경비대장**: 경찰이나 군 출신. 질서와 명령의 사람이다.
- **의무장**(기술·의무진 대표): 구조된 의사. 의약품과 중환자 처분의 얼굴이다.
- **꼬리칸 대표**: 피난민. 가장 많은 표를 끌지만 결속도가 흔들리기 쉽다.
- **측근 2~3명**: 대표 곁에 붙는다. 대표가 바뀌면 후임이 되고, 대개 더 과격하다.
- **세력 지도자 1~2명**: 세 축이 모두 기울 때 나온다. 공동체를 가로질러 사람을 끌어온다.

### 3.2 예시 (Gemini에게 보여줄 기준)

**수석 기관사**

- 헨리크 마주레크(Henryk Mazurek), 67세, 볼슈틴 출신, 기관실 대표.
- 탄 경위: 붕괴 전 볼슈틴 차고의 자원봉사 기관사. 첫 겨울에 박물관 기관차에 불을 넣은 사람 중 하나다.
- 좋아하는 것: 석탄 타는 냄새. 싫어하는 것: 기관차를 '물건'이라 부르는 사람.
- 말투 예: "압력 12. 더 올리면 할멈이 운다."
- 성향과 비밀은 판마다 다르다. 예: 겁 + "보일러에 금이 간 걸 숨기고 있다".

**꼬리칸 대표**

- 파블라 크레이치(Pavla Krejčí), 41세, 브르노 출신, 꼬리칸 대표.
- 탄 경위: 세 번째 겨울에 태운 피난민.
- 좋아하는 것: 라디오 잡음 사이로 새어 나오는 음악. 싫어하는 것: 앞칸 창에 걸린 커튼.
- 말투 예: "우리 칸 난로는 이틀째 꺼져 있어요. 회의는 따뜻한 데서 하시죠?"
- 성향과 비밀은 판마다 다르다.

**프로필 한 줄 (3.5의 200명)**

- 기술·의무진: 빈 약병도 씻어서 선반에 세운다.
- 기관실: 석탄 냄새가 남은 장갑을 찾는다.
- 꼬리칸: 해빙기에도 낡은 털장갑을 챙긴다.
- 출처는 B7 노트([ref/dialogue_references.md](../../ref/dialogue_references.md))의 창작 예문이다(2026-10-06 채택). 셋 중 둘이 장갑이라, 생성할 때는 예시의 물건을 그대로 가져다 쓰지 않게 한다.

### 3.3 비밀 풀 (S1a 20~30개)

- 가벼움(1): 배급을 몰래 조금 더 받는다. 붕괴 전 직업을 속였다.
- 중간(2): 사치품을 빼돌린다. 다른 지도자와 몰래 거래한다. 가족을 앞칸으로 몰래 옮겼다.
- 무거움(3): 물린 가족을 숨겨 줬다가 몰래 처리했다. 필드에서 긁혔는데 검사를 피했다. 예전 정차에서 사람을 버리고 왔다. 외부와 몰래 무전을 한다.

### 3.4 관계 규칙

- 사람마다 1~3개. 가족은 같은 공동체 안에 많고, 원수는 공동체를 가로지른다.
- 대표와 측근 사이엔 늘 관계가 하나 있다(충성 또는 경쟁).

### 3.5 프로필 200명 생성 규칙

- 공동체별 인원(출발점): 꼬리칸 90, 앞칸 30, 기술·의무진 30, 경비대 25, 기관실 25.
- 나이: 아이(0~15세) 약 15%. 그중엔 열차에서 태어난 다섯 살 이하가 있다. 노인(65세 이상) 약 10%. 기관실은 나이 많은 쪽으로 기운다.
- 탄 경위: 공동체마다 기본 줄기가 있다(기관실은 차고, 앞칸은 물건·권력, 경비대는 경찰·군, 기술·의무진은 구조, 꼬리칸은 피난). 20%쯤은 다른 경위로 그 칸에 온 사람으로 섞는다.
- 고향: 폴란드, 독일, 체코를 중심으로, 피난민은 더 넓게.
- 좋아하는 것과 싫어하는 것은 풀에서 고른다: 옛 세상의 물건, 음식, 소리, 습관, 사람. 사건 카드가 이 값을 조건으로 쓸 수 있다(가끔 실제 사건에 걸린다).
- 한 줄 소개는 Gemini가 쓴다. 이름, 나이, 공동체, 고향, 탄 경위, 좋아하는 것, 싫어하는 것만 보고 쓴다. 성향과 비밀은 드러내지 않는다.

### 3.6 정해진 것

- 아이도 의석 계산에 센다(결정). 아이는 표를 직접 던지지 않지만 그 집단의 의석을 늘린다. 아동 노동 같은 법이 아이가 많은 공동체의 무게와 맞물린다.
- 열차장은 탄 경위를 시작할 때 고른다(결정). 스탯, 특성, 피지컬은 다음 설계 주제다.

- **고정 지시**: 이 문서의 2장(문체 가이드)과 세계관의 금기, 쓰지 않는 것, 6.3의 자리표시자·조사 쓰는 법, 6.6 용어집의 한국어 낱말.
- **데이터**: 써야 할 항목의 JSON(예: 인물의 역할, 나이, 고향, 탄 경위, 성향, 비밀).

- **출력**: 스키마에 맞는 JSON만. 설명 문장 없이.

## 5. 검수 체크리스트

- 스키마 검사를 통과했나
- 금지어와 금지 장면이 없나
- 길이 제한을 지켰나
- 말투가 공동체와 역할에 맞나
- 성향을 가리키는 단어가 문장에 없나
- 세계관 금기(원인 단정, '좀비'라는 말)를 어기지 않았나
- 중부 유럽에 있을 법한 물건과 장소인가
- 유명 실존 인물의 이름과 겹치지 않나
- 희생양을 몰아붙이는 말이 이름·출신·말씨·신앙을 겨냥하지 않나

## 6. 글 데이터 규격: 번역 키, 자리표시자, 문맥, 복수형, 용어집

2026-10-07 추가(첫 구간 이야기 스레드, 대사 주인). 근거: 레퍼런스 수집 r8 2절 4·10번(research 가지 reference_harvest_20261007/r8_missed_tasks.md), 화면 스레드가 넘긴 몫(presentation_motion.md '가짜 번역으로 글이 잘리는지 미리 본다'). 상태: 기본값. 사건 규격의 글 쪽만 정한다. 조건·효과·후속 연결 같은 사건 구조와 검사기 코드는 S1a 몫이다(6.7에 요구만 적는다).

Gemini 대사를 대량으로 연결하기 전에 이 규칙부터 맞춘다. 나중에 바꾸면 이미 쓴 문장을 전부 다시 고쳐야 한다.

### 6.1 원칙

- 원문은 한국어다. 원문은 지금처럼 콘텐츠 JSON의 글 필드(body, label, say, preview, text, line, bio)에 그대로 둔다. 번역 키는 따로 적지 않고 id와 필드 경로에서 만든다. 원문과 키를 두 곳에서 관리하면 반드시 어긋난다.
- 화면에 보이는 글은 모두 이 키를 거친다. 코드 안에 화면 글을 직접 쓰지 않는다(버튼 이름, 단위 포함). 가짜 번역(presentation_motion.md)을 켜면 키를 안 거친 글이 바로 드러난다.
- 번역 파일 형식은 S3(Godot)에서 gettext PO로 낸다. Godot은 PO의 문맥(msgctxt)과 복수형을 읽는다. CSV도 되지만 문맥·복수형을 다루는 방식이 버전마다 다르다고 알고 있어 쓰지 않는다(**확인 필요**: 4.7.2 CSV의 문맥·복수형 지원). S3 전 웹(TS) 빌드는 같은 키로 한국어만 읽는다.

### 6.2 번역 키

형식: `<콘텐츠 id>.<필드>`, 선택지는 `<콘텐츠 id>.<선택지 id>.<필드>`, 상황 변형은 `@<변형 id>`를 붙인다.

| 글 | 키 예 |
|---|---|
| 사건 본문 | `ev_tail_cold_01.body` |
| 사건 본문의 상황 변형 | `ev_tail_cold_01.body@lever0` |
| 선택지 행동·대사 | `ev_tail_cold_01.c_give.label`, `ev_tail_cold_01.c_give.say` |
| 법 이름·미리보기 | `law_secret_ballot.name`, `law_secret_ballot.preview` |
| 공용 글(버튼, 단위, 해석 말) | `ui.<자리>.<이름>`: `ui.omen.grave`, `ui.unit.coal` |
| 용어집 낱말 | `term.<id>`: `term.tail` (6.6) |

- 선택지에는 영문 id(`c_` + 소문자·밑줄)를 단다. 순번 키(`.0`, `.1`)는 선택지 순서를 바꾸면 번역이 엉뚱한 선택지로 붙어서 안 쓴다. 지금 스키마(event.schema.json)엔 선택지 id와 say가 없다. 넣는 건 S1a 몫이다.
- 키는 다시 쓰지 않는다. 뜻이 바뀌면 새 id를 만든다. 뜻은 그대로고 한국어 문장만 다듬었으면 키는 두고, 내보낼 때 번역을 '다시 볼 것(fuzzy)'으로 표시한다.
- Gemini는 키를 만들지 않는다. 지금처럼 정해진 필드에 문장만 채운다(gen_text.ts의 흐름).

### 6.3 이름 있는 자리표시자

문장 안에 바뀌는 값은 `{person}`처럼 중괄호 이름으로 넣는다. 이름은 영문 소문자로, 아래 표에 있는 것만 쓴다. 지금 문서에 흩어진 `{칸}`·`{이름}`은 이 표로 바꾼다.

| 자리표시자 | 들어가는 값 | 한국어 조사 | 대상 언어에서 따로 다룰 것 |
|---|---|---|---|
| `{person}`, `{person2}` | 사람 이름(프로필 id로 묶음) | 붙음 | 성별(6.5) |
| `{captain}` | 열차장 이름 | 붙음 | 성별 |
| `{community}` | 공동체 이름(용어집 `term.tail` 등) | 붙음 | 문법 성 |
| `{law}` | 법 이름 | 붙음 | 문법 성 |
| `{place}` | 장소·정차 이름 | 붙음 | 지명 규칙(6.6) |
| `{car}` | 객차 이름 | 붙음 | 문법 성 |
| `{item}` | 물건 이름(상징물, 자원) | 붙음 | 문법 성 |
| `{n}`, `{n2}` | 정수 수량 | 붙이지 않음 | 복수형(6.5) |

- 한 글 항목이 쓰는 자리표시자는 항목에 `params`로 밝힌다(값을 어디서 가져오는지 묶는 건 코드 몫이다). 문장에 있는데 `params`에 없거나, `params`에 있는데 문장에 없으면 검사에서 거른다.
- 번역문은 자리표시자의 순서를 바꿔도 된다. 이름이 있어서 순서가 아니라 이름으로 찾는다.

**한국어 조사.** 이름 뒤 조사는 받침에 따라 바뀐다. "경비대이", "파블라을"처럼 틀리지 않게 조사를 자리표시자 뒤 대괄호에 둘 다 쓴다. 고르는 건 실행할 때 마지막 글자의 받침으로 한다.

| 쓰는 법 | 받침 있음 | 받침 없음 |
|---|---|---|
| `{person}[이/가]` | 이 | 가 |
| `{person}[을/를]` | 을 | 를 |
| `{person}[은/는]` | 은 | 는 |
| `{person}[과/와]` | 과 | 와 |
| `{person}[이나/나]` | 이나 | 나 |
| `{person}[아/야]` (부르는 말) | 아 | 야 |
| `{place}[으로/로]` | 으로(ㄹ 받침이면 로) | 로 |

- 자리표시자 바로 뒤에 조사를 맨글자로 붙이면(`{person}이`) 검사에서 거른다.
- 수량 바로 뒤에는 조사를 붙이지 않는다. 단위 낱말을 두고 조사는 단위에 붙인다: `{n}명이`, `석탄 {n}포대를`.
- 대상 언어는 대괄호를 쓰지 않는다. 번역자는 대괄호째 지우고 그 언어 문법으로 쓴다.

### 6.4 문맥 설명

번역자와 Gemini가 같은 글을 같은 뜻으로 읽게, 글마다 문맥 설명이 붙는다. 대부분은 데이터에서 저절로 만든다. 사람이 쓰는 건 헷갈리는 글에만 쓴다.

- 저절로 붙는 것: 화면 자리(사건 본문, 선택지 행동, 선택지 대사, 일지 한 줄, 법 미리보기 등), 말하는 이(speaker 역할·공동체와 말투 키), 듣는 이(열차장이 하는 말인지, 공동체에게 하는 말인지), 길이 한도(한국어 기준과 '두 줄까지', presentation_motion.md), 자리표시자에 들어갈 수 있는 값의 예.
- 사람이 쓰는 것: 항목의 `notes`에 필드 경로별로 한 줄. 예: `"c_burn.say": "장작불은 시신 화장이다. 요리불로 읽지 않게"`. 낱말이 두 뜻으로 읽힐 때, 비꼬는 말일 때, 일부러 틀린 말을 하는 인물일 때 쓴다.
- PO로 낼 때는 저절로 붙는 것과 `notes`를 번역자 설명(`#.`)으로 넣는다.

### 6.5 복수형과 성별

- **복수형**: 한국어는 수에 따라 문장이 안 바뀐다. 그래도 `{n}`이 들어간 글은 대상 언어에서 수에 따라 형태가 달라진다(폴란드어·체코어는 세 갈래 이상). 그래서 `{n}`을 쓴 글은 내보낼 때 복수형 항목(msgid_plural)으로 만들고, 어느 자리표시자가 수를 정하는지 `plural: "n"`으로 밝힌다. 한 글에 수량이 둘이면 문장을 나눈다.
- **사람의 성별**: 폴란드어·체코어는 과거형 동사와 형용사가 주어의 성별을 따른다("zrobił/zrobiła"). 사람 자리표시자가 주어인 글은 `gender_of: "person"`을 밝히고, 내보낼 때 대상 언어에만 남·여 두 문맥으로 나눈다. 한국어 원문은 하나다.
  - 이를 위해 프로필에 `gender`(male/female)가 있어야 한다. 지금 profile.schema.json엔 없다. 이름 풀은 이미 성별로 나뉘어 있으니(ref/names) 생성기가 값을 낼 수 있다. S1a 몫으로 넘긴다. 화면에 성별을 따로 보여 주지는 않는다.
- **격 변화**: 폴란드어·체코어는 이름 자체도 격에 따라 바뀐다(Pavla → Pavlu). 이름은 주어 자리나 "— {person}"처럼 꼴이 안 바뀌는 자리에만 넣는 게 번역하기 쉽다. 원문을 그 틀에 맞추라고 Gemini 지시에 넣는다. 완전한 해결은 아니다(**확인 필요**: 번역 단계에서 실제로 걸리는 양).

### 6.7 편집 도구

후보 셋을 견줬다. 두 외부 도구의 라이선스는 MIT로 알려져 있고(r8 11·12), Godot 4.7.2 호환은 확인하지 않았다.

| 후보 | 잘 맞는 것 | 안 맞는 것 |
|---|---|---|
| 지금 흐름: Gemini(안티그래비티로 연결, decisions.md) → 콘텐츠 JSON → `npm run validate` 검사기 (gen_text.ts는 같은 틀의 API 판) | 사건이 '조건·효과·후속 + 짧은 글'인 카드라 데이터가 중심이다. 효과 어휘·스키마·금지어 검사가 이미 있다. 웹(TS)과 Godot이 같은 JSON을 읽는다 | 긴 대화를 쓰기 불편하다. 분기를 눈으로 따라가는 화면이 없다 |
| ink·Inky | 긴 분기 대화를 쓰고 바로 돌려 보기 좋다 | 조건과 효과를 ink 안에 다시 써야 해서 효과 어휘와 검사기가 둘이 된다. 번역 기능이 기본으로 약하다고 알려져 있다(**확인 필요**) |
| Godot Dialogue Manager | Godot 안에서 대화를 쓰고 번역 파일로 내보낸다 | S3 전 웹(TS) 빌드에선 못 쓴다. 조건·효과를 이 도구 문법으로 다시 쓴다 |

- **기본: 지금 흐름을 주력으로 둔다.** 이 장의 키·자리표시자·문맥·복수형 규칙을 JSON과 검사기에 더하고, PO 내보내기는 S3에 붙인다.
- 긴 대화 장면(라이프치히 설득, 재판 같은)이 카드 틀에 안 들어가면 그때 Godot Dialogue Manager를 그 장면에만 시험한다. 그 전엔 들이지 않는다.
- 분기를 눈으로 보는 화면이 필요하면 JSON의 followups로 그림을 그리는 작은 보기 도구가 먼저다(검사기의 '닿을 수 없는 사건' 검사와 같은 데이터를 쓴다).

### 6.8 검사기에 더할 것 (S1a 몫, 코디네이터를 거쳐 넘긴다)

- 글 필드마다 키를 만들 수 있나: 선택지 id가 있고, 같은 항목 안에서 겹치지 않나. 변형 id가 겹치지 않나.
- 자리표시자가 6.3 표에 있고, `params`와 문장이 서로 맞나.
- 자리표시자 바로 뒤에 맨글자 조사가 없나. 대괄호 조사가 6.3 표의 짝인가.
- `{n}`을 쓴 글에 `plural`이 있나. 사람 자리표시자가 주어인 글에 `gender_of`가 있나(경고).
- 용어집의 금지 동의어(예: '좀비')가 원문에 없나.
- 길이는 한국어 기준(2장)으로 재고, 가짜 번역 화면 검사는 presentation_motion.md 쪽이 본다.
