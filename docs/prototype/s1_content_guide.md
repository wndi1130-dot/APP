# S1 콘텐츠 가이드: 스키마, 문체, 캐릭터 바이블

작성: 2026-10-05 · 상태: 초안

S1의 글(프로필, 인물, 사건 카드, 법안, 일대기)은 Gemini 4.0이 쓴다. 이 문서는 그 글을 담을 틀이다. 근거: [S1 기획서](s1_political_prototype.md), [decisions.md](../design/decisions.md), [세계관 브리프](../design/briefs/world_lore.md), [유럽 무대 브리프](../design/briefs/europe_setting.md)

## 0. 원칙

- 로직은 우리가, 말은 Gemini가 쓴다. 조건과 효과는 데이터로 먼저 정하고, Gemini는 그 위에 문장만 얹는다.
- 생성 순서: 시뮬레이션 데이터 → Gemini 문장 → 스키마 검사 → 금지어 검사 → 사람 검수(핵심 인물의 목소리).
- S1은 서버가 없다. 문장은 미리 생성해 JSON으로 넣고, 플레이 중에 실시간으로 생성하지 않는다.
- 같은 시드면 같은 사람들이 나온다.

## 1. 콘텐츠 스키마

공통 규칙

- 모든 항목은 id(영문 소문자와 밑줄)를 가진다. 사람에게 보이는 글은 한국어다.
- 효과는 1.9의 효과 어휘에 있는 것만 쓴다. 새 효과가 필요하면 어휘부터 늘린다.

### 1.1 프로필 (200명)

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: p_001 |
| name | 문자열 | 한글 표기. 외래어 표기법을 따른다 |
| name_original | 문자열 | 원어 표기(검수용) |
| age | 정수 | 0~85 |
| community | 열거 | tail(꼬리칸), engine(기관실), guard(경비대), medtech(기술·의무진), front(앞칸) |
| origin_tag | 열거 | original(원래 승객), rescued(구조민) |
| boarding | 열거 | depot(차고), bought(물건·권력을 내고), force(경찰·군), rescue(구조), refugee(피난), born(열차에서 태어남) |
| hometown | 문자열 | 도시, 나라 |
| like | 문자열 | 하나 |
| dislike | 문자열 | 하나 |
| line | 문자열 | 한 줄 소개, 40자 이내(Gemini) |
| state | 열거 | alive, injured, dead, away |

### 1.2 이름 있는 인물 (11~13명)

프로필 필드에 더해 다음을 가진다.

| 필드 | 형식 | 설명 |
|---|---|---|
| role | 열거 | captain(열차장), deputy(부관), ration_officer(배급장), rep(대표), aide(측근), faction_leader(세력 지도자) |
| trait | 열거 | greed(탐욕), ideal(이상주의), family(가족), fear(겁), ambition(야심). 처음엔 가려져 있다 |
| secrets | 목록 | 비밀 id 0~2개 |
| relations | 목록 | {대상 id, 종류: family, friend, enemy} 1~3개 |
| luxuries | 정수 | 가진 사치품 |
| debts | 목록 | {누구에게 또는 누구로부터, 사유} |
| weights | 수 2개 | 집단 이익, 개인 이익. 성향이 정한다 |
| voice | 열거 | 말투 키(2장) |
| bio | 문자열 | 3문장 이내(Gemini) |

### 1.3 비밀

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: s_hidden_bite |
| kind | 열거 | 부패, 과거, 가족, 내통, 숨긴 상처, 거짓 |
| severity | 1~3 | 클수록 협박이 세고 역풍도 크다 |
| proof | 열거 | rumor(소문), evidence(증거) |
| sources | 목록 | 밀고자, 감시, 필드 문서, 포로 |
| text | 문자열 | 2문장 이내 |

### 1.4 사건 카드

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: ev_tail_cold_01 |
| stage | 열거 | s1a, s1b, s1c |
| phase | 열거 | travel(이동), stop(정차), council(의회), settle(정산) |
| trigger | 조건 목록 | 구간 범위, 처지 문턱, 플래그, 필요한 인물 |
| speaker | 참조 | 인물 역할 또는 공동체 |
| body | 문자열 | 3문장, 120자 이내(Gemini) |
| choices | 2~4개 | {label: 15자 이내, effects, followups, witnesses} |
| repeat | 정수 | 0이면 한 번만, 그 외엔 다시 나오기까지의 구간 수 |
| chronicle | 참조 | 일대기 기록 틀 id(중요한 사건만) |

### 1.5 법안

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: law_secret_ballot |
| kind | 열거 | normal(51표), rule(67표) |
| opens_when | 조건 | 상황이 안건을 연다 |
| effects | 효과 목록 | 통과하면 계속 걸리는 효과 |
| stances | 축별 찬반 | 균등↔기여, 규율↔실용, 복원↔적응 |
| preview | 문자열 | 표결 전에 보여줄 변화 요약 |
| chronicle | 참조 | 통과·부결 기록 틀 |

### 1.6 거래 조건

| 필드 | 형식 | 설명 |
|---|---|---|
| id | 문자열 | 예: deal_tail_heat_01 |
| tool | 열거 | open(공개 협상), favor(사적 부탁), fetch(현장 조달), bribe(뇌물), blackmail(협박) |
| from | 참조 | 집단 또는 지도자 |
| ask | 효과 목록 | 이행해야 할 것(물자, 법, 물건) |
| deadline | 정수 | 구간 |
| gives | 효과 목록 | 표, 빚, 지지 |
| breach | 효과 목록 | 어겼을 때 |
| arc_tags | 목록 | 결과 아크가 기억할 패턴 |

### 1.7 장소

| 필드 | 형식 | 설명 |
|---|---|---|
| type | 열거 | freight(화물역), houses(주택가), hospital(병원), factory(공장), church(교회), office(관청) |
| risk | 1~3 | 위험도 |
| loot | 자원별 가중치 | |
| symbols | 목록 | 이곳에서만 나오는 상징물 |
| moral_cards | 목록 | 올라올 수 있는 도덕적 선택 카드 id |

### 1.8 일대기 기록

| 필드 | 형식 | 설명 |
|---|---|---|
| who, what, where, when, why | 참조·문자열 | 누가, 무엇을, 어디서, 몇 구간째, 왜 |
| witnesses | 목록 | 살아 돌아온 목격자 |
| weight | 수 | 어두운 행동의 무게. 톤 계산에만 쓰고 화면엔 안 보인다 |
| template | 참조 | 문장 틀 id |

### 1.9 효과 어휘 (처음 목록)

- 자원: coal, food, medicine, luxury, symbol(+id), secret(+id)
- 처지: community.warmth, community.ration, community.crowding, community.exposure
- 정치: trust(신임), tension(긴장), fear(공포), relation(집단 관계), cohesion(결속도), votes
- 사람: person.state, person.away(구간 수)
- 흐름: flag 설정, 후속 사건 예약, 거래 열기, 일대기 기록

## 2. 문체 가이드

### 기본

- 한국어로 짧고 구체적으로 쓴다. 감정을 설명하지 말고 사물과 행동으로 보여준다. "춥다" 대신 "숨이 하얗게 얼었다".
- 이 세계는 차갑고 건조하다. 영웅적인 말투나 희망찬 구호는 인물의 입으로만 나온다.
- 길이: 사건 본문 3문장(120자) 이내, 선택지 15자 이내, 프로필 한 줄 40자 이내, 인물 소개 3문장 이내, 일대기 증언 2문장 이내.
- 단위는 미터법과 섭씨. 때는 '○번째 겨울, ○구간째'로 쓴다.

### 공동체별 말투

| 공동체 | 말투 |
|---|---|
| 기관실 | 짧고 기술적이다. 숫자로 말한다. 기관차를 사람처럼 부른다 |
| 앞칸 | 격식 있고 돌려 말한다. 거래의 언어를 쓴다 |
| 경비대 | 명령과 보고. 짧게 끊는다 |
| 기술·의무진 | 정확하고 지쳐 있다. 수치와 기한을 말한다 |
| 꼬리칸 | 거칠고 직설적이다. '우리'로 말한다 |

- 세력의 말: 엔진 신앙은 불, 심장, 구원의 어휘를 쓴다. 복원파는 고치고 되찾는 어휘를, 적응파는 받아들이고 버티는 어휘를 쓴다.

### 성향은 이름 대신 행동으로

성향을 가리키는 단어(탐욕, 겁 등)는 문장에 쓰지 않는다. 행동으로 드러낸다.

- 탐욕: 물건과 값을 먼저 말한다.
- 이상주의: 원칙과 약속을 말한다.
- 가족: 가족을 먼저 챙긴다.
- 겁: 피하고 미룬다.
- 야심: 자리와 그다음을 말한다.

### 세계관의 금기

- 추위와 감염의 원인을 단정하지 않는다. 인물은 자기 해석을 믿을 뿐이다.
- 대사에서 '좀비'라고 부르지 않는다. '망자', '그것들'처럼 이 세계의 말을 쓴다.
- 도덕 점수나 선악 수치를 문장에 드러내지 않는다.

### 쓰지 않는 것

- 실제 총기 제조사와 모델명. 일반 명칭과 별명을 쓴다.
- 강제 이송 열차를 흉내 내는 표현과 장면: 사람을 화물칸에 싣기, 줄 세워 가르는 선별 장면의 직접 모방, 수용소 어휘.
- 국적이나 민족을 집단의 성격으로 쓰는 것. 희생양은 외부인이지 특정 민족이 아니다.
- 유명 실존 인물, 실제 정당과 단체의 이름.
- 신체 훼손의 직접 묘사. 폭력과 절단은 소리와 결과로 암시한다.
- 상투어: "희망의 불씨", "운명의 수레바퀴", "모든 것이 변했다" 같은 말.

### 이름

- 중부 유럽(독일, 폴란드, 체코)을 중심으로 섞고, 피난민은 더 넓게 섞는다.
- 한글 표기는 국립국어원 외래어 표기법을 따르고, 원어 표기를 함께 저장한다.
- 유명 실존 인물과 같은 이름은 피한다(검수 때 확인).

### 용어집

열차장, 부관, 배급장, 구간, 정차, 회기, 칸(꼬리칸, 기관실, 앞칸, 식당칸, 열차장실, 의무칸 등), 망자, 갓 일어난 자, 얼어붙은 자, 껴입은 자, 한파, 해빙기, 중앙역(라이프치히), 볼슈틴 차고.

## 3. 캐릭터 바이블의 틀

### 3.1 깊은 시뮬레이션 인물 템플릿 (S1a)

템플릿마다 역할, 공동체, 탄 경위, 나이 범위, 말투는 고정이다. 이름, 성향, 비밀, 관계는 판마다 무작위다. 같은 역할이라도 판마다 다른 사람이 된다.

- **열차장**(플레이어): 이름과 탄 경위를 시작할 때 고른다(결정). 고른 공동체와 관계가 조금 좋게 시작한다. 좀보이드처럼 스탯, 특성, 피지컬도 정한다(설계 예정).
- **부관**: 열차장의 오른팔. 후계는 S1 범위 밖이지만, 후계 후보로서의 성격은 정해 둔다.
- **배급장**: '맡기기'의 얼굴이다. 성향이 배급에 묻어난다. 앞칸이나 기술·의무진 출신이 많다.
- **기관실 대표 = 수석 기관사**: 60~75세, 차고 출신. 파업 카드의 얼굴이다. 늙었다는 것 자체가 지식 소실의 예고다.
- **앞칸 대표**: 물건이나 권력을 내고 탄 사람. 협상과 뇌물에 익숙하다.
- **경비대장**: 경찰이나 군 출신. 질서와 명령의 사람이다.
- **의무장**(기술·의무진 대표): 구조된 의사. 의약품과 중환자 처분의 얼굴이다.
- **꼬리칸 대표**: 피난민. 가장 많은 표를 끌지만 결속도가 흔들리기 쉽다.
- **측근 2~3명**: 대표 곁에 붙는다. 대표가 바뀌면 후임이 되고, 대개 더 과격하다.
- **세력 지도자 1~2명**: 세 축이 모두 기울 때 나온다. 공동체를 가로질러 사람을 끌어온다.

### 3.2 예시 (Gemini에게 보여줄 기준)

**수석 기관사**

- 헨리크 마주레크(Henryk Mazurek), 67세, 볼슈틴 출신, 기관실 대표.
- 탄 경위: 붕괴 전 볼슈틴 차고의 자원봉사 기관사. 첫 겨울에 박물관 기관차에 불을 넣은 사람 중 하나다.
- 좋아하는 것: 석탄 타는 냄새. 싫어하는 것: 기관차를 '물건'이라 부르는 사람.
- 말투 예: "압력 12. 더 올리면 할멈이 운다."
- 성향과 비밀은 판마다 다르다. 예: 겁 + "보일러에 금이 간 걸 숨기고 있다".

**꼬리칸 대표**

- 파블라 크레이치(Pavla Krejčí), 41세, 브르노 출신, 꼬리칸 대표.
- 탄 경위: 세 번째 겨울에 태운 피난민.
- 좋아하는 것: 라디오 잡음 사이로 새어 나오는 음악. 싫어하는 것: 앞칸 창에 걸린 커튼.
- 말투 예: "우리 칸 난로는 이틀째 꺼져 있어요. 회의는 따뜻한 데서 하시죠?"
- 성향과 비밀은 판마다 다르다.

### 3.3 비밀 풀 (S1a 20~30개)

- 가벼움(1): 배급을 몰래 조금 더 받는다. 붕괴 전 직업을 속였다.
- 중간(2): 사치품을 빼돌린다. 다른 지도자와 몰래 거래한다. 가족을 앞칸으로 몰래 옮겼다.
- 무거움(3): 물린 걸 숨기고 있다. 예전 정차에서 사람을 버리고 왔다. 외부와 몰래 무전을 한다.

### 3.4 관계 규칙

- 사람마다 1~3개. 가족은 같은 공동체 안에 많고, 원수는 공동체를 가로지른다.
- 대표와 측근 사이엔 늘 관계가 하나 있다(충성 또는 경쟁).

### 3.5 프로필 200명 생성 규칙

- 공동체별 인원(출발점): 꼬리칸 90, 앞칸 30, 기술·의무진 30, 경비대 25, 기관실 25.
- 나이: 아이(0~15세) 약 15%. 그중엔 열차에서 태어난 다섯 살 이하가 있다. 노인(65세 이상) 약 10%. 기관실은 나이 많은 쪽으로 기운다.
- 탄 경위: 공동체마다 기본 줄기가 있다(기관실은 차고, 앞칸은 물건·권력, 경비대는 경찰·군, 기술·의무진은 구조, 꼬리칸은 피난). 20%쯤은 다른 경위로 그 칸에 온 사람으로 섞는다.
- 고향: 폴란드, 독일, 체코를 중심으로, 피난민은 더 넓게.
- 좋아하는 것과 싫어하는 것은 풀에서 고른다: 옛 세상의 물건, 음식, 소리, 습관, 사람. 사건 카드가 이 값을 조건으로 쓸 수 있다(가끔 실제 사건에 걸린다).
- 한 줄 소개는 Gemini가 쓴다. 이름, 나이, 공동체, 고향, 탄 경위, 좋아하는 것, 싫어하는 것만 보고 쓴다. 성향과 비밀은 드러내지 않는다.

### 3.6 정해진 것

- 아이도 의석 계산에 센다(결정). 아이는 표를 직접 던지지 않지만 그 집단의 의석을 늘린다. 아동 노동 같은 법이 아이가 많은 공동체의 무게와 맞물린다.
- 열차장은 탄 경위를 시작할 때 고른다(결정). 스탯, 특성, 피지컬은 다음 설계 주제다.

## 4. Gemini에 넘기는 것

- **고정 지시**: 이 문서의 2장(문체 가이드)과 세계관의 금기, 쓰지 않는 것.
- **데이터**: 써야 할 항목의 JSON(예: 인물의 역할, 나이, 고향, 탄 경위, 성향, 비밀).
- **예시**: 3.2의 두 인물, 그리고 사건 카드 한두 장.
- **출력**: 스키마에 맞는 JSON만. 설명 문장 없이.

## 5. 검수 체크리스트

- 스키마 검사를 통과했나
- 금지어와 금지 장면이 없나
- 길이 제한을 지켰나
- 말투가 공동체와 역할에 맞나
- 성향을 가리키는 단어가 문장에 없나
- 세계관 금기(원인 단정, '좀비'라는 말)를 어기지 않았나
- 중부 유럽에 있을 법한 물건과 장소인가
- 유명 실존 인물의 이름과 겹치지 않나
