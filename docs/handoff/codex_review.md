- 작은 메모: 석탄이 화물역(40)과 공장(50)에 몰려 있고 병원·교회·관청은 0이다. 석탄은 열차를 움직이는 자원이라, 어느 정차역에 화물역과 공장이 있는지가 경로 설계와 바로 엮인다. 지금은 초안이라 괜찮다.
- 판정: 합쳐도 된다. ref/는 A1 검사기가 보지 않으니 지금 합쳐도 깨지는 것은 없다. loot 키는 A1 스키마 쪽에서 맞춘다.

### 설계 쪽으로 넘길 것

- 장소 loot 키(B5와 A1의 충돌): 가이드 1.7을 "loot는 coal·food·medicine·luxury·symbol·secret의 가중치, symbol이 뽑히면 symbols 목록에서 고른다"로 고치고 A1 스키마에 두 키를 더하자는 제안이다. 사용자가 정하면 반영한다.
- 출발 구간(B4 데이터로 확인): 명세에 볼슈틴 → 포즈난을 첫 구간으로 적었는데, 포즈난은 라이프치히 반대쪽(북동)이다. 같은 그래프에서 볼슈틴 → 즈봉시네크는 직결선으로 28.3km, 포즈난을 거치면 159.3km다. 볼슈틴 → 라이프치히 최단 경로는 즈봉시네크·코트부스를 지나는 311.9km로, 베를린 경유(514.7km)보다 200km 짧다. 직결선이 지금 여객 운행 중인지는 미확인이다(데이터로는 폐선 태그가 없다는 것까지만 안다). 포즈난을 꼭 지나야 할 이유가 없다면 직결선을 기본 경로로 하고, 포즈난은 큰 도시를 들르는 우회 선택지로 두는 편이 낫다. 명세를 쓴 설계 세션의 문제라 코덱스 판정과는 무관하다.
