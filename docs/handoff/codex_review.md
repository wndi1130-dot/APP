### #2 A1 프로젝트 뼈대와 콘텐츠 검사기 (20:25 KST 확인)

- 범위: s1/만 건드렸다. docs/는 그대로.
- 확인한 것: `npm ci` 후 `npm test` 49개 통과. `npm run validate -- fixtures/valid`는 오류 0개, `fixtures/invalid`는 19개 오류를 모두 한국어 이유와 함께 낸다. `npm run build`(타입 검사 포함) 통과.
- 잘된 점: 스키마 여덟 종류와 효과 어휘가 가이드와 맞는다(공동체·탄 경위·역할 열거값, 글자 수와 문장 수 제한). 대사 필드에만 '좀비' 금지를 거는 등 필드별 규칙이 정확하다. 자동 검사로 못 잡는 것(실존 인물, 원인 단정, 민족 고정관념, 폭력 장면)은 사람 검수 목록으로 따로 뺐다.
- 후속 수정(합친 뒤 따로 해도 됨)
  1. 총기 금지어에 모델명이 빠졌다. 지금은 제조사 11개(글록, 베레타, 칼라시니코프 등)뿐이다. AK 계열(AK, AK-47, AKM, AK-74), M16·M4·AR-15, MP5, 마우저, 모신나강, 마카로프, 토카레프, 브라우닝, 루거, 모스버그, 그리고 우리 무대에 나올 법한 체코·오스트리아·핀란드 제조사(CZ·체스카 즈브로요브카, 슈타이어, 사코)를 더한다. 영문 모델 코드 꼴(예: AK-47)은 패턴으로 경고를 거는 편이 낫다.
  2. '강제 이주', '강제 추방'이 오류로 막혀 있다. 추방은 우리 게임의 정식 수단(추방 명단, 칸 분리)이라 정상 문장도 걸린다. 이 둘은 경고로 낮추고, 수용소·가스실·절멸·강제 이송만 오류로 둔다.
- 판정: 합쳐도 된다. A2·A3·A5가 이 뼈대 위에 서야 하니 가장 먼저 합친다.

### #4 B4 실제 철도망 데이터 (20:45 KST 확인)

- 범위: ref/rail/ 파일 8개. docs/와 s1/은 그대로. 원본 약 199MB는 .cache/에만 두고 커밋하지 않았다(규칙 9).
- 확인한 것: `python3 -m unittest discover -s ref/rail -p test_fetch.py -v` 8개 통과. `python3 ref/rail/fetch.py --check`는 네트워크 없이 노드 19,758개, 구간 27,873개, 역 67개, 경로 4개를 검사해 통과. 역마다 OSM 원본 링크가 있고, README·routes.md·graph.json에 ODbL 표기가 있다. PR 설명도 규칙 10을 다 채웠다.
- 잘된 점: 테스트가 철도 데이터에서 틀리기 쉬운 곳을 겨눴다. 입체 교차를 분기점으로 잇지 않기, 한 역 안의 다른 선로로 순간이동하지 않기, `tracks=1` 태그만 보고 단선이라 단정하지 않기. 순간이동 금지는 결과에서도 보인다. 프랑크푸르트 오데르 → 베를린 → 라이프치히를 이어 달리면 두 구간을 따로 잰 합보다 5.7km 길다(259.0km 대 253.3km). 베를린 중앙역의 지상 동서 승강장에서 지하 남북 승강장으로 역 안에서 건너갈 수 없어 생긴 차이로 보인다(추정).
- 경로 거리(포즈난 → 즈봉시네크 79.9km, 베를린 → 슈트랄준트 230.9km, 뤼겐담 → 베르겐 25.7km 등)는 상식선에서 맞는다. 운행표와 대조하지는 않았다.
- 빈 값: 복선 여부는 구간 27,873개 중 25개(14km)만 채워졌고, 경사는 하나도 없다. 명세가 "알 수 있으면"이라 했고 코덱스가 지어내지 않았으니 결함은 아니다. 전철화는 길이 기준 88%, 궤간은 99%가 채워졌다. 게임에서 경사가 필요해지면(석탄 소모, 견인력) 게임용 구간마다 직접 정하거나 표고 데이터를 따로 붙인다.
- 후속 메모(합친 뒤 해도 됨)
  1. core.geojson(10MB)과 graph.json(15MB)이 각각 한 줄짜리 JSON이다. 다시 만들 때마다 25MB가 기록에 통째로 쌓이고, PR 화면에서 무엇이 바뀌었는지 볼 수 없다. .gitattributes에 `-diff linguist-generated`를 달고, 기준 시각을 바꿀 때만 다시 만든다.
  2. 궤간 6000mm 구간이 하나 있다(OSM 태그 오류로 보인다). 제외한다던 750mm 협궤도 6개 들어왔다. `--check`에 궤간 이상값 검사를 더한다.
  3. 게임에 바로 쓰기엔 그래프가 너무 촘촘하다(분기점 16,801개, 선로 길이 합 약 49,700km, 복선은 두 번 셈). 역과 큰 분기점만 남긴 게임 지도용 그래프(수백 개 규모)를 여기서 따로 뽑아야 한다. 이번 명세 범위 밖이라 결함은 아니다.
- 판정: 합쳐도 된다.
