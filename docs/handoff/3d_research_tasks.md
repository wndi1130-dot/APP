# 3D 제작 자료 조사 — 에이전트 공통 지시서

작성: 2026-10-07 · 현재 범위: **조사·정리와 허용된 지시사항 교정**

## 공통 계약

작업 저장소는 `wndi1130-dot/APP`다. 시작할 때 기본 브랜치의 커밋을 읽어 기준 SHA를 남기고, 별도 브랜치/작업 폴더에서 작업한다. main에 직접 push하지 않는다. 자료·기준·수정 내용을 PR로 남기고, 합치기는 별도 승인/기존에 명확히 부여된 권한이 있을 때만 한다.

먼저 [세션 안내](session_start.md), [공통 아트 기준](../art/production_brief.md), [설계 결정](../design/decisions.md), [조사 2판](../../ref/art/production_resources.md)을 읽는다. 현재의 사용자 요청이 역사적 A/B 작업 목록보다 우선한다. `codex_tasks.md`의 docs 읽기 전용 규칙은 당시 병렬 구현 작업의 경계다. 그것을 이유로 현재 사용자가 명시적으로 허용한 문서 교정까지 거부하지 않으며, 반대로 이번 교정 허가를 임의 게임 설계 변경으로 확대하지 않는다.

**월드는 좀보이드식 그래픽의 사선 탑뷰이며 픽셀 월드가 아니다.** 과거 시안의 레이아웃과 아이콘 의미만 참고한다. 전월드 픽셀화·일괄 spritesheet 변환은 조사 기본 경로에서 제외한다. UI·초상·폰트는 미확정이다. 2D 입자 텍스처나 국소 impostor까지 금지하지 않는다.

S1→S2→S3 순서를 유지한다. 현재 실제 모델링·렌더링·애드온 설치·MCP 서버 설치·구매·유료 API 호출·게임 코드 수정은 하지 않는다. 특정 단계가 필요하면 근거와 후속 시험으로 남긴다. 현재 파일을 읽는 것만으로 ‘계속하기’·스케줄·외부 전송을 시작하지 않는다.

## 조사 묶음

| ID | 담당 질문 | 특히 확보할 근거 |
|---|---|---|
| R1 | 몸체·겨울 복장·공통 리그 | 원본 형식, 변형용 뼈, 의복 교체, 원본 재배포 조건 |
| R2 | 이동·전투·생활·작업 모션 | 실제 clip name, 무료/유료 등급, 운반·부축·삽질의 실재 여부, 리타기팅 경로 |
| R3 | 기관차·객차·중앙유럽 장소 | 치수 있는 자료, 내외부 분리, 문·계단·연결기·작업점, 정확한 지역성과 도면 권리 |
| R4 | 재질·눈·성에·가림·효과 | 제작용과 엔진용 구분, 지원 버전, 투명 표면·그림자·깊이·모바일 비용 |
| R5 | 자동화·변환·검수 | CLI/API 실제 존재, Blender/엔진 버전, 오류 보고, ID/소켓 보존, 네트워크·텔레메트리 |

각 담당자는 정해진 새 연구 파일만 소유하고 공통 목록의 병합은 한 명이 한다. 한 .blend나 공통 JSON에 여러 작업자가 동시에 쓰지 않는다. 같은 기술의 단순 포크를 후보 수 늘리기용으로 중복 기재하지 않는다.

## 후보 하나의 기록 형식

식별자·정식 이름·제작자·공식 URL·조사일, 종류(도구/자산/서비스/기법), 우리 게임에서 필요한 이유, 출처가 실제로 보장하는 내용, 포맷·버전·의존성, 비용 등급, 라이선스와 원본 재배포, 클라우드 입력/학습 조건, 자동화 범위, 수정/이식 비용, 미확인 항목, 대안과 후속 검증을 기록한다. 구조는 [resource_index.json](../../ref/art/resource_index.json)을 따른다.

출처 문서 확인, 패키지 내용 확인, Blender 실행, 엔진 import, 실제 폰 성능은 별도 증거다. 한 단계의 통과를 나머지 통과로 쓰지 않는다. 미실행 항목을 ‘호환됨’으로 적지 않는다. 빈 데이터는 미확인으로 남기며 추정과 공식 수치를 섞지 않는다.

가격이 무료여도 원본 재배포를 허용하는 것은 아니다. 상업 게임에 쓸 수 있어도 공개 GitHub의 .blend/FBX/모션 원본 업로드나 외부 AI 서비스 전송은 따로 확인한다. 구매하지 않은 패키지의 파일 내용을 본 척하지 않는다.

## 교정 작업의 범위

명시적으로 허용된 문서의 오류만 고치고 **이전 문구 → 새 문구 → 근거 → 바꾸지 않은 범위**를 남긴다. 과거 로그·시안 평가·실제 테스트 기록을 현재 결과처럼 재작성하지 않는다. 시안의 역사적 원문은 보관하고 현재 작업 입구에서 효력이 없음을 표시한다. 증거가 없는 게임 규칙·정확한 성능 예산·엔진 버전·모델 출시 여부는 새로 확정하지 않는다.

## 검증과 제출

저장소 루트에서 `python ref/art/validate_catalog.py`, `python -m unittest discover -s ref/art -p 'test_*.py' -v`, `git diff --check`, `git diff --name-only`를 실제 실행하고 결과를 기록한다. 문서만 바꿨다면 기존 게임 회귀 테스트를 실행했다고 쓰지 않는다. 검사기는 외부 링크 가용성과 라이선스 법률 판단을 대신하지 않는다.

최종 보고에는 `[PASS]`인 변경/문서 검사, `[WATCH]`인 후보의 미실행·미확인, `[BLOCKED]`인 버전/방향 충돌을 구분한다. PR 번호·브랜치·커밋·변경 파일·검증 명령·잔여 문제와 실제로 열 수 있는 산출물 경로를 남긴다.
