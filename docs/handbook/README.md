## 무슨 게임인가

달리는 증기기관차를 이동식 사회로 운영하는 모바일 가로 화면 생존·정치 게임이다. 끝나지 않는 겨울과 망자들 사이로 열차가 중부 유럽을 지난다. 열차 안에서는 다섯 공동체(꼬리칸, 기관실, 경비대, 기술·의무진, 앞칸)가 의석을 나눠 갖고, 열차장은 프로스트펑크 2처럼 표를 사고 약속하고 협박하며 법을 통과시킨다. 정차하면 열차장이 직접 내려 좀보이드식 사선 탑뷰 필드에서 물자를 찾고, 가져온 것과 잃은 것이 다시 의회로 돌아온다.

- 본체는 무한모드이고, 캠페인(정차 36곳, 약 15시간)은 해금한다.
- 첫 구간 볼슈틴 → 라이프치히는 두 모드가 함께 쓰는 서막이다.
- 엔진은 Godot 4.7.2, 그림은 전부 실시간 3D다. 정치는 S3 전까지 웹(TypeScript) 시제품에서 규칙을 검증한다.
- 판매는 F2P로 먼저 낸다. 무료판에는 서막, 무한모드, 캠페인 1막이 들고, 유료판은 한 번 사는 해금(캠페인 2·3막, 이어지는 세계)이다.
