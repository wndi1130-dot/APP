# 그림 일곱 장의 조짐 자리와 낡음 점검 (바깥 눈 점검 C)

2026-10-07. 점검 꾸러미(00_external_review_package.md) C 요청에 대한 답이다. 대상 그림(화면 컨셉 C1·C3·C9, 모델 시안 M4 v6·M6 v4·M7b v5·M8 v2)은 저장소에 없고 로컬에만 있다. 표의 배치는 제안이며, 그림에서 실제로 보인 것과 구분해 적었다.

# 1절 한눈 요약

- 일곱 그림에는 겨울과 쇠락의 분위기가 충분하지만, 하차 판단에 쓸 위험 조짐은 더 크고 구체적으로 보여 줄 필요가 있다.
- 그림 1·3·6·7에 각각 세 자리, 총 열두 자리를 제안한다. 아래의 추가 요소와 사건은 제작 제안이며, 현재 그림에서 확인한 요소와 구분한다.
- 조짐이 나온 사건은 반드시 일어나게 한다. 하차 여부와 인원 선택은 그 위험에 노출되는 방식과 피해를 바꾸며, 조짐 자체가 사망을 확정하지는 않는다.
- 사람과 열차에는 눈·먼지 외에 서로 다른 재료의 덧댐, 손때, 비대칭 수리 흔적을 보강한다. 객차의 시야와 출입 기능은 유지한다.
- 개 짖음의 부재, 조짐의 움직임, 모바일 실기 가독성은 정지 그림만으로 확인할 수 없다. 복장과 격자 소품의 주의 사항은 5절에 적는다.

# 2절 그림별 조짐 자리

위치는 각 그림 전체를 기준으로 쓰며, 그림 7만 스토리보드의 칸 번호를 함께 적는다. 현재 관찰은 첨부 그림에 보이는 내용이고, 배치 제안은 앞으로 넣을 내용이다. 표의 위험은 조짐을 보여 준 뒤 반드시 발생시킬 사건으로 정한다. 같은 조짐을 장식으로 되풀이하거나, 날씨가 바뀌었다는 이유로 다른 위험을 뜻하게 만들지 않는다.

작은 입가의 피, 한 줄의 긁힘, 먼 눈동자만으로 판단하게 해서는 안 된다. 가까운 형태와 바닥 흔적을 함께 보여 주고, 움직임은 정차 관찰 장면에서 보강한다. 조짐을 읽어야 하는 곳에는 별도의 경고 문구나 위험 색 테두리를 얹지 않는다.

# 3절 아직 말끔한 곳과 낡게 할 방법

현재는 눈과 얼룩이 낡음을 주로 설명한다. 여섯 번째 겨울까지 버텼다는 인상을 내려면, 닳은 곳을 여러 번 고친 흔적이 필요하다. 따뜻한 실내와 새하얀 눈은 유지하되, 사람이 자주 만지는 부분과 바깥에 노출된 부분의 마모를 다르게 그린다.

| 그림과 위치 | 현재 판정 | 낡게 할 방법 |
|---|---|---|

그림 4·5의 위쪽 회색 시트는 표면 채색 전 형태를 보여 주는 자료로 읽힌다. 회색이라는 이유만으로 새것으로 판정하지 않는다. 다만 덧댐의 두께, 교체판의 단차, 비대칭 밑단처럼 실제 형태로 남아야 할 수리 흔적은 이 단계에도 필요하다. 기관차와 건물의 균열·흔들림을 사건 조짐으로 정한 경우에는 같은 모양을 단순 노후 장식으로 재사용하지 않는다.

# 4절 장소·날씨별 그림 조각 목록

표의 ‘공통 날씨’는 눈·안개·진눈깨비·흐림·맑은 추위를 모두 뜻한다. ‘먼저’는 처음 조짐을 구별하고 사건과 연결하는 데 필요한 조각이고, ‘나중’은 같은 의미를 유지하면서 장소별 반복을 줄일 변형이다. 표의 장소는 조각을 사용할 범위이며, 첨부 그림에 그 장소가 모두 그려져 있다는 뜻은 아니다.

조각은 정상 상태, 조짐 상태, 사건 뒤 상태를 묶어 준비한다. 예를 들어 인양 화물은 반듯하게 매달린 상태, 기울며 파편이 떨어지는 상태, 바닥에 떨어져 길을 막은 상태가 이어져야 한다. 날씨는 흔적의 재료감과 보이는 거리를 바꾸고, 조짐이 뜻하는 사건은 유지한다. 한 장소에 모든 조각을 동시에 넣기보다 하차 판단에 필요한 조짐을 먼저 읽히게 한다.

## 확인 못 한 것

- 정지 그림이므로 개 짖음의 중단, 새의 동시 비행, 구조물 흔들림, 실제 위험 발생의 시간 순서는 확인하지 못했다. 표에 적은 동작과 사건 연결은 제안이다.
- 핏자국·끌림 자국·화재 연기·열린 자동차 문은 현재 그림에서 분명한 조짐으로 확인되지 않았다. 눈바닥의 어두운 얼룩과 기관차 증기를 그 증거로 취급하지 않았다.
- 실제 모바일 화면 크기, 밝기, 눈부심, 손가락과 조작 버튼의 가림 아래에서 읽히는지는 확인하지 못했다. 크기를 줄인 기기 화면에서 글과 위험 계기를 가리고, 하차 전에 조짐의 위치와 의미를 알아볼 수 있는지 확인해야 한다.
- 실제 3D 모델의 뒷면·재질·관절·객차 내부 구조는 이 시트로 확인할 수 없다. 회색 형태 시트와 채색 시트는 표현 방향을 판단하는 자료로만 사용했다.
- 조짐이 뜨면 반드시 사건이 발생한다는 구현, 하차 거절 시의 처리, 선택한 인원만 내리는 흐름은 확인하지 못했다. 이 문서의 완료 상태는 일곱 그림의 시각 점검과 배치 제안 작성 완료를 뜻한다.
- Markdown 원문에서 절·표 구성과 내용을 확인했다. 공개 저장소의 실제 렌더링과 게시 상태는 확인하지 못했다.
