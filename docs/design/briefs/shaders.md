# 설계 브리프: 셰이더와 화면 효과

작성: 2026-10-09 · 상태: 제안(숫자는 모두 가안). 코드는 `s2/fx/`, 미리보기는 `s2/fx/gallery.tscn`, 시험은 `s2/tests/test_fx.gd`.

상황마다 어떤 셰이더를 쓰는지, 날씨·시각을 어떻게 셰이더에 넘기는지, 폰 예산과 금지선을 효과에서 어떻게 지키는지를 정한다. 그림 방향은 [decisions.md](../decisions.md)의 날씨와 빛, UI 연출, [presentation_motion.md](presentation_motion.md)를 따르고, 계절·시각·지역 축은 [seasons_regions.md](seasons_regions.md)를 따른다.

## 1. 원칙

- **모델은 맨 것, 날씨는 셰이더가 얹는다.** 눈, 젖음, 진창, 성에, 그을음은 재질에 굽지 않고 셰이더가 전역 값으로 얹는다(seasons_regions.md 7장 추천과 같은 전제). 그래서 트리포 모델 하나가 한겨울·해빙·눈 없는 상태를 다 쓴다.
- **날씨 상태는 한 곳에서 쓴다.** 셰이더 전역 값 일곱 개를 `s2/fx/fx_state.gd` 하나만 쓴다. 게임 코드는 "이 정차는 안개와 가는 눈, 영하 14도, 12시"만 말한다.
- **직접 짠다.** 이번 묶음은 남의 코드를 하나도 쓰지 않았다. 공개 셰이더는 레퍼런스로만 보고, 들여올 때는 권리 장부에 먼저 적는다(7장).
- **폰에서 싸게.** 화면·깊이 텍스처를 읽지 않고, 노이즈는 텍스처 없이 두 겹, 화면 전체 패스는 하나만 둔다(5장).

## 3. 날씨 상태 하나로

셰이더 전역 값(project.godot `[shader_globals]`, 모두 0~1):

| 이름 | 뜻 | 누가 정하나 |
|---|---|---|
| `fx_wet` | 젖음. 비 1, 진눈깨비 0.75, 안개 0.25, 흐림 0.1. 영하 3도 밑에서는 0.25를 넘지 않음 | 날씨 |
| `fx_snow` | 쌓인 눈. 두께 0·1·2 = 0, 0.38, 0.9 | 계절(seasons_regions 7장). 안 주면 기온으로 어림 |
| `fx_frost` | 성에. 영하 2도부터 늘어 영하 18도에서 1 | 기온 |
| `fx_wind` | 바람 방향(x, z)과 세기 | 날씨(weather.gd의 wind_dir, wind) |
| `fx_tint` | 하늘·안개·입자에 덮는 색(날씨 색 × 시각 색) | 날씨와 시각 |
| `fx_flash` | 번개 몇 프레임 | 사건 |
| `fx_fade` | 전술 일시정지 바램 | 필드 |

쓰는 법:

```gdscript
const FxState = preload("res://fx/fx_state.gd")
FxState.apply(FxState.params_for(weather.kinds, ambient_c, weather.wind_dir, weather.wind, hour, FxState.snow_for_level(season_snow)))
var light := FxState.lighting_for(weather.kinds, hour)  # 해 색·세기, 주변광, 안개 색·밀도, 등불 색
```

- 날씨 종류는 `game/sim/weather.gd`를 따르고, seasons_regions.md 4장의 여섯 가운데 `overcast`(흐림)와 무한모드용 `rain`을 더 받는다. 모르는 종류는 weather.gd처럼 버린다.
- 시각 띠는 넷이다: 새벽 청회색, 낮 납빛, 해 질 녘 호박빛이 섞인 회색, 밤 등불만. 경계 시각은 계절 상태마다 다르다(seasons_regions.md 7장): 한겨울 07:00 / 08:30 / 14:50 / 16:30, 늦겨울 06:30 / 08:00 / 15:30 / 17:10, 해빙 초입 05:45 / 07:15 / 16:15 / 17:55. `params_for`·`lighting_for`의 `season`(deep_winter, late_winter, early_thaw, 기본 한겨울)으로 고른다.
- 눈 두께는 `snow_level_for(season, open_ground)`: 한겨울 2, 늦겨울 2(바람에 깎인 평원은 1), 해빙 초입 1(볕·진창은 0).
- 계절 스레드와 닿는 곳은 `params_for`의 `ground_snow`와 시각 띠 둘이다. 셰이더는 고치지 않고 이 두 입력만 바꾸면 된다.

## 4. 숫자 (가안)

- 색: 날씨 색과 시각 색은 모두 회색·청회색이다. 파란 쪽으로 기운 색은 채도 0.15를 넘지 않고(하늘색은 지지에만), 해 질 녘도 빨강 쪽으로 0.15 넘게 기울지 않는다(빨강은 불만·부족에만). 시험이 이 두 줄을 지킨다.
- 눈 색 (0.70, 0.71, 0.72), 성에 색 (0.70, 0.715, 0.73): 회백색. 처음 판(0.80)은 미리보기에서 하얗게 날아가 낮췄다.
- 낮 해 세기 0.55, 주변광 0.45. 궂은 날씨는 해를 0.6~0.8배로 줄인다.
- 눈 두께 1은 평평한 데를 대부분 덮고 바람에 깎인 맨땅 줄이 남으며 비탈은 거의 맨것, 두께 2는 비탈까지 덮는다.

## 5. 폰 예산

- 화면 텍스처(`hint_screen_texture`)와 깊이 텍스처를 읽지 않는다. 서리 유리처럼 화면을 읽는 효과는 폰에서 비싸다(presentation_motion.md 743~748). 시험이 이 줄을 지킨다.
- 화면 전체를 덮는 패스는 `screen_overlay` 하나다. 위에 섞기만 하고 아래를 읽지 않는다. 일시정지 바램은 화면 패스가 아니라 세계 셰이더 안의 전역 값이다.
- 노이즈는 텍스처 없는 값 노이즈 두 겹(`fx_common.gdshaderinc`). 성에 결만 여섯 번 읽는다.
- 연기는 겹칠수록 비싸다(train_cars_20261007.md 339). 달리는 기관차 연기는 입자 72개로 시작하고, 폰에서 재 보고 줄인다.
- 실제 폰(Mobile 렌더러, Vulkan)에서는 아직 재지 않았다. 클라우드에서는 Godot 4.7.2를 llvmpipe(GL 호환)로 띄워 미리보기를 찍었다. 엔진 문서 9장의 다음 S22 재측정 때 같이 잰다.

## 6. 금지선을 효과에

프로젝트 지침의 연기·불빛 줄을 효과로 옮긴 것이다. 연기는 모두 `fx/smoke.gd` 한 곳에서 만들고, 종류 표가 곧 규칙이다.

| 종류 | 어디서 | 모양 | 막는 것 |
|---|---|---|---|
| `loco_run` | 달리는 기관차 굴뚝 | 굵고 긴 회색 연기가 뒤로 흐름(뒤로 가는 양이 오르는 양의 두 배 넘음) | 곧게 선 기둥 |
| `loco_idle` | 선 기관차 바퀴 옆 | 바닥에 퍼지는 옅은 김, 1m 밑 | 멈춘 열차의 연기 기둥. 속도 1m/s 밑이면 굴뚝 연기는 저절로 꺼짐 |
| `stove` | 객차 난로 연통 | 옅은 김, 진하기 0.22 이하 | |
| `low_drift` | 포대·문틀의 조짐 연기, 들판 연기 | 땅에 깔려 옆으로, 1.5m 밑 | 굴뚝·높은 기둥 |

- 건물·공장 굴뚝, 냉각탑, 닫힌 화차의 연통, 장작불 화장의 높은 연기는 **종류 자체가 없다**. `build("chimney")` 같은 호출은 빈 값을 돌려주고, 시험이 이를 확인한다.
- 연기는 HUD 띠 뒤로 지나가도 되지만 칸 단면의 창과 사람 얼굴을 덮지 않는다. 이건 놓는 자리의 문제라 홈 단면을 만들 때 확인한다.
- 사람이 사는 칸의 창은 성에와 판자가 불빛을 줄여도 가리지는 않는다(`window_glass`의 최소 비침 0.55).
- 성에 무늬는 결이 고른 격자나 엇갈린 줄을 쓰지 않는다. 미리보기 두 번째 판의 엇갈린 결이 철망처럼 읽혀 휘는 잎맥 무늬로 바꿨다. 실제 성에 사진에서 뽑은 마스크가 생기면 그걸로 바꾼다.
- 눈 덮임의 맨땅 자국은 고른 얼룩이 되지 않게 넓게 휜 노이즈를 쓴다. 미리보기에서 네모 얼룩이 위장 무늬처럼 보여 바꿨다.
- 색: 빨강과 하늘색을 쓰지 않는다(물림은 어두운 맥박, 무리 경고는 색 없는 성에). 처치·위생 장면의 분무, 김 쏘이기, '소독' 효과는 만들지 않는다. 솥·주전자 김이 필요하면 `stove` 종류를 쓴다.

## 7. 공개 셰이더와 권리

- 이번 묶음 열한 개와 공용 함수는 모두 이 저장소에서 새로 짰다. 남의 코드나 그림을 들여오지 않았다(권리 장부 1장에 한 줄).
- 이미 조사된 후보(권리 장부 4장, Pro 수집 r5): Snow-Covered Surface(CC0), Improved frosted glass(CC0), 눈 위 바퀴 자국(MIT), Bloody Pool(MIT). 앞의 둘은 이번에 같은 일을 직접 짰으니 들여오지 않는다. 서리 유리는 화면을 읽어 5장 예산에 걸린다.
- 상황별 공개 셰이더 조사(2026-10-10, PC 워커 루나 웹 조사 + 솔 교차, 원문은 공유 폴더 `refs_luna.md`·`refs_sol.md`·`refs_COMPARE.md`): 두 모델이 라이선스까지 겹친 것은 다섯이다(Snow-Covered Surface CC0, Frostbite CC0, Noise-Based Moving Smoke Effect CC0, More Advanced "Simple 2D dissolve" CC0, Basic Fog of War Shader MIT). 링크는 사람이 열어 보지 않았고 Mobile 렌더러 동작은 둘 다 확인하지 않았다.
  - 판단(제안): 지금은 들여오지 않는다. 눈·연기·디졸브는 이번 묶음이 같은 일을 하고, Frostbite와 Fog of War 셰이더는 화면을 읽어 5장 예산에 걸린다. 종이 잉크 번짐과 부드러운 시야 경계는 그대로 쓸 예제가 없다는 데 둘이 같았다.
  - 다음 묶음에 쓸 엔진 기본 기능(엔진 MIT, 권리 장부의 Godot 줄로 덮임): 손전등·등불 빛 쿠키는 `Light3D.light_projector`, 색 보정은 `Environment`의 조정과 3D LUT, 연기를 더 싸게 할 때는 `GPUParticles3D` 플립북. 부드러운 입자(Proximity Fade)는 깊이를 읽어 쓰지 않는다.
  - 공개 셰이더를 들여올 때는 코드만 허가 범위이고 미리보기 그림·딸린 텍스처는 따로 확인한다. 라이선스가 CC0·MIT·Apache·BSD가 아니면 쓰지 않는다.

## 8. 미리보기

- `s2/fx/gallery.tscn`: 회색 상자 마당 하나에 모든 셰이더를 놓고 상황 열 개(안개·가는 눈 낮, 진눈깨비 해 질 녘, 해빙 비, 눈보라 밤, 맑은 추위 새벽, 무리 경고, 전술 일시정지, 눈 두께 0·1·2)를 1~0 키로 바꾼다.
- 찍기: `godot --path s2 --rendering-driver opengl3 res://fx/gallery.tscn -- --shots=<폴더>`가 상황마다 PNG를 남기고 끝난다.
- 폰 빌드에서는 시작 화면의 **셰이더 보기** 단추로 연다(메뉴로·이전·다음 단추와 뒤로 제스처가 있다).

## 9. 남은 일과 넘길 것

- **S2 필드에 붙은 것(2026-10-10)**: `field_game.gd`가 정차 시작 때 `FxState.apply`를 부르고, 해·주변광·바깥 배경색을 `lighting_for`와 `fx_tint`에서 받는다(해 질 녘에는 도착 때 빛에서 밤 띠 값으로 줄어든다). `world_vis`는 눈·젖음에 더해 선 면의 옅은 성에(`fx_frost`)와 일시정지 바램(`fx_fade`, 0.25초)을 읽고, 눈발은 `precip`이 그린다. 필드가 전보다 어둡고 회색이다(낮·안개·가는 눈에서 해 0.7 → 0.41, 주변광 0.6 → 0.39). 폰에서 보고 숫자를 고친다. 아직 안 붙은 것: `screen_overlay`(HUD 층과 순서를 맞춰야 한다), 망자 셰이더의 날씨.
- **S2 필드 파밍(처음 적은 것)**: 필드 지도는 정점 색 회색 상자와 시야 마스크(`world_vis.gdshader`)로 그린다. 날씨를 붙이려면 `world_vis`가 `fx_common`을 include해 `weathered`의 눈·젖음 몇 줄을 쓰거나, 실제 모델이 들어올 때 `weathered`로 바꾼다. `field_game.gd`가 정차 시작 때 `FxState.apply`를 한 번 부르면 된다. 고칠 곳 둘: 부활 링이 빨강(zombies.gd 74~77), 추위 테가 하늘색(field_hud.gd 18). 갤러리를 부팅 메뉴에 단추로.
- **트리포 발주**: 모델은 맨 것(눈·때 굽지 않음), 램프 유리는 따로 재질, UV는 겹치지 않게. 재질 칸에 `porosity`(천·나무·벽돌 0.6~0.8, 금속·유리 0.05~0.1)와 `metallic`을 정해 두면 `weathered`에 바로 꽂힌다.
- **계절·시간대와 지역 변형**: 눈 두께 0·1·2 시험 결과(4장)와 시각 띠 경계, 계절별 해 뜸·짐을 받는 자리(3장).
- **금지선 점검 / 좀비 설계**: zombies.md 34·69의 '연기 기둥을 향해 걷는 자'는 '보일러 열과 바퀴 밑에 낮게 깔린 김을 향해'로 고쳐졌다(PR 80). 6장의 연기 네 종류와 맞는다.
