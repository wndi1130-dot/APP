## 1. 원칙

1. **말투는 세계의 말투**다. 건조한 평서 '~다'. 무엇이 일어났는지 한 문장, 플레이어가 할 일이 있으면 한 문장. 사과, 느낌표, 이모지, '죄송합니다', '오류 코드 0x…'는 쓰지 않는다. 기술 세부(스택, 파일 이름)는 접힌 칸이나 복사 묶음에만 둔다.
2. **빨강을 쓰지 않는다.** 빨강은 불만과 부족 전용이다. 오류와 경고는 호박색(`--warning`) 테두리나 종이 쪽지로 보인다.
3. **판을 잃지 않는다는 걸 먼저 말한다.** 오류가 나도 저장이 남아 있으면 그 사실이 첫 줄이다. 잃었으면 어디까지 잃었는지 말한다.
4. **알림창은 아낀다.** 조용히 지나가는 장면(presentation_motion '알림창이나 소리 신호는 쓰지 않는다')에는 띄우지 않는다. 띄울 때는 한 번에 하나, 같은 알림을 되풀이하지 않는다.
5. **되돌릴 수 없는 메뉴 동작은 두 번 누른다.** 판 전체를 버리는 동작(새 판, 처음부터)은 첫 탭에 '한 번 더 누르면 …' 쪽지를 띄우고 3초 안에 다시 눌러야 실행한다. 확인 창(모달)은 쓰지 않는다. 출발 레버의 두 번 눌러 출발과 같은 몸짓이다.
6. **기다림은 연출로 가리고, 가려지지 않으면 말한다.** 1초 안은 아무것도 띄우지 않는다. 1초를 넘으면 세계 안 문구, 8초를 넘으면 다시 시도할 길을 준다.
7. 문구도 민감한 역사 금지선을 지킨다(프로젝트 지침). 로딩 문구에 굴뚝 연기, 칸 잠금, 명령조 외침을 쓰지 않는다.

## 3. 일부러 안 하는 것

- 스피너, 진행률 막대, 스켈레톤. 계산이 모두 기기 안에서 끝나고 기다림이 짧다. 진행률은 거짓말이 되기 쉽다.
- 확인 모달. 두 번 누르기로 대신한다.
- 네트워크 오류 화면. 서버가 없다(스토어 N3만 예외).

## 4. 남은 일 (S1에는 안 입힘)

- P3 못 누름 이유를 터치에서도 보이게: 지금 `title`에만 있는 곳(한눈에 보기의 자동 레버, 내정 몇 곳)을 화면 글로 옮기거나, 단추를 막지 않고 눌렀을 때 쪽지를 띄운다. 내정 화면을 건드리는 일이라 내정 스레드와 겹치지 않게 나중에.
- 터치 크기: 32px 아래 단추(칩, 닫기, 내정 칩 26px)를 44px 눌림 영역으로. 출시판에서는 '엄지 크기 단추'(s2 ui_theme)로 처음부터 맞춘다.
- 렌더 뒤 키보드 포커스 복원.
- 출시판 문구는 번역 키를 거친다(s1_content_guide 6.2). 이 문서의 문구가 첫 한국어 값이다.
