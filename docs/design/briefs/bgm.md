# 제안 브리프: 배경 음악(BGM) — 상황·날씨·위협에 맞춰 들어가고 빠지는 음악

작성: 2026-10-24 · 상태: 제안. 사용자 2026-10-24 말 「bgm 부분도 시작해보자 … 분위기나 날씨 상황에 맞게 bgm 짜게해줘 … 여러게 만들고 내가 평가해줄게」를 다룬다(장부 번호는 다음 장부 PR에서 붙는다). 목표는 결정 415(어색·불합리 없게)다.

바탕: [sound_music.md](sound_music.md) 3장(원칙), 5장(출발 소리 순서), 6장(일곱 층), 7.1(조짐 소리), 9장(음악의 성격 C, 2026-10-07 사용자 결정), [seasons_regions.md](seasons_regions.md), [weather_fx.md](weather_fx.md), 필드 소리 `s2/game/audio/field_audio.gd`, 무리 조율 `s2/game/sim/horde_director.gd`, 분위기 틀 `s2/fx/atmosphere.gd`(분위기 세션 가지에 있고 아직 main에 없다). 참고 게임 하나의 음악이 언제·어디서·어떻게 도는지 읽은 결과는 저장소 밖 결과 글에 있고, 여기에는 이름 없이 배운 점만 옮긴다.

## 요약

- 음악은 늘 깔지 않는다. 필드는 「조각 하나 → 조용한 틈 → 다음 조각」으로 가고, 위협이 오르면 빠르게 층이 붙고 내려가면 천천히 빠진다.
- 곡을 고르는 값은 둘이다. **탐색 결**(시각 띠 × 날씨 × 계절 진행)과 **위협 단계**(0 없음 · 1 보임 · 2 쫓음 · 3 덮침 · 4 무리). 결이 곡의 색을, 위협이 곡의 세기를 정한다.
- 열차 안은 지금 결정(9장 C: 칸 노래·축음기·방송이 음악이고, 메인 악보는 장면에만)을 그대로 둔다. 이 문서는 열차 안에 새 상시 층을 깔지 않는다. 열차 화면 밑에 날씨·추위의 옅은 지속음을 둘지는 사용자에게 묻는다(9장).
- 규칙 소리가 늘 이긴다. 규칙 경고, 조짐, 망자 소리, 제동, 기적, 무전이 나면 음악이 비켜 서고, 공포의 침묵과 조짐 묶음이 우는 동안에는 음악이 없다.
- 시안은 8갈래 19곡을 생성 음악으로 만들어 저장소 밖에서 사용자가 듣고 고른다(7장). 고른 곡만 쓰기 조건을 확인한 뒤 저장소에 넣는다.
- 9.1의 「필드는 무리가 몰릴 때 짧게」를 이 문서가 넓힌다(필드 탐색에도 조각을 둔다). 사용자의 이번 요청에 따른 것이고 확정은 사용자 답으로 한다.

## 1. 참고 게임에서 배운 것

1. **곡은 값 두 개로 고른다.** 하나는 탐색 쪽 세기(차분함↔들뜸), 하나는 위협이다. 둘 다 0~100 점수를 문턱 둘(34, 67)로 잘라 낮음·중간·높음 세 단계만 음악에 넘긴다. 연속 곡선보다 단계가 다루기 쉽다.
2. **세기는 사건이 더하고 뺀다.** 기준 50에서 건물에 들어가 있는 동안 −40, 새 상자를 뒤지면 −10, 처음 보는 방을 보면 −30(60초)이다. 창 넘기·담 넘기는 +30, 탈것에 타면 +50(120초)이다. 사건마다 정해진 시간(대부분 30초) 그대로 있다가 한 번에 빠진다. 같은 사건은 겹쳐 쌓지 않고 시간만 새로 센다. **살피는 행동은 음악을 낮추고, 몸을 쓰는 행동과 사고는 올린다.**
3. **위협은 「나를 향해 움직이는 놈」이 거의 전부다.** 보이기만 하는 망자는 마리당 0.1점이고, 나를 노리고 걸어오거나 달려드는 망자는 가까이(10칸 안) 마리당 10점, 멀리 5점이다. 공황과 다친 정도가 각각 최대 20점을 더한다.
4. **곡은 같은 곡을 세 판(낮음·중간·높음)으로 만들어 세기만 바꾸고**, 쫓김·싸움 곡은 4~16마디 고리 조각을 이어 붙인다(들어감 → 고리 → 다리 → 끝). 낮은 세기에서는 곡이 사라졌다 다시 들어오는 길이 곡 안에 짜여 있다. 조용한 틈이 장치의 일부다.
5. **곡을 고를 때 바로 앞 곡은 빼고,** 지금 값에 가까운 곡 몇 개 가운데 무작위로 고른다.
6. 날씨·시각 값은 참고 게임에서 바탕 소리용으로만 갱신되고 음악용 값 목록에는 없다(추정: 곡 이름에도 날씨·밤 갈래가 보이지 않는다). **분위기·날씨에 맞추는 것은 우리가 새로 얹는 것이다.**

## 2. 원칙

1. **조용한 틈이 기본이다.** 필드 한 판(안전 체류 20분, 손실 한계 30분)에서 음악이 울리는 시간은 절반을 넘지 않는다(제안 35~50%). 조각이 끝나면 60~180초 쉰다. 정차 직후 읽기 박자(조짐 소리가 우는 때, sound_music 7.1)에는 음악이 없다.
2. **위협은 빨리 오르고 천천히 내린다.** 오를 때는 다음 박(0.5~2초)에 붙고, 내릴 때는 위협이 사라져도 20초 버틴 뒤 한 단계씩 8~12초에 걸쳐 빠진다. 문턱 근처에서 단계가 자주 뒤집히지 않게 단계마다 최소 유지 시간(8초)을 둔다.
3. **음악은 규칙을 흘리지 않는다.** 위협 값은 플레이어에게 이미 드러난 것만 센다: 화면에 보이는 망자, 소리 경고가 뜬 망자, 화면 막대로 보이는 무리 압력, 화면에 뜬 무리 예보. 보이지 않는 곳의 망자, 숨은 결과, 정찰 안 한 곳의 위험은 음악에 넣지 않는다. 소리를 끄고 해도 지는 일이 없어야 한다(sound_music 원칙 1).
4. **잔혹한 결정을 축하하지 않는다**(sound_music 원칙 4). 희생·축출·통과·부결에 승리나 패배처럼 들리는 마무리를 붙이지 않는다. 장조로 풀거나 큰 타격으로 끝내지 않는다.
5. **폰 스피커 기준이다.** 선율과 맥박은 200Hz~4kHz에 둔다. 낮은 저음은 이어폰에서 더해지는 덤이고, 모노로 들어도 같은 곡이다.
6. **음색은 아트 방향을 따른다**(sound_music 4장, 9.1). 현악 중심(독주 첼로 → 4중주 → 현악 합주), 그 밑에 늘인 소리·긁는 쇠·두드리는 줄 같은 거친 질감. 밝은 신시사이저, 영웅적인 금관, 행진 박자, 북, 합창 구호, 찬송처럼 들리는 것은 쓰지 않는다(9.3 '버티는 노래'의 선과 같다).

## 4. 탐색 결: 시각 띠 × 날씨 × 계절

이름은 분위기 틀(`s2/fx/atmosphere.gd`, 분위기 세션 가지)을 따른다. 그 파일은 아직 main에 없고, main의 규칙 날씨(`s2/game/sim/weather.gd`)에는 흐림과 비가 없다. 틀이 합쳐지면 이름을 다시 맞춘다.

- 시각 띠: `dawn` 새벽, `day` 낮, `dusk` 해 질 녘, `night` 밤
- 날씨: `clear` 맑음, `overcast` 흐림, `fog` 안개, `snow` 눈, `blizzard` 눈보라, `sleet` 진눈깨비, `rain` 비
- 계절 진행(결정 423, 늦가을 시작 → 3막만 해빙): 늦가을(`late_autumn`) → 이른 첫 추위 → 초겨울(`early_winter`) → 한겨울(`deep_winter`) → 해빙(`late_winter`·`early_thaw`)

4 × 7 × 5 = 140 조합에 곡을 하나씩 두지 않는다. 곡마다 맞는 띠·날씨·계절을 표시해 두고, 지금 상태와 가장 잘 맞는 곡 몇 개(맞는 정도 위 30%) 가운데 바로 앞 곡을 빼고 무작위로 고른다(1장 5).

| 축 | 값 | 음악이 바뀌는 것 |
|---|---|---|
| 시각 띠 | 새벽 | 얇은 높은 지속음, 장조도 단조도 아닌 결, 가장 조용 |
| | 낮 | 탐색 조각의 기본(선율이 있다) |
| | 해 질 녘 | 같은 빠르기로 낮은 음역에 내려간다 |
| | 밤 | 선율이 거의 없고 지속음과 성긴 피아노. 틈이 1.5배 |
| 날씨 | 맑음 | 가장 드물다. 궂은 날씨 8할인 세계라 맑은 날은 낯설게 조용하다. 틈이 2배 |
| | 흐림 | 기본 |
| | 안개 | 선율을 줄이고 가까운 지속음. 소리가 가까이 붙는 결 |
| | 눈 | 느리고 부드럽게, 음이 드문드문 떨어진다 |
| | 눈보라 | 탐색 조각은 없다. 바람이 음악이다. 위협 판만 운다 |
| | 진눈깨비·비 | 뜯는 현, 젖은 질감 |
| 계절 진행 | 늦가을 | 기타와 첼로, 나무의 따뜻함이 조금 남는다 |
| | 이른 첫 추위 | 같은 주제가 얇아진다 |
| | 초겨울 | 현악 중심, 쇠 질감이 들어온다 |
| | 한겨울 | 높은 배음, 유리 같은 긁힘, 가장 성기고 조용하다 |
| | 해빙(3막만) | 느린 장조 조각. 위협 판은 그대로다 |

편성은 이야기 단계에 따라 커진다(9.1 변주 축: 독주 첼로 → 4중주 → 현악 합주). 지역 띠는 질감만 바꾼다(9.1 예: 탄광 구간의 쇠 타악 질감).

## 5. 위협 단계와 층

위협 점수(0~100, 제안 값, 4단계 구현 때 시험으로 맞춘다). 1장 3처럼 「나를 향해 오는 놈」을 무겁게 둔다.

| 입력 | 점수 | 읽을 곳(구현은 4단계) |
|---|---|---|
| 화면에 보이는 망자 | 마리당 1, 최대 10 | 필드 시야(`s2/game/sim/sense_rules.gd`) |
| 나를 향해 오는 망자(보이거나 소리 경고가 뜬 것), 10m 밖 | 마리당 8 | 같은 곳 |
| 같은 망자, 10m 안 | 마리당 15 | 같은 곳 |
| 잡힘·몸싸움 중 | 70 | `s2/game/sim/grab_rules.gd` |
| 다침(피 흘림, 큰 상처) | 최대 10 | 몸 상태 |
| 무리 압력(화면 막대로 보이는 만큼만) | 최대 15 | `horde_director.gd`의 `pressure()` |
| 무리 도착 단계 | 4단계로 바로 | `horde_director.gd` |

단계: 0 없음(10 미만) · 1 보임(10~29) · 2 쫓음(30~59) · 3 덮침(60 이상이거나 잡힘·3m 안) · 4 무리(도착 단계 동안). 오를 때는 바로, 내릴 때는 2장 2의 버팀과 최소 유지 시간을 따른다.

층: 시안 단계에서는 단계마다 다른 곡(THREAT_SEEN, THREAT_CHASE, THREAT_HORDE)으로 갈아 넘긴다(섞어 넘기기). 생성 음악은 한 덩어리 믹스로 나와 층(스템)을 따로 받지 못하기 때문이다. 같은 갈래 곡은 같은 조성(라 단조)으로 시킨다. 들어 보고 섞어 넘길 때 어긋나면, 고른 곡을 사람이 층으로 나누거나 작곡가에게 맡기는 길(9장 3)로 간다.

## 6. 소리 효과와의 크기 규칙

음악은 sound_music 6장 일곱 층의 5~6층 사이에 들어간다. 그 표를 바꾸지 않고, 음악이 언제 비켜 서는지만 정한다.

- 버스: `Music` 버스를 따로 둔다(지금 필드에는 `SFX`, `SFX_MID`, `SFX_FAR`만 있다). 설정의 음악 음량이 이 버스다. 칸 노래와 축음기는 열차 안에서 나는 소리라 음악 버스가 아니라 효과 음량을 따른다(sound_music 9.3). 음악을 끈 사람도 반란 전야의 합창은 듣는다.
- 기준 크기(제안, S22 폰 스피커에서 잰다): 탐색 조각은 효과 바탕보다 6dB 낮게, 위협 곡은 3dB 낮게, 장면 곡(TITLE, CRISIS, LOSS)은 바탕과 같게.

| 그때 나는 소리 | 층 | 음악 | 내림·되돌림 |
|---|---|---|---|
| 규칙 경고(부르는 자의 들이쉼, 무리 예고, 위급 알림) | 1 | −12dB | 0.1초에 내리고, 소리가 끝나고 1.5초 뒤 0.8초에 되돌림 |
| 무전, 의사의 목소리, 방송 | 2 | −8dB | 0.2초 / 끝나고 0.5초 |
| 망자 신음(8m 안), 문 부수기, 총 | 3 | −3dB | 0.3초 / 2초 |
| 제동, 기적 | 3 | 음악을 멈춤 | 제동 꼬리가 사라질 때까지 새 조각 없음 |
| 조짐 묶음 | 4 | 음악 없음 | 정차 직후 읽기 박자, 파견 카드를 펼칠 때 |
| 칸 노래·축음기(열차 안) | 5 | 메인 악보가 울리면 칸 노래가 −10dB 물러난다(9.1). 그 밖에 BGM은 열차 안에 없다 | — |
| 공포의 침묵(공포 80 이상) | 5 | 음악 없음 | 침묵이 계기라 위에 얹지 않는다 |
| UI(레버, 종이, 버튼) | 7 | 비켜서지 않음 | — |

- 같은 경고가 짧은 간격으로 겹쳐도 음악을 계속 눌러 두지 않는다. 내림은 마지막 경고를 기준으로 한 번만 센다.
- 소리를 끈 폰에서도 정상이다. 진동은 음악에 쓰지 않는다(sound_music 8장).

## 7. 시안 갈래와 이름

생성 음악(사용자가 정한 서비스)으로 갈래 8개, 곡 19개를 만든다. 곡 파일과 프롬프트 전문은 저장소 밖 시안 폴더의 목록 파일에 있고, 사용자가 들어 보고 평가한다. 프롬프트에는 다른 게임·작곡가·곡 이름을 넣지 않고 악기, 빠르기, 조성, 결로만 쓴다.

| 갈래 | 상황 | 곡 수 | 바뀌는 축 |
|---|---|---|---|
| TITLE | 시작 화면 | 3 | 편성(독주 첼로 / 피아노와 현 / 현악 합주) |
| TRAIN | 열차 내정에 옅은 층을 둘 때의 시험(9장 1의 답을 위해) | 2 | 평온 / 밤 |
| CRISIS | 위기 회기·큰 결정 | 2 | 반복음 긴장 / 독주와 지속음 |
| FIELD_DAY | 필드 탐색 낮 | 3 | 늦가을 흐림 / 초겨울 눈 / 한겨울 |
| FIELD_NIGHT | 밤·안개·지하 | 2 | 밤 안개 / 지하 |
| THREAT | 보임·쫓음·무리 | 3 | THREAT_SEEN / THREAT_CHASE / THREAT_HORDE |
| RETURN | 열차로 돌아옴 | 2 | 첼로 / 피아노와 비올라 |
| LOSS | 죽음·잃음 | 2 | 애가 / 판 끝 |

고를 때 볼 것: 폰 스피커에서 선율이 들리는가, 아는 곡을 닮지 않았는가, 행진·북·금관·합창 구호처럼 들리는 데가 없는가, 조각 끝이 틈으로 자연스럽게 사라지는가, 같은 갈래 곡끼리 섞어 넘겨도 어긋나지 않는가.

## 8. 구현 계획(사용자 평가 뒤, 4단계)

- 음악 감독 노드 하나를 필드·열차·정차 연출이 같이 쓴다(제안 이름 `s2/game/audio/music_director.gd`). 입력은 장면(title, train, stop, field, under, return, loss, decision), 탐색 결(띠, 날씨, 계절), 위협 단계다. 하는 일은 곡 고르기, 섞어 넘기기, 틈, 비켜서기다.
- 입력 연결: 분위기 틀의 `look`(띠·날씨·추위), 무리 조율의 `pressure()`·도착 단계·`forecast()`, 필드 시야와 잡힘. 새 사건 장부를 따로 만들지 않고 이미 있는 값을 읽는다.
- 겹치는 파일: `field_audio.gd`(망자 소리 세션)와 `slice_flow.gd`(정차 연출 세션)는 4단계를 시작할 때 열린 PR을 먼저 본다.
- 시험(GUT): 위협이 오르는 시간과 내리는 버팀, 단계 최소 유지, 틈의 길이, 바로 앞 곡 빼기, 비켜서기 값, 공포 침묵과 조짐 동안 음악 없음.
- 파일: OGG, 96~128kbps 스테레오. 2~3분 곡이 곡당 약 1.5~3MB라 첫 묶음 20곡이면 약 30~60MB다. 폰 용량 예산과 같이 정한다.

## 9. 사용자가 정할 것

1. **열차 화면 밑에 옅은 지속음을 둘지.** 지금 결정(9장 C)은 열차 안 음악을 칸 노래·축음기·방송으로만 내고 메인 악보를 홈 상시 배경으로 깔지 않는다. 안은 둘이다. (가) 지금대로 둔다: 열차 안의 날씨·추위는 바람, 성에 긁힘, 느려지는 노래로만 들린다. (나) 평온하고 칸 노래가 멎은 동안에만, 회기 한 번에 한 번꼴로 아주 옅은 조각(TRAIN)을 둔다. 추천은 (가)다. 칸 노래가 멎는 순간이 계기인데 다른 음악이 그 자리를 채우면 침묵이 안 들린다. TRAIN 시안 두 곡은 (나)를 들어 보고 고르라고 만든다.
2. **필드 탐색에도 조각을 둘지**(9.1 「필드는 무리가 몰릴 때 짧게」를 넓히는 것). 이 문서는 넓히는 쪽이다. 사용자 이번 요청이 날씨·분위기에 맞춘 음악이기 때문이다.
3. **시안 평가 뒤 어떤 갈래를 쓸지,** 그리고 생성 음악을 출시판에 넣을지. 고른 서비스의 약관에 상업 이용을 명시적으로 허락하는 문구가 없으면, 같은 방향을 상업 허락이 명시된 서비스(권리 장부 2장)나 작곡가로 다시 만드는 쪽과 비교한다.

## 10. 아직 모르는 것

- 생성 음악이 프롬프트의 조성·빠르기를 실제로 지키는지. 섞어 넘길 때 어긋날 수 있다.
- 2~3분 곡의 반복 이음매. 끊김 없는 반복은 받은 뒤 손으로 다듬어야 한다(sound_music 9.2).
- 폰 스피커에서의 기준 크기와 비켜서기 값. S22에서 잰다.
- 정차 연출의 「지붕 위 달리기 → 내려다봄」이 정차 연출 세션에서 바뀌면 3장의 ARRIVAL 자리를 다시 맞춘다.
